# AutoApprove 0.2.354 · 빌드 381

공식 Codex에 포커스 보호용 `PreToolUse` 훅을 추가했습니다. Codex가 포커스를 가져갈 수 있는 computer use 도구를 호출하면, 훅이 호출을 차단하고 기존 `desktop_*` 도구로 안내합니다. 개별 화면 조회 도구와 AutoApprove MCP 도구는 계속 사용할 수 있습니다. JavaScript를 실행하는 `cua_repl`은 한 호출에 조회와 조작을 섞을 수 있어 실행을 차단하고 `desktop_snapshot`이나 `desktop_screenshot`으로 안내합니다.

```sh
/Applications/AutoApprove.app/Contents/MacOS/autoapprove install-codex-desktop-hook
```

별도 Codex 홈은 `--codex-home PATH`로 지정합니다. Codex의 `/hooks`에서 AutoApprove 훅을 확인하고 신뢰하면 적용됩니다. 현재 세션에서 새 훅이 보이지 않으면 Codex를 다시 시작한 뒤 확인합니다. `autoapprove desktop-guard off`로 포커스 보호를 끄거나 `autoapprove remove-codex-desktop-hook`으로 해당 홈의 훅을 제거할 수 있습니다. 앱에 연결할 수 없을 때는 보호 대상 호출을 차단합니다.

공식 Codex가 `PreToolUse`에 전달하는 로컬 호출에 적용됩니다. [Codex 훅 문서](https://learn.chatgpt.com/docs/hooks#tool-coverage)
