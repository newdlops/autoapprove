# AutoApprove 0.2.301

- 복원 중 서버 시작 명령이 기존에 설치된 호환 가능한 새 Codex 서버를 실행한 경우에도, 실행 파일과 소켓을 다시 검증하여 복원을 이어갑니다. 내장 클라이언트는 유지합니다.
- 세션 프로필에 그룹 이름, 구성원, 그룹장과 상위 구성원 관계를 함께 저장합니다. 실행 PID와 TTY는 저장하지 않습니다.
- 복원된 탭의 실제 실행 세션을 그룹 구성원에 다시 연결합니다. 대화 ID 확인과 탭 연결 확인은 구분하며, 메시지 전달에는 기존 대화 식별 검증을 유지합니다.
- 이전 프로필은 남아 있는 그룹 파일의 정확한 대화 식별 정보로 연결합니다. 과거 프로필에 저장되지 않은 그룹 구성은 추측하여 복원하지 않습니다.

검증: 프로필 회귀 검사, 선택 복원 컨트롤러 검사, 관리형 서버 검사 및 배포 빌드. 사용자 대화를 다시 실행하는 실복원은 별도로 확인해야 합니다.
