# 0.2.178 · 빌드 205

Codex의 일반 질문을 판별할 때 마지막300행을 한꺼번에 정규화하던 비용을 줄였습니다. 같은 원문 범위에서 선택된 번호·마지막 선택지·완전한 푸터·허가 제목·질문 제목을 확인하며, 실제로 읽는 행만 기존 NFC·공백·정규식 처리로 준비합니다. 다른 검출기가 이미 행을 준비했다면 그 결과를 재사용합니다.

ASCII 접두부는 확실히 불가능한 제목·선택지만 제외하는 데 사용합니다. Unicode·제어 문자와 가능한 모든 행은 기존 판정을 거칩니다. Codex 질문의 원문 코드 블록 경계와 별도 허가창의 정규화된 코드 블록 경계를 각각 유지합니다. Claude 전체 문맥·Cocoa/손상 UTF-16·일반 질문의 수동 응답·현재 모델 유지·오류/Goal 복구·원문 예산과 입력 직전 검증을 유지하며, 새 보관 캐시·타이머·서비스를 추가하지 않습니다.
