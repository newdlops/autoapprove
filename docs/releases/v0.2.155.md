# AutoApprove 0.2.155 · 빌드 182

이전 연결이 많은 웹 관리 페이지의 목록 갱신 비용을 줄였습니다. 0.2.154의 지난 세션 중복·기록 깜박임 수정도 포함합니다.

- 이미 연결이 끊긴 Mac의 배경 조회는 같은 오프라인 결과를 즉시 사용합니다. 조회 작업·동시 실행 슬롯·완료 대기를 만들었다 곧바로 거절하던 경로를 제거했습니다.
- 사용자가 선택한 Mac은 실제 재접속을 시도합니다. 진행 중인 조회와 유효한 성공 결과는 공유하며, 성공 결과의 만료와 자동 발견을 유지합니다.
- 조건부 응답은 현재 Mac 식별자·출처·설정·발견 상태를 계속 검증합니다. 연결 상태가 바뀌면 새 목록을 제공합니다.

동일한 실제 Release Core를 합성 로컬 Mac 0·12·96대 조건에서 8쌍 교대 비교했습니다. 최초 및 캐시 만료 후 목록 갱신의 CPU 중앙값은 12대에서 **2.152→0.438ms**, 96대에서 **40.575→2.820ms**였습니다. 반복 조건부 조회·대기 시간·메모리의 사전 한도도 통과했습니다. 전체 앱 CPU나 실제 휴대폰 지연의 개선율은 아닙니다.

최종 Release 전체 **379/379** 검사가 통과했습니다. 새 회귀에서 저장된 Mac 선택·자동 발견·조건부 응답의 출처/식별자 검증·성공 결과 만료를 확인했습니다.

서명 패키지 통합 검사 3개와 Chromium·WebKit의 목록 안정성 검사가 통과했습니다. 반복 갱신 시 세션 영역의 위치 변화는 두 엔진 모두 0px였습니다. 검증한 코드·웹 자원과 DMG의 무결성·설치 구성을 확인했습니다. 실제 휴대폰 확인은 포함하지 않습니다.
