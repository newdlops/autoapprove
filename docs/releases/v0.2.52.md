# AutoApprove 0.2.52 · 빌드 63

자동 승인·원본 터미널·질문·화면 공유를 유지하면서 반복 조회의 CPU 소모를 줄였습니다.

- 같은 화면의 분석을 재사용하고 함께 읽은 세션 상태를 한 번에 반영합니다. 새 화면·질문·세대 변경은 즉시 처리하며 입력 대기 확인과 승인 직전 검증을 유지합니다.
- 빈 알림 목록과 이미 정리한 읽은 알림의 반복 서비스 호출을 생략합니다. 초기 연결·명시적 재연결의 진행 표시는 유지합니다.
- 작업 폴더를 macOS API로 매번 직접 읽습니다. API 조회가 안 되는 프로세스에는 기존 방법을 적용합니다.
- 휴대폰의 **화면 공유**는 Mac 화면을 보기만 하며, **세션에 테스트 지시**는 같은 Codex·Claude Code 세션으로 보냅니다. 닫기·숨김의 이미지 요청 중지와 공유 만료를 유지합니다.

동일한 합성 16개 세션의 연속 조회 검사에서 CPU 소모가 동일 화면 **약 99%**, 변경 화면 **약 92%** 줄었습니다. 검사 프로세스의 최대 RSS는 약 **0.81MiB 증가**했습니다. 앱 전체 CPU·장시간 메모리나 실제 휴대폰 입력 지연을 측정한 수치는 아닙니다.

Core 152개와 웹·입력·대기열 회귀 검사를 통과했습니다. 각 Mac을 업데이트하고 휴대폰 페이지를 새로고침해주세요. 휴대폰 설치는 필요 없습니다.

검증 범위와 측정 조건은 [VALIDATION.md](https://github.com/newdlops/autoapprove/blob/main/VALIDATION.md)에 기록합니다. 설치 파일은 `AutoApprove-0.2.52-macOS-arm64.dmg`입니다.
