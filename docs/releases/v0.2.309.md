# AutoApprove 0.2.309 · 빌드 336

Claude가 대기 중이고 입력창도 비어 있는데 사용자 상태 줄 때문에 그룹 수신함 알림이 막히던 0.2.308의 회귀를 수정했습니다. 모델명·컨텍스트 사용량·요금제 사용량·초기화 시각을 표시하거나 상태 줄이 여러 줄로 접히는 경우를 포함합니다.

알림을 입력하기 전에 Claude 입력칸의 위·아래 구분선과 빈 본문을 확인합니다. 입력칸 밖의 상태 줄을 일반 활동 판정 규칙에 맞춰 해석할 필요가 없습니다. 경계가 없는 기존 표준 입력창은 기존 판정 방식을 유지하고, 경계와 상태 줄 모두 확인할 수 없는 화면은 계속 보류합니다.

- 한 줄·여러 줄 초안, 선택지, 권한 확인, 피드백 검토 메뉴에는 알림을 입력하지 않습니다.
- 기존 Claude 등록 상태가 busy이면 보관하고, idle로 돌아오면 같은 메시지의 알림을 다시 시도합니다.
- 알림 제출 후에도 수신자의 명시적 ACK 전까지 메시지는 미확인 상태로 남습니다. 같은 Mac의 로컬 저장·통신과 기존 그룹 권한을 유지합니다.
- 일반 활동 표시를 강제로 idle로 바꾸거나, 화면이 멈췄다는 이유로 작업 완료 보고를 만들지 않습니다. 완료 훅이 없는 세션의 완료 판단은 이 입력창 검사와 별개입니다.

Release 전체 회귀 **272/272**, Debug·Release IP 통신 차단 그룹 검사 **36/36**와 MCP 발신자·재연결 검사가 통과했습니다. 합성 Claude 화면과 입력 어댑터로 검증했으며, 실제 사용자 터미널에 시험 메시지를 넣거나 진행 중인 CLI를 재시작하지 않았습니다. 상세 결과는 [VALIDATION.md](../../VALIDATION.md)에 기록합니다.
