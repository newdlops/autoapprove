# 0.2.266 · 백그라운드 Terminal 입력 준비

- 원격 입력을 받으면 실행 중인 Terminal을 먼저 활성화하고, 대상 창을 복원해 앞으로 가져옵니다. 백그라운드 창 조회가 시간 초과되어 활성화하지 못하는 경로를 개선했습니다.
- 창 전환 직후에는 정확한 대상의 포커스가 준비될 때까지 최대 0.5초 기다립니다. 이미 포커스된 입력은 기존 빠른 경로를 사용합니다.
- 원래 프로세스·TTY·창·선택 탭·권한을 입력 직전에 다시 확인합니다. 포커스를 얻지 못하거나 다른 곳으로 옮겨지면 입력을 중단합니다.
- 손쉬운 사용 기반 입력을 유지하며 root 입력 서비스를 사용하지 않습니다. 실제 상대 Mac의 입력 지연은 배포 후 별도 측정이 필요합니다.
