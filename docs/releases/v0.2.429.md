# AutoApprove 0.2.429 · 빌드 456

그룹장은 `get_group_status(view: "overview")`에서 구성원의 상태와 대기 건수를 보고, `get_group_messages`에 `mailboxMemberID`와 `deliveryOrder: true`를 지정해 실제 전달 순서와 보류 사유를 확인할 수 있습니다. 첫 메시지가 보류된 경우 다음 시도 예정 시각도 표시합니다.

담당 그룹장은 `manage_group_inbox`로 미전달 일반 메시지의 본문을 수정하거나 전달을 취소할 수 있습니다. `messageIDs`로 최대 32개를 한 번에 취소하거나 삭제할 수 있습니다. 한 건이라도 처리할 수 없으면 전체를 보류합니다. 삭제하면 구성원의 수신함에서 사라지며 발신함에는 기록이 남습니다. 그룹장이 편집한 본문은 받는 터미널에도 편집 사실을 표시합니다.

`move`에 `beforeMessageID`를 지정하면 해당 메시지 앞으로 이동합니다. 생략하면 같은 우선순위의 끝으로 보냅니다. 막힌 메시지를 뒤로 보내거나 취소하면 전달기가 다음 항목을 다시 확인합니다. 수신자가 입력을 받을 수 있게 된 뒤에는 `retry`로 보류된 첫 메시지를 다시 시도할 수 있습니다.

자동 승인에서 명령을 거절하는 기준도 변경했습니다. 셸의 파일·디렉터리 삭제 명령, 파일 삭제 도구, 삭제 패치가 확인되면 원본을 보존하도록 안내합니다. 보안·접근 권한, 관리자 권한, 시스템 설정·자동 실행 변경은 원래 승인창에서 사용자가 결정합니다. 그룹 수신함에서 메시지를 삭제하는 작업은 파일 삭제와 구분합니다.
