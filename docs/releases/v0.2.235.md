# 0.2.235 · 계정 전환 뒤 중단 작업 이어가기

로그인 변경으로 작업을 중단한 뒤, 새 계정·서버와 기존 창·대화의 연결이 확인되면 해당 작업을 자동으로 이어갑니다. 활성 Goal은 같은 목표·예산·사용량을 유지해 재개하고 일반 작업은 같은 대화에 이어가기 요청을 한 번 보냅니다. 원래 대기 중이던 대화나 일시정지한 Goal은 실행하지 않으며, 터미널의 작성 중인 초안과 원래 모델·폴더를 유지합니다.

서버 재시작 중 연결이 잠깐 사라져도 재연결 확인 시간을 기다립니다. 이미 보낸 재시작의 결과는 새 계정·서버·원래 연결 증거로 다시 확인할 수 있으며 같은 재시작을 반복하지 않습니다. 사라진 서버의 실행·전환 기록 없는 지원 오류는 정리합니다.

재개 직전 계정·서버·원래 차례·Goal·대기 입력을 다시 확인합니다. 작업이나 목표가 바뀌었으면 해당 대화를 유지하고, 전달 결과가 불명확하면 같은 요청을 반복하지 않습니다. 진행 화면의 **나머지 이어가기 중지**로 이후 재개를 멈출 수 있습니다. 이전 버전에서 이미 중단·취소된 기록에는 자동 재개 권한을 새로 부여하지 않으며, 이번 버전에서 시작한 전환부터 적용합니다.

중단 요청과 자연 완료가 겹친 일반 작업은 다시 실행하지 않습니다. 마지막 차례가 실제 중단된 상태인지 재확인한 뒤 이어가며, 화면 밖 대화를 불러오는 경우도 같은 조건을 적용합니다.
