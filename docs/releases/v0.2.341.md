# AutoApprove 0.2.341 · 빌드 368

- 에이전트가 다른 Mac 앱을 조작할 때 사용자가 쓰는 앱, 키보드 포커스와 마우스가 바뀌지 않도록 백그라운드 조작 MCP 도구(`desktop_list_apps`, `desktop_open_app`, `desktop_snapshot`, `desktop_screenshot`, `desktop_press`, `desktop_set_value`, `desktop_type`, `desktop_key`)를 추가했습니다.
- 버튼을 누르거나 값을 지정할 때는 손쉬운 사용 API를 쓰고, 글자와 키는 대상 앱 프로세스에만 보냅니다. 화면은 대상 창 하나만 캡처하므로 다른 창에 가려져 있어도 확인할 수 있습니다. 조작한 앱이 스스로 앞으로 나오면 바로 이전 앱을 다시 앞으로 가져오고, 그 사실을 도구 결과에 적습니다.
- 메뉴 실행, ⌘ 단축키, 좌표 클릭은 백그라운드 앱에서 동작하지 않으므로 도구로 제공하지 않습니다. 터미널, 개발 도구, 보안 앱, 에이전트 앱은 조작하지 않고, 비밀번호 입력란에는 입력하지 않습니다.
- Claude Code의 computer use가 클릭, 입력, 앱 실행처럼 포커스를 가져가는 호출을 하면 훅이 그 호출을 거부하고 백그라운드 도구를 쓰라고 안내합니다. 스크린숏 같은 확인 동작은 그대로 허용합니다. 이 거부 기능은 `autoapprove desktop-guard off`로 끌 수 있습니다.
- 앱 차단 목록, 키 이름 변환, computer use 동작 분류는 특정 에이전트에 묶이지 않은 모듈로 분리했습니다. 그래서 Codex에서도 같은 도구와 규칙을 쓸 수 있습니다.
