# 0.2.278 · 오류 상태 부모의 서브에이전트 현황 갱신

- 오류로 중단된 부모 대화도 연결할 수 있도록 수정했습니다. 이전에는 정상 작업·대기 상태의 부모만 목록에 포함해 ‘부모 대화를 다시 선택’ 오류가 발생했습니다.
- 상태 조회와 승인 가능 여부를 분리했습니다. 부모가 오류 상태일 때도 읽은 자식 현황을 유지하며, 이 경로에서 승인 응답은 보내지 않습니다.
- 마지막 갱신 시각을 표시합니다. 자동 관측이 회복되면 수동 조회 때의 이전 오류 문구도 지웁니다.
- 화면을 처음 열 때 서버 연결에 실패하면 3초 간격으로 관측 연결을 다시 확인합니다. 연결 후에는 기존 엔진의 감시 작업이 갱신을 맡습니다.

검증: DEBUG 빌드와 격리된 소켓 통합 검사. 오류 부모 연결·자식 상태 유지·수동 조회·자동 관측, 승인 범위와 중복 응답 방지, 불명확한 응답의 재실행 방지를 확인했습니다. 실제 SwiftUI 시험 화면(1040×700pt)에서 오류 부모의 수동 갱신, 자식 대기→작업 중 자동 변경, 조회 실패와 자동 회복 후 오류 문구 해제를 확인했습니다. 이 검증은 합성 세션을 사용하며 실제 사용자 작업을 실행하지 않았습니다.

로그인 그룹 간 기존 대화 이동과 자식 Goal 일시정지 기능은 계속 구현 중입니다.
