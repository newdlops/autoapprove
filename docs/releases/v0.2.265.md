# 0.2.265 · 연속 입력의 요청 대기 감소

- 원본 터미널의 이전 입력 응답을 기다리는 동안 연속 문자를 한 요청으로 묶습니다. 여러 글자의 창·신원 검사 요청이 한 글자씩 대기열에 쌓이는 현상을 줄입니다. 특수 키의 순서와 입력 직전 안전 검사는 유지합니다.
- 지연 표시는 브라우저 대기를 포함한 실제 입력 응답으로 계산합니다. 연결 확인용 ping이 낮은 수치로 입력 지연을 덮어쓰지 않습니다.
- 처리 지연 400ms를 넣은 생산 코드 모의 검사에서 72자 입력의 중앙값은 3400ms에서 800ms로 감소했습니다. 이는 실제 Mac 측정값이 아니며 환경과 키 조합에 따라 다릅니다.
- 연결 끊김·대상 전환·Unicode·키 순서·미전송 초안 보존·중복 전송 방지 회귀 검사를 통과했습니다. PTY와 화면 공유의 기존 전송 창은 유지합니다.
