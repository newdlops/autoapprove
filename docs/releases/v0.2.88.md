# AutoApprove 0.2.88

백그라운드 Terminal 감시에서 매번 `osascript`를 실행하는 대신 앱 안에서 Apple Events로 원본 TTY를 직접 읽습니다. 스크립트 실행·JSON 변환 비용을 줄이고 제목은 창 메타데이터를 모아서 확인합니다.

동일 원본을 이전 버전과 번갈아 읽은 비교에서 조회 작업과 자식 프로세스의 총 CPU 시간이 20개 원본 기준 약 84%, 단일 원본 기준 약 98% 감소했습니다. 앱 전체나 Mac 전체의 CPU 감소율을 뜻하지 않습니다.

감지 주기와 입력 전 원본·최신 화면 검증은 유지합니다. 권한 거절은 중단하고, 백그라운드 네이티브 읽기는 동의 창을 띄우지 않습니다. 첫 연결의 기존 동의 절차와 미지원 환경의 호환 경로를 유지하며, 커서가 필요한 웹 화면은 기존 읽기를 사용합니다. 별도 서비스나 새 권한은 추가하지 않습니다.
