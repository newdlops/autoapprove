# AutoApprove 0.2.360 · 빌드 387

복원된 Terminal 또는 iTerm2의 원래 그룹장 탭에서 `get_session_groups`를 호출해 자신의 구성원과 `canReconnect`를 확인하고 `reconnect_group_member`로 연결을 갱신할 수 있습니다. 그룹장과 구성원 ID는 유지됩니다.

Antigravity 훅은 세션 자동 승인이 켜져 있으면 작업 폴더 안의 파일 읽기와 디렉터리 목록 조회, 정확한 `/bin/pwd` 요청에 공식 `auto_approve` 결정을 반환합니다.

대화 그래프의 Antigravity 노드와 범례를 초록색으로 표시합니다. Codex는 파랑, Claude Code는 보라입니다.
