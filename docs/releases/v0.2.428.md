# AutoApprove 0.2.428 · 빌드 455

Codex 그룹장과 일반 구성원의 서브에이전트는 `get_session_groups`를 인자 없이 호출해 원래 구성원의 그룹과 역할을 확인할 수 있습니다. 같은 그룹의 구성원에게 일반 메시지·질문·회신을 보내고, 원래 구성원의 수신함과 발신함을 읽을 수 있습니다. 메시지는 원래 구성원 명의로 기록됩니다.

그룹장이 생성한 서브에이전트는 해당 그룹의 구성원 터미널을 조회하고 직속 구성원에게 작업을 배정할 수도 있습니다. 승인 응답, 세션 초기화, 그룹 연결 변경은 해당 권한을 가진 구성원 본인이 실행합니다.

AutoApprove는 호출별 대화 ID와 같은 계정에 저장된 활성 부모·자식 관계를 확인합니다. 여러 단계로 생성한 서브에이전트에도 같은 규칙을 적용합니다.
