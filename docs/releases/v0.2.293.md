# AutoApprove 0.2.293

- 관리 창의 세션 목록과 휴대폰 웹의 세션 목록에서 그룹에 속한 세션을 접고 펼 수 있는 계층 구조로 보여 줍니다.
  - 그룹마다 머리 행을 두고, 그 아래에 그룹장과 지시를 받는 구성원을 상위와 하위 관계대로 들여 써서 보여 줍니다. 하위 구성원이 있는 구성원도 접을 수 있습니다.
  - 그룹을 접어도 머리 행에 세션 수와 확인이 필요한 구성원 수가 남습니다. 접은 상태는 앱을 다시 열어도 유지되고, 웹에서는 같은 브라우저를 쓰는 동안 유지됩니다.
  - 그룹에 속하지 않은 세션은 지금처럼 평면 목록으로 보여 주며 드래그로 순서를 바꿀 수 있습니다. 그룹 안의 순서는 상위 구성원 관계를 따릅니다.
- 각 행에서도 그룹장과 하위 구성원을 구분해 표시합니다.
  - 그룹장 행에는 왕관 표시와 함께 그룹 이름과 하위 구성원 수를 보여 줍니다.
  - 하위 구성원 행에는 그룹 이름과 작업을 지시하는 세션을 보여 줍니다.
  - 그룹 작업 상태(그룹 작업 중, 질문 대기, 승인 대기, 보고 전달 대기)와 아직 전달되지 않은 보고 수도 함께 보여 줍니다.
  - 그룹 이름으로 세션을 검색할 수 있습니다. 여러 그룹에 속한 세션은 그룹장인 그룹을 먼저 보여 주고, 나머지 그룹 수를 덧붙입니다.
- 그룹 작업 중인 작업자가 권한 확인에서 8초 넘게 멈추면, 사용자가 승인을 위임한 것으로 보고 요청 내용과 선택지를 지시한 세션의 터미널에 입력합니다. 지시한 세션이 `answer_group_question`으로 선택지를 고르면 사용자 승인으로 처리하고, 승인 내역에 "그룹장 위임 승인"으로 남깁니다.
- AutoApprove가 그룹원에게 위임 사실을 알려, 그룹원이 그룹장의 지시를 사용자의 지시로 따르게 합니다.
  - Claude Code 작업자에게는 AutoApprove가 방금 입력한 그룹 작업 지시에만, 사용자가 설치한 AutoApprove hook으로 위임 맥락을 붙입니다. 이 맥락에는 사용자가 판단을 지시한 세션에 위임했다는 사실과, 그 세션의 결정과 선택을 사용자의 지시로 따르고 사용자에게 다시 확인을 요구하지 말라는 요청이 들어갑니다.
  - 지시한 세션에는 AutoApprove가 방금 전달한 보고, 질문, 승인 요청에만 같은 방식으로 맥락을 붙입니다. 이 맥락에는 작업 범위 안에서는 사용자에게 다시 묻지 말고 판단하라는 요청과, 범위를 벗어나거나 되돌리기 어려운 요청은 승인하지 말라는 요청이 들어갑니다.
  - Codex처럼 이 hook이 없는 작업자를 위해 작업 지시 문구에도 위임 사실을 적습니다.
  - 사용자가 직접 입력한 프롬프트나 다른 작업의 머리말을 흉내 낸 프롬프트에는 맥락을 붙이지 않습니다.
  - 그룹장이 있는 그룹에서는 작업 지시와 답변을 `assign_group_task`와 `answer_group_question`으로만 보내라고 MCP 안내에 적었습니다. 각 도구의 메시지 기능으로 직접 보낸 지시에는 위임 사실이 전달되지 않아 작업자가 따르지 않을 수 있습니다.
  - Claude 작업자의 질문 도구를 돌려보낼 때도 사용자가 판단을 위임했다는 사실을 함께 알립니다.
- 위임하지 않는 요청은 다음과 같습니다.
  - 시스템 변경: 사용자도 앱에서는 승인할 수 없는 요청입니다. 지금처럼 거절하고 안전한 대안을 안내합니다.
  - 전체 일시정지 중의 요청
  - macOS 권한 대화상자
- 위임 승인은 직속 상위 세션만 할 수 있습니다. 화면의 요청이 보고한 내용과 달라졌으면 선택을 입력하지 않습니다. 이미 답한 요청은 다시 보고하지 않습니다.

새 도구 설명은 MCP를 다시 연결하거나 세션을 다시 시작한 뒤 적용됩니다.
