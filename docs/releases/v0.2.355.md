# AutoApprove 0.2.355 · 빌드 382

- 세션 다시 시작을 요청하면 선택한 CLI의 현재 작업이 끝나기를 기다리지 않고 종료한 뒤 원래 탭에서 같은 대화를 엽니다. 종료 전에 대화와 프로세스, 돌아갈 셸을 확인합니다.
- 직접 요청한 Codex 로그인·재연결은 대상 로그인 서버의 실행 중인 대화들에 중단 요청을 보내고 함께 결과를 확인합니다. 중단 상태나 대기 입력을 확인할 수 없으면 서버 전환을 보류합니다.
- 수신이 확인되지 않은 그룹 메시지는 발송 후 기본 120분에 만료됩니다. 재전달과 미확인 집계에서 빠지고 원문과 메시지 ID는 기록에 남습니다. 연결 설정의 그룹 메시지 항목에서 1~10,080분으로 변경할 수 있습니다.
