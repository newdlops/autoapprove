# 0.2.132 · 반복 감시와 화면 갱신 경량화

여러 Claude Code·Codex 세션을 켜 둔 동안 반복되는 기록 조회, 프로세스 판별, 터미널 문자열 분석과 화면 갱신 비용을 줄였습니다.

- Codex 기록은 인덱스 기반 변경분 조회와 SQLite 연결·statement 재사용으로 처리합니다. 기록 교체·과거 행 수정·질문 제거도 다시 확인합니다.
- 프로세스 발견과 원본 확인은 필요한 메타데이터와 PID를 읽고, 일반 프로세스의 에이전트 판별에서 불필요한 경로 변환을 줄입니다.
- 같은 터미널 화면의 반복 분석과 UTF-8 크기 계산을 줄이고 스트림의 JSONEncoder를 연결 안에서 재사용합니다.
- 감시 대상이 없을 때 반복 타이머 대신 변경 신호를 기다립니다. 세션·승인 내역 창은 사용하는 상태만 갱신하고, 연결 설정의 화면용 10초 타이머를 제거합니다.
- 웹의 긴 ASCII 입력 크기 검사에서 추가 인코딩을 줄였습니다. Unicode 처리와 입력 크기 제한은 유지합니다.

원본 PID·시작 시각·TTY와 입력 직전의 현재 상태 검증, 전송 결과가 불명확할 때의 중복 입력 방지는 유지합니다. 새 상주 서비스나 시스템 자동 실행 항목을 등록하지 않습니다.

검증: Release Core 357/357, 실제 제품 창을 사용한 합성 데이터 변경 전후 3쌍 비교, 패키지 웹·MCP·PTY, 입력 보조 프로그램 메타데이터, 기존 발행자 서명 호환과 DMG 무결성 검사를 통과했습니다. 합성 벤치마크를 설치 앱 전체 CPU나 실물 휴대폰의 지연 개선율로 해석하지 않습니다.

macOS 14 이상 Apple Silicon용이며 빌드는 159입니다. 기존 발행자 인증서를 재사용했습니다. Developer ID 서명·Apple 공증은 포함하지 않으며 기존 macOS·회사 관리 정책은 적용됩니다. 설치 방법은 [설치 안내](../../README.md#설치)를 참고하세요.
