# 0.2.143 · 반복 세션 검색 경량화

실행 중인 CLI의 조상 프로세스를 확인할 때 tmux 판별용 파일 URL을 매번 만들던 비용을 줄였습니다. 일반 실행 경로는 문자열의 마지막 이름으로 판별합니다. 빈 경로·점 경로·물결표 이름·NUL이 들어간 경로에는 기존 Foundation 처리를 유지합니다. tmux 서버의 실행 식별자·소켓 소유자·대상 pane 검증과 원본 터미널 입력 검사는 유지합니다.

실제 Release Core에 합성 프로세스 목록과 32개 세션을 넣고 이전/수정 실행 파일을 3쌍 교대 측정했습니다. 각 400회 검색의 CPU 중앙값은 Terminal만 있는 경우 **0.491→0.164초**, 여러 터미널이 섞인 경우 **0.524→0.255초**, Cocoa 문자열을 쓰는 혼합 경우 **0.489→0.312초**였습니다. 각 종류·버전당 9개 표본이며 세션 표시 결과 96개가 일치했습니다. 프로세스 목록을 읽은 뒤 세션을 분류하는 구간의 결과이며, 앱 전체 CPU·메모리나 휴대폰 연결 지연의 개선율로 해석하지 않습니다.

전체 Release **368/368**과 실제 수정 Core의 경로 비교 **5,112건**이 통과했습니다. 비교에는 Cocoa 문자열 988건·Unicode·특수 경로가 포함되며, tmux 서버와 바깥쪽 Terminal의 구별 및 서버 식별자가 맞지 않을 때 원본 탭으로 연결하지 않는 회귀를 확인했습니다. 버전 리소스 복사 뒤에도 측정한 Core와 검사 실행 파일의 동일성을 확인했습니다.

서명 패키지의 자동 응답 12건·명시적인 웹 답변을 기다리는 수동 질문 12건, 일시정지·재시작·응답 유실·중복 방지·격리 웹/MCP/PTY·입력 구성요소와 DMG 검사가 통과했습니다. App/CLI 각 38개 코드 section 및 웹 리소스 13개가 최종 빌드/소스와 일치합니다. 사용자 터미널에 시험 입력을 보내지 않았습니다.

macOS 14 이상 Apple Silicon용이며 빌드는 170입니다. 기존 발행자 인증서를 재사용합니다. 설치 방법은 [설치 안내](../../README.md#설치)를 참고하세요. 웹 화면 구성은 0.2.142의 기록 정리 기능을 유지합니다.
