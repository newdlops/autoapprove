# AutoApprove 0.2.243

macOS 로그인 셸의 `-zsh`, `-bash` 등 이름을 원본 셸로 인식하지 못해 기존 세션이 계속 연결 대기하던 경로를 수정했습니다. 실제 앱 소유 로그인 셸에서 같은 대화의 재연결을 검증합니다.

- ‘현재 로그인으로 세션 재연결’이 독립 실행 중인 기존 세션의 연결을 먼저 진행합니다. 종료·재실행 결과를 확인한 뒤 계정 확인으로 넘어가며, 서버만 실행 중인 경우에도 버튼을 사용할 수 있습니다. 이전 자동 준비 실패 후 수동 요청으로 서버 상태를 다시 읽을 수 있습니다.
- 재연결 요청 후 목록을 새로 읽습니다. ‘연결 다시 확인’은 연결 상태 조회, ‘현재 로그인 확인’은 연결된 서버의 계정 확인 역할을 유지합니다.
- 대기 사유를 프로젝트·터미널별로 표시합니다. 화면 연결이 꺼진 상태를 작업 중으로 표시하지 않으며 작업·질문·초안·Goal은 유지하고 대기합니다.

[검증 기록](../../VALIDATION.md). 다른 Mac의 실제 기존 세션 성공은 직접 확인하지 못했습니다. Apple Silicon·macOS 14 이상 대상입니다.
