# 0.2.272 · 공용 컴퓨터용 네트워크 격리

- 연결 설정에 **네트워크 격리** 스위치를 추가했습니다. 켜면 웹 서버를 열지 않고, 실행 중이던 서버도 중지합니다. 같은 네트워크 탐색과 광고, 다른 Mac 연결, 휴대폰 접속, LAN 업데이트, 외부 터널도 모두 중단합니다. 격리 중에는 웹 서버와 터널을 켤 수 없습니다.
- 새로 설치한 앱은 격리를 켠 상태로 시작합니다. 이미 웹 접속을 설정해 둔 설치는 저장된 설정을 그대로 유지합니다.
- 격리를 끌 때는 같은 네트워크의 누구나 로그인 없이 터미널과 자동 승인을 제어할 수 있다는 경고를 확인해야 합니다. 개인용 컴퓨터에서만 끄세요.
- 격리를 끄면 저장해 둔 웹 설정대로 서버를 다시 엽니다. 격리 때 중지한 외부 터널은 직접 다시 켜야 합니다.
- 명령줄에서는 `autoapprove isolate on|off`로 바꾸고 `autoapprove isolate`로 현재 상태를 확인합니다. 이 명령은 경고 없이 바로 적용합니다.
