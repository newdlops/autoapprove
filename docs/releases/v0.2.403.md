# AutoApprove 0.2.403 · 빌드 430

그룹장은 직속 Codex, Claude Code, Antigravity 구성원의 Goal을 설정하고, 사용자가 직접 설정한 Goal도 수정·중지·해제할 수 있습니다.

- `get_group_member_goal` 응답의 `threadID`와 `goalRevision`을 `manage_group_member_goal`에 전달합니다. `set`과 `objective`로 목표를 설정하거나 교체합니다. `stop` 또는 `pause`로 중지하고 `resume`으로 재개합니다. `clear` 또는 `delete`는 목표를 해제합니다.
- Codex는 연결된 원래 대화의 Goal API를 사용합니다. 기존 Goal을 편집할 때 식별자와 토큰 예산을 확인합니다. 일시정지는 다음 Goal 실행부터 적용되며 실행 중인 턴은 계속될 수 있습니다.
- Claude Code는 원래 터미널의 `/goal` 명령과 해당 대화의 Goal 기록을 사용합니다. Antigravity는 `/goal`로 설정하고 취소 메시지로 중지합니다. 두 CLI의 중지는 네이티브 목표를 해제하며 재개 시 목표를 다시 설정합니다. 저장된 목표 문구가 없으면 재개에 `objective`를 지정합니다.
- `source=unobserved`는 CLI의 실제 Goal 상태를 읽지 못했다는 뜻입니다. 이때도 `set`, `stop`, `clear`를 요청할 수 있습니다. `lastRequest.delivery=submitted`는 터미널에 전달한 단계이고 `confirmed`는 대화 기록에서 적용까지 확인한 단계입니다.
