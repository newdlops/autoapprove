# 0.2.170 · 빌드 197

원본 터미널 연결과 미리보기에서 한 프로세스의 식별자를 확인할 때, 전체 프로세스 목록 대신 해당 PID의 최신 정보를 읽습니다. 연결 전·권한 확인 후·원본 탭 표시 후의 세 검증과 새 이미지·캐시 이미지의 전후 검증은 그대로 유지합니다. PID·시작 시각·TTY·CLI 종류·foreground가 바뀌면 연결을 거부합니다. 식별자 캐시는 추가하지 않았으며 기존 주입 reader와 읽기 전용 fallback도 유지합니다.

반복 세션 탐색은 CLI 후보와 부모 사슬의 원래 인덱스를 모아 필요한 항목만 상세 처리합니다. 원래 순서,60단계 상한, 공유 부모 중복 제거와 중복 PID의 기존 동작을 유지합니다. 전체 목록이 필요한 다른 경로에는 완전한 reader를 계속 제공합니다.

같은 실제 Core에 소유 비활성 PTY 한 개를 연결하고, 텍스트·이미지·권한·탭 표시 콜백을 합성한 비교입니다. 새16프로세스·8쌍을 AB/BA 순서로 실행했습니다. 네트워크·실물 휴대폰·원본 Terminal 앱·VPN/보안 도구의 같은 개선율을 뜻하지 않습니다.
