# AutoApprove 0.2.184 · build 211

연결된 세션에서 ‘상태 미확인’이 반복되는 화면 판독 누락을 수정했습니다.

- Claude의 프로젝트·브랜치·모델·사용량 상태줄이 있는 입력창을 인식합니다.
- Codex의 경고 안내가 하단에 있어도 빈 입력창과 작성 중인 초안을 구분합니다.
- Codex의 서버 응답 대기 대화상자는 ‘작업 중’으로 표시합니다. 해당 메뉴에 자동
  입력을 보내지 않습니다.
- 실제 읽기 실패·연결 해제·질문 메뉴·불명확한 화면의 처리는 유지합니다. 기존
  입력 대기 2초 확인·원본 식별·입력 중복 방지·실시간 전송 경로도 유지합니다.

실제 미확인 화면 7개를 같은 입력으로 비교해 7개 모두 작업 중·대기·초안으로
구분했습니다. 합성 화면을 실제 엔진과 Chromium/WebKit에 연결해 표시와 읽기
실패/복구를 검사했습니다. 사용자 원본 CLI에는 입력하지 않았습니다.
