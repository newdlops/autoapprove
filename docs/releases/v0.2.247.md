# AutoApprove 0.2.247

실행 중인 Goal에서 ‘현재 로그인으로 세션 재연결’을 눌렀을 때 중단 입력이 실제 전송기에서 거절되던 원본 TTY 신원 누락을 수정했습니다. 원래 Codex의 커널 신원을 고정해 전달하고, 전송기가 실행·UID·장치·전경 프로세스 그룹을 다시 확인합니다.

Goal 일시정지·실제 대기 확인·같은 대화의 서버 연결·새 계정 확인 후 단일 재개 순서는 유지합니다. 직접 입력 도우미가 없으면 손쉬운 사용 권한으로 원래 창·탭·Codex 프로세스를 검증한 뒤 Esc를 보냅니다. 작업 표시의 시간·스피너 변화는 허용하고, 초안·질문·실제 출력 변화는 유지합니다. 권한도 없으면 macOS 승인 안내를 표시하고, 승인 후 같은 버튼으로 다시 시도할 수 있습니다. 0.2.246의 확실한 미전송 기록도 복구합니다. 응답 유실·부분 전송·이미 관찰한 중단은 재전송하지 않습니다.

직접 입력의 실제 검증기, 키보드의 실제 창·프로세스 검증기와 커널 신원 캡처를 거치는 시험을 추가했습니다. 생성된 창 확인 스크립트도 실행했습니다. 시험에서는 창 메타데이터와 마지막 전송을 소유 PTY로 대체했습니다. 실제 macOS 권한 창·도우미·TIOCSTI·다른 Mac의 사용자 Terminal 성공을 직접 검증한 것은 아닙니다. [검증 기록](../../VALIDATION.md).
