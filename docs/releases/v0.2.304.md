- 에이전트용 `reconnect_group_member`를 추가했습니다. 저장된 원래 프로세스와 터미널을 확인하고, 필요하면 `/status`로 현재 대화 ID를 읽어 그룹에 반영합니다. Codex는 작업 중에도 조회하되 작성 중인 입력·질문·승인과 충돌하면 보류합니다.
- 앱 재시작 후 대화 ID를 확인하지 못해도 원래 프로세스가 일치하면 그룹 조회에 복구 대상으로 표시합니다. `canReconnect`로 자신·직속 구성원 또는 그룹장이 없는 그룹의 같은 도구 구성원을 복구할 수 있습니다. 메시지·작업·보고 수신에는 기존의 확인된 대화 식별 조건을 유지합니다.
- 그룹장이 없는 그룹의 같은 도구 간 양방향 메시지에 `send_group_message`를 제공합니다. 기존 작업 지시·질문 답변·완료 보고와 동일하게 원래 로컬 터미널로 전달하며 외부 서버나 메시지 큐로 우회하지 않습니다.
- 네트워크 격리 중에도 그룹 저장·조회·재연결·전달이 동작합니다. 인터넷·LAN·웹 서버·Cloudflare는 그룹 기능의 의존성이 아닙니다. Codex·Claude 모델 자체의 응답 생성에 필요한 네트워크와는 별개입니다.
- 기존 Claude 발견·작업 전달·자동 승인 규칙은 유지합니다. 종료된 터미널이나 같은 프로젝트의 다른 세션을 추측해서 재연결하지 않습니다.
