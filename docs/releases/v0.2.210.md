# AutoApprove 0.2.210 · build 237

**릴리스 후보 · 배포와 설치 보류:** 기존 게시자 키를 사용하는 제한 모드 패키징에서 `codesign: no identity found`가 발생했습니다. 키체인 잠금·검색 목록·접근 정책은 변경하지 않았습니다. 서명된 DMG/업데이트 ZIP·체크섬, 태그와 GitHub 릴리스 게시, 공개 다운로드 검증, 로컬 설치와 실행 버전 확인이 남아 있습니다. 현재 설치본에 수정이 적용됐다고 표시하지 않습니다.

Mac 기본 Terminal의 탭 그룹이 복원 때 모두 개별 창으로 나뉘는 문제를 수정합니다. Terminal의 자동화 API는 macOS 기본 탭 그룹에 속한 탭도 각기 다른 창 ID로 보고할 수 있습니다. 이전 코드는 이 ID를 그대로 그룹으로 저장했고, 새 탭 확인도 같은 ID만 허용했습니다. [AppKit의 기본 탭 그룹](https://developer.apple.com/documentation/appkit/nswindowtabgroup)은 여러 창을 하나의 탭 묶음으로 표시합니다.

- **현재 창 저장:** 실제 macOS 접근성 탭 막대와 탭 객체로 그룹·순서·선택 상태를 확인합니다. 같은 제목의 탭도 이름이나 화면 좌표로 추측하지 않습니다. 확인하는 동안 대상 Terminal 탭을 잠시 선택하고 원래 선택과 전면 앱으로 돌아옵니다. 손쉬운 사용 권한이 필요하며, 창 구성이나 초점이 바뀌면 확인되지 않은 구성을 저장하지 않습니다.
- **그룹 복원:** 새 탭이 별도 창 ID를 받아도 원래 TTY와 동일한 실제 탭 막대에 속하는지 확인합니다. 새 TTY·원래 프로세스·선택 창·빈 셸을 확인한 뒤에만 CLI 명령을 전달합니다. 탭 확인 실패와 결과 미확인 시 후속 탭을 중단하며 개별 창으로 우회하거나 명령을 재전송하지 않습니다.
- **선택 탭:** 저장한 탭의 내부 선택뿐 아니라 해당 네이티브 창을 앞으로 가져와 실제 표시도 바꿉니다. 기존 프로필 화면·파일 형식과 iTerm2 복원 방식은 유지합니다.

**기존 프로필은 갱신이 필요합니다.** 탭 그룹 정보가 이미 개별 창으로 저장된 파일에서는 원래 묶음을 추론할 수 없습니다. Terminal을 원하는 탭 그룹으로 묶은 상태에서 **세션 프로필 → 프로필 관리 → 현재 창으로 갱신**을 선택해 저장해주세요. 기존 파일을 자동으로 덮어쓰지 않습니다.

배포·설치와 검사 결과는 [검증 기록](../../VALIDATION.md)에 기록합니다. 실제 사용자 Terminal 직접 접근은 컴퓨터 조작 도구의 안전 정책으로 제한되며, 격리된 실제 AppKit 탭 창과 합성 Terminal 계약 검사를 구분합니다.
