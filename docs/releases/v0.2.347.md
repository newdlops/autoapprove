# AutoApprove 0.2.347 · 빌드 374

- 백그라운드 셸 작업(개발 서버, 반복 확인 명령 등)을 실행 중인 Claude 구성원에게도 그룹 메시지와 작업 지시를 입력합니다. Claude 는 이 상태를 `shell` 로 기록하는데, 이전에는 이 값을 작업 중으로 판단해 백그라운드 작업이 끝날 때까지 메시지를 입력하지 않았습니다. 백그라운드 작업이 며칠씩 이어지면 메시지도 그동안 전달되지 않았습니다.
- 이런 구성원이 지시받은 작업을 마치면, 이제 AutoApprove 가 완료를 감지해 작업을 지시한 구성원에게 보고합니다. 이전에는 완료를 감지하지 못했습니다.
- 대화 그래프와 구성원 목록에서 이 구성원을 "상태 미확인" 대신 "대기 중"으로 표시합니다.
