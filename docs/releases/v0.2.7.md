# AutoApprove 0.2.7

macOS Terminal과 VS Code 통합 터미널에서 실행 중인 Claude Code·Codex를 관리하는 첫 GitHub DMG 배포입니다.

## 주요 기능

- Claude Code·Codex 세션 탐색, 작업·대기 상태, 프로젝트명과 터미널 제목 표시
- 세션별 자동 승인, 전체 일시정지, 저장되는 승인 내역과 요청·답변 상세 펼치기
- 자동 처리할 수 없는 질문 알림, 알림 클릭 시 해당 터미널로 이동·강조
- Codex 질문 대기열 수집, 앱에서 여러 선택지 선택·직접 입력 후 답변 보내기
- 앱에서 처리할 수 없는 질문의 **터미널에서 답하기**

## 설치

**macOS 14 이상 · Apple Silicon(arm64)**용입니다. Intel Mac용 빌드는 포함하지 않습니다.

1. 아래 `AutoApprove-0.2.7-macOS-arm64.dmg`를 다운로드합니다.
2. 기존 AutoApprove가 실행 중이면 종료하고, DMG의 **AutoApprove.app**을 **Applications**로 드래그합니다.
3. DMG를 추출하고 응용 프로그램 폴더에서 앱을 엽니다.
4. **연결 설정**에서 Terminal·VS Code를 연결하고 알림을 허용합니다. 자동 승인은 원하는 세션에서 켭니다.

VS Code 확장 0.2.3은 앱에 포함되어 있습니다. Claude Code·Codex는 별도로 설치해야 합니다. 기존 설정과 승인 내역은 유지됩니다.

이 배포본은 **ad-hoc 서명**이며 **Developer ID 서명·Apple 공증을 받지 않았습니다**. 개발자 확인 경고가 나타나면 출처를 확인한 뒤 [Apple의 실행 허용 안내](https://support.apple.com/ko-kr/102445)를 따라주세요.

## 지원 범위

- Terminal은 macOS 자동화 권한이 필요합니다. VS Code는 확장 연결 후 시작한 명령부터 출력 감지가 가능합니다.
- Codex 질문 수집·응답은 **Codex 0.155.1**에서 검증했습니다. 로컬 이력 형식과 `codex queue` 지원에 의존합니다.
- **전달 대기**는 Codex 메시지 큐에 접수됐다는 뜻입니다. 실행 중인 작업이 이미 답변을 받았다는 뜻은 아닙니다.
- 질문 이력에 명시적인 미응답 상태가 없어 오래된 질문이 남을 수 있습니다. 처리한 항목은 **목록에서 정리**할 수 있습니다.
- SSH, Dev Containers, WSL과 임의의 사용자 정의 승인 화면은 지원하지 않습니다.

## 검증 및 무결성

핵심 검사 43개와 훅·소켓·PTY 통합 검사, 격리된 Codex 큐 전송 검증을 통과했습니다. DMG 이미지와 마운트한 앱의 코드 서명을 검증했습니다. 실제 사용자 터미널에 시험 응답을 보내지 않았으며 실환경 전체 승인 흐름을 검증한 것은 아닙니다. 자세한 범위는 [검증 기록](https://github.com/newdlops/autoapprove/blob/v0.2.7/VALIDATION.md)을 참고하세요.

함께 제공하는 `.dmg.sha256` 파일을 같은 폴더에 다운로드한 뒤 확인할 수 있습니다.

```sh
shasum -a 256 -c AutoApprove-0.2.7-macOS-arm64.dmg.sha256
```
