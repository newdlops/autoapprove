# AutoApprove 0.2.342 · 빌드 369

- 그룹 대기의 기한이 지난 뒤 작업 결과나 답변이 도착하면, 기다리던 구성원에게 결과 본문을 담은 알림을 한 번 보냅니다. 이전에는 기한 만료 알림만 보냈고, 나중에 도착한 결과는 알리지 않았습니다.
- 그룹 수신함의 모든 메시지를 본문과 함께 받는 구성원의 터미널에 입력합니다. 요약 보고와 선택지 질문도 본문이 바로 입력되므로, 받는 구성원이 수신함을 조회하거나 수신 확인을 호출하지 않아도 됩니다. 프롬프트에는 답할 때 필요한 그룹 ID와 보낸 구성원 ID가 들어 있습니다.
- 입력한 메시지가 받는 구성원의 대화에 들어간 것을 확인하면 전달 완료로 기록합니다. Claude는 프롬프트 제출 훅이나 대화 기록으로, Codex는 대화 기록으로 확인합니다. 수신 확인을 기다리며 2분마다 같은 알림을 다시 입력하던 동작은 없앴습니다.
- 입력한 메시지가 대화에 들어가지 않은 것이 확인될 때만 같은 메시지 ID로 다시 입력합니다. 받는 구성원이 쉬고 있고 입력창이 비어 있는데 대화에 흔적이 없으면 들어가지 않은 것으로 판단합니다. 세 번 입력해도 들어가지 않으면 자동 입력을 멈추고, 메시지를 수신함에 보관한 채 대화 그래프에 전달 막힘으로 표시합니다.
