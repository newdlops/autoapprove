# 0.2.149 · Claude 상태 조회 경량화

Claude 등록 파일과 작업 상태 파일의 경로를 만들 때 파일·디렉터리 유형을 명시해, Foundation이 유형을 추측하며 수행하던 파일 속성 조회를 줄였습니다. 실제 파일의 종류·크기·변경 시각과 프로세스 식별 정보는 계속 확인합니다. 조회 주기와 자동 승인·일반 질문·안전한 대안 안내 정책은 그대로입니다.

실제 Release 코어에 합성 Claude 16세션과 파일을 제공하고, 경우별 1,000회 읽기를 8쌍 교대로 비교한 CPU 중앙값입니다.

| 조회 상황 | 기존 | 변경 후 | 감소율 |
| --- | ---: | ---: | ---: |
| 등록 파일 변경 없음 | 0.257086초 | 0.195855초 | 약 23.8% |
| 등록 파일 없음 | 0.147772초 | 0.104194초 | 약 29.5% |
| 질문 대기 상태 변경 없음 | 0.418547초 | 0.256522초 | 약 38.7% |
| 질문 상태 파일 교체 | 2.513847초 | 1.871848초 | 약 25.5% |

매번 바뀐 질문 내용도 확인했고 사전에 정한 CPU·메모리 기준을 통과했습니다. 비교 프로세스의 peak RSS 중앙값은 29,057,024→29,097,984바이트로 비슷한 수준입니다. 전체 앱의 CPU·메모리나 휴대폰·VPN 연결 속도의 개선율은 아닙니다.

전체 회귀 **375/375**와 Claude 등록 경계 검사 **3/3**을 통과했습니다. 특수 문자가 있는 경로, 파일의 원자적 교체, 누락, 디렉터리로의 변경과 심볼릭 링크 대상 변경을 확인했습니다. 새 서비스·자동 실행 등록이나 보안·권한·VPN 설정 변경은 없습니다.

최종 서명 패키지의 자동 Allow/이번 세션/현재 모델 응답 12건과 명시적 웹 답변을 기다리는 일반 질문 12건, 일시정지·재시작·응답 유실/중복 방지·웹/MCP·격리 PTY·입력 번들·DMG 검증도 통과했습니다. 설치 DMG는 7,843,984바이트입니다.

macOS 14 이상 Apple Silicon용이며 빌드는 176입니다. 설치 방법은 [설치 안내](../../README.md#설치)를 참고하세요.
