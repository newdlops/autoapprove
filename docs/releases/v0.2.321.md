# AutoApprove 0.2.321 · build 348

`clear_group_member(groupID, memberID, requestID)`로 그룹에서 지정한 세션 하나만
`/clear`하고 새 세션 ID를 확인해 저장합니다. Codex와 Claude를 모두 지원합니다.
대상은 `get_session_groups` 또는 `get_group_status`에 표시된 구성원 `memberID`로
지정합니다. 그룹장이 있으면 그룹장만 요청할 수 있고, 그룹장이 없으면 소속이
확인된 세션이 요청할 수 있습니다. 호출자 자신도 대상으로 지정할 수 있습니다.

기존 전체 초기화와 같은 실행 경로를 사용합니다. 대상의 작업·질문·승인·작성 중인
입력이 끝나고 빈 입력창이 될 때까지 기다리며, 다른 구성원의 대기 상태는 개별
초기화를 막지 않습니다. 해당 그룹의 초기화 요청은 한 번에 하나씩 처리합니다.
그룹 역할·미확인 수신함은 보존합니다.

새 요청에는 UUID `requestID`가 필요합니다. 같은 대상에 대한 재시도에는 같은
값을 사용하세요. 같은 요청 ID를 다른 구성원이나 전체 초기화에 재사용하면
거부합니다. 앱 재시작이나 응답 유실로 전달이 불확실해도 `/clear`를 자동으로
다시 보내지 않습니다.

다른 Terminal 창의 초기화가 멈추던 전달 경로도 수정합니다. Claude의 고정
`/clear`는 message·submit 두 경로에서 모두 백그라운드로 전달합니다. 사용자가
다른 창에서 입력하는 경우에는 앞 창의 선택된 TTY를 직접 Apple Event로 두 번
확인해 대상별 입력 보호를 적용합니다. 실제 입력 중인 대상과 포커스를 확인할 수
없는 경우에는 계속 기다립니다. 기존 일반 입력·자동 승인에는 앱 전체 입력 보호를
유지합니다. 창을 활성화하거나 탭을 선택하는 키보드 입력으로 우회하지 않습니다.
창 입력 대상 조회는 UI 스레드 밖에서 실행하고, 조회 후 입력 보호와 그룹 권한을
다시 확인합니다.
같은 TTY가 네이티브 탭 그룹의 여러 창 별칭에 나타나면 모든 별칭의 화면·CLI를
검증하고 한 번만 전달하며, 화면이 다르면 전송하지 않습니다.

`get_group_clear_status(groupID, requestID)`에서 `scope=member`, 대상 `memberID`,
이전·새 세션 UUID와 진행 상태를 확인합니다. `accepted`는 접수만 뜻합니다.
`done=true`와 `status=completed`를 함께 확인해야 초기화·ID 갱신 완료입니다.
요청 ID를 생략하면 그룹의 최근 전체·개별 초기화 요청을 조회합니다. 호출자 자신의
초기화 중에는 새 ID를 검증해 저장할 때까지 구성원 확인이 일시적으로 거부될 수
있습니다. 이때 새 대화 UUID로 상태를 다시 조회하세요. 이전 버전의 전체 초기화
기록도 그대로 읽습니다. 기존 MCP 연결을 다시 연결하면 새 도구가 표시됩니다.
통신과 전달은 같은 Mac의 로컬 경로를 사용합니다.

`set_group_member_title(groupID, memberID, title)`은 원래 Terminal·iTerm2 탭과
AutoApprove 표시 이름을 한 줄로 1~80자까지 변경합니다.
`set_group_member_tab_color(groupID, memberID, color)`는 이름 앞 색상 표식과
AutoApprove 세션 색상을 저장합니다. red·orange·yellow·green·blue·purple·gray를
지원하며 default는 표식을 제거합니다. 이름·메모를 보존하고, 같은 색상을 반복
지정해도 표식이 중첩되지 않습니다. 그룹장이 있으면 그룹장만 요청할 수 있습니다.

Terminal.app의 스크립팅 사전에는 탭 바만 칠하는 속성이 없어 색상은 이름 앞
🔴·🟠·🟡·🟢·🔵·🟣·⚪️ 표식으로 표시합니다. 반환값의 `colorMode`는
`title_marker`입니다. iTerm2에도 같은 표식을 사용합니다. 터미널 본문 배경·
글자색·공용 설정 프로필·포커스와 CLI 입력은 변경하지 않습니다. 작업 중에도
사용할 수 있으며, 적용 후 원래 탭의 이름을 다시 읽어 확인합니다. iTerm2의 분할
패널은 하나의 탭 이름을 공유합니다. iTerm2의 탭·세션 제목 속성은
[공식 스크립팅 사전](https://github.com/gnachman/iTerm2/blob/master/iTerm2.sdef)을
기준으로 사용합니다.

검증은 소유한 가짜 터미널과 격리 MCP를 사용하며 실제 사용자 세션에는
시험용 `/clear`를 보내지 않습니다.
실제 Terminal 화면 검증은 도구의 안전 정책으로 접근이 차단되어 수행하지 못했습니다.
iTerm2는 이 Mac에 설치되어 있지 않아 실제 앱 검증은 수행하지 못했습니다.

별도 검토한 [#14](https://github.com/newdlops/autoapprove/issues/14)의 명시적 ID
갱신 시 기존 확인값 재사용과 Claude가 제외된 진단 범위는 후속 개선이 남아 있습니다.
[#13](https://github.com/newdlops/autoapprove/issues/13)에서 제기한 프로세스 조회는
현재 `LC_ALL=C`·`LANG=C`를 강제하지만 해당 이슈 전체의 해결을 확인하지 않아
열린 상태를 유지합니다.
