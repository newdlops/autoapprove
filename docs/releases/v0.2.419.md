# AutoApprove 0.2.419 · 빌드 446

세션 프로필 복원 중 Terminal 자동화가 잠시 사용 중이면 차례를 기다립니다. 같은 탭 막대에 새 탭 하나가 추가된 것을 확인하면 원래 탭과 새 탭 사이를 다시 전환하는 과정을 생략합니다. Terminal을 재실행한 뒤 재사용된 TTY 번호가 이전 복원 기록과 겹쳐도 현재 세션을 다시 확인합니다.

**저장할 때 현재 창·탭 배치 읽기**를 켜고 저장하면 Terminal 창의 화면 좌표와 크기도 기록합니다. 복원할 때 새로 만드는 창에 한 번 적용합니다. 저장 당시의 화면이 분리됐으면 현재 화면 안에 배치합니다. 기존 프로필은 저장된 창 묶음과 탭 순서로 열 수 있습니다. 화면 좌표가 필요하면 원하는 배치에서 프로필을 갱신하세요.

여러 Codex 세션을 복원할 때 같은 대용량 런타임 파일의 SHA-256 검사 결과를 재사용합니다. 각 파일을 다시 열어 파일 식별 정보와 변경 시각, 배포 목록의 지문이 일치하는지 확인합니다.
