# AutoApprove 0.2.264 · 빌드 291

관리자 페이지에서 Terminal의 원본에 직접 타이핑할 때, 매 입력마다 반복하던 창 확인 스크립트 실행을 줄였습니다. 같은 원본 Terminal 창이 이미 선택돼 있고 포커스를 가진 경우에는 현재 선택 TTY와 WindowServer·손쉬운 사용 포커스를 네이티브 조회로 확인합니다. 다른 창으로 이동해야 하거나 화면 내용 검증이 필요한 전송은 기존 준비 경로를 유지합니다.

각 키 입력 직전에 원본 PID·정밀한 시작 시각·사용자 ID·TTY 장치·전경 작업·Terminal 소유 프로세스와 창·탭·포커스·권한을 다시 확인합니다. 입력 결과가 불확실하면 자동으로 다시 보내지 않습니다. root 입력 서비스는 사용하지 않습니다.

내용 없는 입력 단계별 시간 통계를 추가했습니다. `autoapprove terminal-timings`에서 스크립트 준비·네이티브 창 확인·포커스 확인·프로세스 확인·키 이벤트 게시 비용과 각 준비 경로의 사용 횟수를 확인할 수 있습니다. 터미널 내용이나 요청 텍스트는 이 통계에 저장하지 않습니다. 웹의 입력 왕복 지연 표시는 실제 확인 응답을 계속 사용합니다.
