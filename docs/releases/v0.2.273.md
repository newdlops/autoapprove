# 0.2.273 · 실시간 화면과 감시의 중복 조회 감소

- Terminal 감시가 같은 원본의 완료된 실시간 화면을 180ms 이내에서 공유해 중복 텍스트 조회를 줄입니다. 감지 처리는 계속 실행하며 실제 관찰 시각을 보존합니다.
- 현재 권한·원본·변경 세대·입력 우선권을 확인하고, 처리 중 바뀌거나 오래된 결과는 사용하지 않습니다. 별도 표시 투영이 있는 화면은 기존 조회를 유지합니다.
- 공유 화면이 감시 캐시의 수명을 늘리지 않도록 하고 커서 정보를 검증해 보존합니다. 내용 없는 공유 횟수 계측을 추가했습니다.
- 실제 입력부터 화면 반영까지의 지연 개선은 배포 후 계측하며, 50ms 목표 달성을 뜻하지 않습니다.
