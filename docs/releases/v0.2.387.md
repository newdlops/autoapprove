# AutoApprove 0.2.387 · 빌드 414

Terminal.app, iTerm2, AutoApprove PTY에서 MCP 복구를 선택하면 같은 대화로 CLI를 재시작한 뒤 새 세션의 MCP 연결을 확인합니다. 세션 재시작과 복구 모두 필요한 대화 ID만 조회하고, 선택한 CLI에 Esc를 먼저 시도합니다. Terminal.app에서 포커스를 옮겨야 하는 탭은 검증된 CLI에 종료 신호를 보냅니다.

셸이 돌아오면 즉시 같은 탭에 재실행 명령을 보냅니다. Terminal.app의 셸 재실행은 한 번에 하나씩 처리하고, 서로 다른 iTerm2·PTY 탭은 최대 두 개까지 함께 처리합니다.
