# AutoApprove 0.2.188 · build 215

7844 포트가 막힌 네트워크를 위한 **Cloudflare HTTPS (443)** 연결을 추가했습니다.

- Cloudflare 승인 → 도메인·짧은 서브도메인 선택 → 연결의 3단계입니다.
- Workers와 SQLite Durable Object를 계정에 설정하고, 앱은 HTTPS/WSS 443으로 연결합니다.
  별도 서버 운영이나 API 키 복사가 필요 없습니다. 기존 Tunnel 승인을 쓴 경우
  Workers 권한은 브라우저에서 최초 한 번 더 승인합니다.
- 기존 Tunnel 실패 화면에서 **HTTPS (443)로 연결**로 전환할 수 있습니다.
  기존 저장된 연결 방식과 주소는 유지합니다.
- 바이너리 터미널 출력은 줄바꿈을 기다리지 않고 전달합니다. 요청별 흐름 제어와
  재접속을 제공하며, 전송 결과가 불확실한 입력은 자동 재전송하지 않습니다.
- 기존 접속 키·쿠키·Host/Origin 검사와 공개 주소 검증을 유지하고 다른 DNS를 덮어쓰지 않습니다.

Cloudflare 계정의 사용량 한도가 적용되며 유료 요금제는 자동 신청하지 않습니다.
HTTPS WebSocket이 허용된 네트워크가 필요합니다. 실제 계정의 브라우저 승인과
사용자 도메인 연결은 사용자가 앱에서 진행합니다. 로컬 검증은 실제 workerd 런타임,
합성 계정 API, 격리된 원본·PTY를 사용하며 실계정 배포 성공과 구분합니다.
