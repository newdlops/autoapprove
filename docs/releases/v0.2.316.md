# AutoApprove 0.2.316 · build 343

Codex에 이어 Claude Code의 긴 승인창이 멈추는 문제를 수정했습니다.
0.2.315의 Codex 수정도 포함합니다.

Claude는 명령·편집 내용을 승인 질문 앞에 표시합니다. 기존 코드는 `Bash command`,
`Edit file`, `Create file` 제목과 질문 사이가 300줄을 넘으면 요청 경계를 버렸습니다.
이때 이전 요청에 이미 승인 입력을 보낸 상태라면, 새 요청까지 이전 요청의
중복 방지 상태를 물려받아 자동 승인이 멈췄습니다. 연속된 승인창을 사용하는
검사에서 수정 전 실패를 재현했습니다.

알려진 패널 제목과 현재 승인 질문이 확인되면 본문 길이 때문에 경계를 버리지
않습니다. 이전 패널의 제목을 가져오거나 알 수 없는 패널에 경계를 만들어
주지는 않습니다. 같은 명령·파일 내용이 유지된 화면은 이전 출력이나 줄바꿈이
바뀌어도 중복 승인하지 않습니다. 전송 직전 전체 화면 비교도 유지합니다.

검증은 가짜 화면 어댑터와 JavaScriptCore를 사용했습니다. 299·300·301·1,200줄
Claude 명령 승인, 1,200줄 파일 편집·생성 승인, 연속 요청 구분, 동일 요청의
출력·줄바꿈 변경 시 중복 방지, 파일 경로 변경 시 전송 차단, 불명확하거나
이전 패널에서 가져온 경계의 차단을 확인했습니다. 사용자 터미널에는 시험
입력을 보내지 않았습니다.

Codex에서는 0.2.315에서 확인한 300줄 검색 제한 수정이 포함됩니다. 두 도구 모두
필요한 제목·선택지·확인 안내가 읽힌 화면에서 빠진 경우에는 내용을 추정해
자동 승인하지 않습니다. 이번 변경은 기존 터미널 화면 텍스트 경로를 사용하며
내부 IPC나 서버 승인 정보로 대체하지 않습니다.

전체 디버그 회귀 검사 305개가 통과했습니다.
최종 배포 빌드의 회귀 검사도 276개 모두 통과했습니다.
