# AutoApprove 0.2.201 · build 228

시간이 지난 뒤 화면이 꺼지며 작업 연결이 멈추지 않도록, 잠자기 유지 범위를 앱 실행 시간 전체로 바꿨습니다.

- 연결 설정의 **앱이 켜진 동안 계속 작업 → 앱 실행 중 잠자기·자동 화면 꺼짐 방지**를 켜면 작업·질문·대기 상태와 관계없이 유지합니다. 자동 승인 OFF·전체 일시정지·세션 검색 중에도 유지하며, 마지막 작업 뒤 2분 후 해제하던 조건을 없앴습니다.
- 시스템 잠자기와 별도로 macOS의 유휴 화면 꺼짐도 방지합니다. 설정에서 덮개·화면 잠김 상태를 확인하고 **macOS 잠금 화면 설정**을 열 수 있습니다.
- 앱/설정을 끄면 유지 요청을 해제합니다. 기존 배터리 20% 이하·과열 보호와 앱 비정상 종료 감시/복원을 유지합니다. 다른 앱이 설정한 잠자기 금지는 변경하지 않습니다.

이미 잠긴 화면을 자동으로 해제하지 않습니다. 덮개 동작·수동 잠금·조직 보안 정책에 따른 모든 잠금을 막는 기능은 아닙니다. macOS 인증 설정은 자동으로 변경하지 않습니다. [검증 범위](../../VALIDATION.md).
