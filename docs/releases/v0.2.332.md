# AutoApprove 0.2.332 · 빌드 359

- 새 작업 배정에 연결된 입력과 응답을 확인하면 작업자가 이미 쓴 원문을 원래 지시자에게 전달합니다. 기존 작업 지시와 선택지·승인 흐름을 유지합니다.
- 여러 결과를 기다리는 경우 앱이 중간 결과를 보관하고, 대기 조건이 충족되면 결과를 한 메시지로 전달합니다. 만료 후 도착한 결과는 원래 수신함에 남습니다.
- Claude 종료 훅을 놓친 경우 대화 ID, 제출한 입력, 로컬 기록의 마지막 완료를 대조해 질문의 답을 복구합니다. 같은 입력의 반복이나 대화 불일치가 확인되면 자동 회신을 보류합니다.
- 터미널의 한 줄 입력 한도를 넘는 원문은 로컬 수신함에서 조회할 수 있습니다.
