# 0.2.267 · 손쉬운 사용으로 Terminal 활성화

- 0.2.266에서 일반 앱 활성화 요청이 거절되면 입력 준비를 바로 중단하는 문제를 수정했습니다. 기존에 허용한 AutoApprove의 손쉬운 사용 권한으로 실행 중인 Terminal의 숨김을 해제하고 활성화합니다.
- 활성화 작업 전후에 동일한 Terminal 프로세스인지 다시 확인합니다. 정확한 대상 창·탭의 포커스가 준비된 후에만 키를 전달합니다.
- 활성화 실패 메시지에 손쉬운 사용의 작업과 오류 코드를 포함하며, 준비 시간과 실패도 계측합니다. root 입력 서비스나 추가 권한을 도입하지 않습니다.
- 모의 검증 결과와 실제 Mac 입력 결과는 구분합니다. 실제 백그라운드 입력은 설치 후 확인이 필요합니다.
