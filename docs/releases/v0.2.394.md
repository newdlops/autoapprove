# AutoApprove 0.2.394 · 빌드 421

- 그룹장은 `watch_group_events(groupID, cursor, waitSeconds)`로 전달 보류, 제출 결과 불명, 수신 확인, 작업 상태 변경을 조회합니다. 마지막 cursor를 저장하면 재연결 후 그 다음 이벤트부터 받습니다. 페이지당 50건, 호출당 최대 20초입니다.
- `explain_group_delivery(groupID, messageID)`는 기록과 현재 입력창을 대조해 단계, 근거, 관측 시각, 다음 행동을 반환합니다. 전달 키 입력과 수신 확인은 별도 단계입니다.
- `replace_group_task(groupID, memberID, taskID, task, requestID)`는 직속 작업자의 기존 배정과 대화를 확인하고 교체합니다. 현재 작업이 실행 중이면 Esc를 요청하고 빈 대기 입력창을 확인합니다. awaitingStop이면 같은 requestID로 다시 조회하세요.
- `clear_group_composer(groupID, memberID)`는 현재 초안의 토큰을 반환합니다. 같은 호출에 draftToken을 넣으면 확인한 초안을 지우고 결과를 다시 읽습니다. Terminal.app에서는 포커스를 바꾸지 않고 키를 전달할 수 있는 탭이어야 합니다.
