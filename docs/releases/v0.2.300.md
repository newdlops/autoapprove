# AutoApprove 0.2.300 · 복원 시 창 구성 유지

- 같은 창의 새 탭을 확인하지 못했을 때 별도 창으로 대체하던 동작을 제거했습니다. 탭 연결 실패를 새 창 실행 성공으로 표시하지 않고 실제 실패 단계와 전달 상태를 유지합니다.
- 중간 항목이 실패해도 마지막으로 확인한 기존 창의 탭 연결을 유지합니다. 후속 항목을 새 창으로 분리하지 않습니다.
- 첫 창의 생성 결과가 불확실하고 연결 위치가 없으면 같은 저장 창의 후속 항목은 보류합니다. 정확한 기존 대화 연결이 확인되면 해당 창에서 남은 탭을 복원할 수 있습니다.
- 새 탭의 생성 위치가 불확실하면 같은 복원 요청에서 그 창의 추가 탭 생성을 멈춥니다. 다른 저장 창의 복원은 계속 처리합니다.

검증: 프로필 검사 19개(새 창 대체 금지, 중간 실패 시 기존 창 유지, 불확실한 첫 창의 재시도 중복 방지, 독립 창 복원 포함), 배포 빌드의 프로필 검사, 생성된 Terminal 스크립트의 격리 검사. 실제 사용자 대화를 다시 실행하는 복원 시험은 하지 않았습니다.
