# Codex 0.167.1 AutoApprove managed1

macOS 14 이상 Apple Silicon용 보조 실행 패키지입니다. AutoApprove 앱 버전은
0.2.280으로 유지하며, 이 릴리스가 앱의 자동 업데이트 대상으로 선택되지는 않습니다.

- 실제 자식 Goal을 조회하고 일시정지·재개하는 서버 확장과 기존 자식 승인창 수정을 함께 제공합니다.
- 공식 0.167.1 실행 패키지의 보조 프로그램·음성 리소스·라이선스를 보존합니다. CLI와 음성 매니페스트의 CLI 체크섬을 변경하고 기존 AutoApprove 게시자 서명으로 서명했습니다.
- 서명된 전체 패키지를 별도 홈에 설치해 실제 데몬에서 Swift Goal 제어를 검증했습니다. Goal UUID·목표·예산, 사용량의 단조 증가, 부모 턴 보존과 이전 상태 요청 거절을 확인했습니다.
- 실제 TUI에서 자식 화면을 방문한 뒤 부모로 돌아와 자동승인, 명령 완료, 승인창 해제를 확인했습니다. 같은 시험으로 공식 0.167.1의 기존 오류도 재현했습니다.
- 새 홈에서는 포함된 CLI의 `app-server daemon start`로 서버를 준비할 수 있습니다. 실행 중인 서버를 업데이트하는 명령은 재시작을 수반하므로 기존 세션의 투명한 이동·보존 업그레이드로 취급하지 않습니다.

이 패키지는 AutoApprove 유지보수 빌드이며 OpenAI 공식 배포판이 아닙니다.
Apple 공증을 받지 않았습니다. 자세한 구성과 재현 명령은
[패키지 안내](../../patches/codex/0.167.1-managed-package.md)를 참고하세요.
기존 대화의 로그인 그룹 이동·세션별 서버 지정은 이번 보조 패키지의 완료 범위가 아닙니다.
