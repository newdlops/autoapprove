# AutoApprove 0.2.198 · build 225

웹 관리자에 계속 쌓이던 지난 질문을 정리할 수 있습니다.

- 질문 뒤에 대화가 이어졌거나 답변이 접수된 항목을 **지난 질문·답변**으로 접습니다. 최근 10개만 간단히 표시하며 필요한 질문은 **답변하기**로 다시 열 수 있습니다.
- **목록 정리 → 지난 질문 정리**로 여러 Mac의 지난 질문을 한 번에 정리합니다. 세션별 개별·전체 정리와 1분 동안 되돌리기도 제공합니다. 정리는 해당 Mac에 저장되어 다른 브라우저와 재접속에도 유지됩니다.
- 새 질문·작성 중 답변·전송 중·전달 결과 미확인을 보호하고, 내용이나 전송 상태가 바뀐 질문은 정리하지 않습니다. 원본 CLI의 대화·대기 입력·답변 기록은 유지합니다. 구형 Mac은 기존 브라우저 표시 정리를 사용합니다.
- 브라우저의 전달 확인된 이전 메시지는 세션별 최근 20개로 제한합니다. 미확인·실패·전송 중 기록과 초안은 자동으로 지우지 않습니다.
