# AutoApprove 0.2.405 · 빌드 432

화면 조회와 자동 승인이 동시에 발생해 입력을 시작할 수 없으면 원래 세션과 승인 요청을 다시 검증해 자동으로 이어갑니다. CLI 오류 후 이어가기, 그룹 메시지와 원격 입력도 전송 전의 경합을 구분합니다. 입력을 시작한 뒤 결과가 불분명하면 중복 전송 방지를 유지합니다.

대상 검증을 위한 읽기는 호스트별 최대 4건이 순서대로 0.8초까지 자리를 기다릴 수 있습니다. 실제 IPC는 호스트별 1건, 전체 2건 이내로 유지합니다. 키보드 상태가 아직 준비되지 않은 경우 첫 표본을 비동기로 기다리고, 활성화해 둔 Terminal·iTerm2의 macOS 자동화 권한이 돌아오면 자동으로 감시를 재개합니다.

실제 Terminal.app의 임시 탭에서 모의 승인 요청의 전송을 경합으로 막았다가 해제했습니다. 추가 화면 이벤트 없이 승인 키와 Enter가 한 번 도착했고, 이어서 보낸 테스트 메시지도 Enter로 한 번 제출됐습니다.
