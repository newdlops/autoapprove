# 0.2.146 · Codex 질문 기록 해석 경량화

머지된 [PR #7](https://github.com/newdlops/autoapprove/pull/7)을 포함합니다. 현재 열린 Codex 기록 파일과 헤더는 매번 새로 읽고, 바이트가 같은 헤더의 root ID 해석만 재사용합니다. 질문 DB와 입력 원본은 계속 확인합니다. 헤더/ID 데이터는 최대 4MiB·64개로 제한하며, 처음만 사용하는 수집기는 큰 헤더를 보관하지 않습니다. 첫 질문은 바로 읽습니다.

실제 Core에 같은 합성 16세션을 넣어 각 상황을 별도 프로세스에서 8쌍 교대 비교했습니다. 약 100KB의 같은 헤더 60회 조회 CPU 중앙값은 **1.681→0.710초**, 본문만 추가할 때는 **1.758→0.822초**였습니다. 첫 조회는 **0.392→0.401초**이며, 매번 헤더를 바꾸는 30회 시험은 **0.880→0.965초**로 약 9.7% 늘었습니다. 결과 64,512개와 source DB 불변을 확인했습니다. 이는 합성 처리 경로의 측정이며 전체 앱·네트워크·휴대폰의 개선율은 아닙니다.

전체 Release **370/370** 검사가 통과했습니다. 헤더가 같아도 질문 DB의 변경을 반영하며, 같은 크기와 복원한 mtime의 root 변경·잘못된 헤더·모호하거나 사라진 파일·빈 세션 뒤 복구를 확인했습니다.

서명 패키지의 자동 응답 12건·웹 답변까지 기다리는 수동 질문 12건, 일시정지·재시작·응답 유실/단일 전달·격리 웹/MCP/PTY·입력 구성요소·DMG 검사도 통과했습니다. 패키지 코드와 웹 파일이 검사한 빌드/소스와 일치합니다.

0.2.145의 미구독 화면 비교 경량화와 웹 지난 메시지·끊긴 Mac·경고 정리 기능도 포함합니다. macOS 14 이상 Apple Silicon용이며 빌드는 173입니다. 기존 발행자 인증서를 재사용합니다. 설치 방법은 [설치 안내](../../README.md#설치)를 참고하세요.
