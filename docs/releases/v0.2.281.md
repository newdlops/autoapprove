# AutoApprove 0.2.281 · build 308

로그인 그룹과 실행 중인 세션의 연결을 관리할 수 있습니다. 계정·로그인에서 그룹을 만들고 이름을 설정하며, 각 세션은 개별 로그인 홈을 사용하거나 같은 그룹의 계정을 공유할 수 있습니다.

- 세션의 그룹 변경은 기존 대화와 하위 서브에이전트를 선택한 그룹으로 이전하고, 같은 대화를 원래 터미널에서 다시 연결합니다. 준비 단계에서 이동 범위를 확인하거나 취소할 수 있습니다.
- 세션의 실제 Codex app-server 연결을 표시합니다. 이전이 끝난 뒤 재연결이 남으면 계정·로그인에서 확인할 수 있습니다.
- 서브에이전트 현황은 현재 하위 대화의 실행 상태를 다시 읽어 갱신합니다. Goal을 일시정지·재개하거나 후속 Goal 진행을 멈춘 채 현재 작업 종료를 기다릴 수 있습니다.
- 필요한 네이티브 연결·Goal 제어 기능을 포함한 AutoApprove 관리형 Codex 0.167.1 런타임을 동봉합니다. 기존 실행 중인 CLI와 서버는 자동으로 교체하지 않으며, 이동 전에 관리형 서버 연결이 필요합니다.

기존 32MB 업데이트 제한을 넘는 런타임이 포함되므로 이전 앱에서는 DMG로 업데이트해야 합니다. 이 버전부터는 런타임을 포함한 업데이트 크기를 지원합니다. 계정 자격 증명은 대화와 함께 복사하지 않고 선택한 그룹에 그대로 둡니다.

검증: 관련 그룹 이동·Goal·연결 검사, 실제 CLI와 서버 두 개를 사용하는 격리된 앱 이동 API 실행, 동일 셸·PTY 재연결, 대화와 일시정지 Goal ID 보존, 입력 잠금·해제와 초안 보존을 확인했습니다. 실제 계정과 모델 API는 사용하지 않았습니다. 네이티브 그룹 UI의 긴 이름·경로·연결 실패 표시를 확인했습니다.
