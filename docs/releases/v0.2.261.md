# AutoApprove 0.2.261 · 빌드 288

연결된 Codex의 부모와 서브에이전트 상태를 서버에서 주기적으로 읽어 Mac과 웹에 표시합니다. 부모가 작업 중이어도 대기 중인 자식은 별도로 표시합니다. 자동 승인이 꺼져 있거나 전체 일시정지 중에도 상태 조회는 계속하며, 이 조회는 승인·메시지·키 입력을 보내지 않습니다. 연결 오류나 오래된 결과는 확인 중으로 표시합니다.

Terminal 직접 입력 서비스의 게시자 서명이 현재 앱과 다르면 그 원인을 안내합니다. Mac의 연결 설정에서 직접 입력 연결을 누르면 봉인된 앱과 설치 정책을 검증한 뒤 macOS 관리자 인증으로 서비스를 설치·갱신합니다. 정상 연결된 서비스와 백그라운드 승인 대기 상태는 재설치하지 않습니다. 웹 요청이나 자동 조회에서 서비스를 설치하지 않으며, 설치 후 실제 XPC 응답을 확인해야 연결 완료로 표시합니다. 기존 입력을 재전송하지 않습니다.

서브에이전트의 상태는 명시적으로 연결된 대화 트리에만 적용합니다. 다른 대화나 연결하지 않은 터미널은 기존 표시 방식을 유지합니다.
