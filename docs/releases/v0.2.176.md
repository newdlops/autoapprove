# 0.2.176 · 빌드 203

Cocoa 터미널 출력의 행별 정규화에서 중간 문자열 변환을 줄입니다. 기존 4,096단위 UTF-16 버퍼 안에 정상 Unicode 행이 모두 있으면, 해당 문자를 소유 저장소에 복사하고 NFC 정규화합니다. 버퍼 경계를 넘는 행은 원본 Cocoa substring을 정규화하며, 손상 UTF-16은 기존 복구 경로를 사용합니다. 원문 UTF-8 예산과 행 경계·끝 빈 행 처리, native 경로, 허가·일반 질문·모델·오류/Goal·최종 원문 확인 정책을 유지합니다.

정식175와 실제 Core의 합성16세션을 새16프로세스·8쌍·512구간으로 비교했습니다. 한글·결합문자·이모지가 포함된 Cocoa 변경 화면은 **CPU 12.3%·경과 시간 12.5% 감소**했고, 미리 정한17개 CPU/경과/최대RSS 기준을 모두 통과했습니다. 다음 값은 후보/정식 비율입니다. 8개 ABBA/BAAB 구간의 비율 중앙값을 쌍별로 구한 뒤8쌍 중앙값을 사용하며, 따로 구한 절대 시간 중앙값의 몫과는 다릅니다.
