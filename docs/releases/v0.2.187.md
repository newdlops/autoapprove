# AutoApprove 0.2.187 · build 214

Cloudflare 접속 주소의 서브도메인을 클라이언트에서 직접 지정할 수 있습니다.

- `a`, `aa`, `term`처럼 짧게 입력하고 완성된 접속 주소를 확인합니다.
- 이미 사용 중인 이름은 덮어쓰거나 임의 접미사를 붙이지 않고 다른 이름을 요청합니다.
  주소 충돌은 새 터널 생성 전에 확인합니다.
- 저장된 기존 주소는 유지하며 연결을 종료한 뒤 이름을 바꾸고 다시 연결할 수 있습니다.
  다시 연결할 때 같은 터널을 재사용하고 새 접속 링크와 QR을 제공합니다.
- TCP 고정 설정을 풀어 QUIC/HTTP2와 IPv4/IPv6를 자동 선택합니다.

470개 핵심 검사와 두 브라우저의 인증·격리 터미널 검사를 통과했습니다.
네이티브 입력 오류·한 글자 이름·Enter 연결·취소·주소 수정·저장을 확인했습니다.
Cloudflare Tunnel은 UDP 또는 TCP 7844가 필요합니다. 443만 허용된 네트워크를 위한
Workers 중계는 별도 기능이며 이번 자동 전환만으로 443 연결을 제공하지 않습니다.
