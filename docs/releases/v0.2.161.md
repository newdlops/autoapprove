# 0.2.161 · 빌드 188

여러 세션에 누적된 자동화를 한 번에 비우는 **전체 초기화·재실행**을 추가했습니다.

- 웹의 Mac 행에서 **모든 세션 초기화**: 해당 Mac의 모든 세션을 초기화합니다.
- 웹의 **연결된 Mac 모두 초기화**: 클릭할 때 연결된 Mac들에 한 번씩 요청합니다.
- Mac 앱 도구 막대의 **전체 초기화**: 이 Mac의 모든 세션을 초기화합니다.
- 기존 세션별 **자동화 초기화·재실행**도 유지합니다.

실행·종료 세션에 남은 예약 작업, 재시도와 감지 캐시를 함께 비웁니다. 세션별 초기화를 반복하는 대신 한 번의 일괄 처리로 감지 세대를 바꾸고 작업 표를 해제합니다. 이전 조회가 늦게 돌아와도 초기화된 상태를 되살리지 못하며, 실행 중인 원본 화면·질문을 다시 읽습니다. 새 폴링이나 상주 서비스를 추가하지 않았습니다.

원본 터미널과 대화, 작성 중인 초안, 각 세션의 자동 승인 설정과 전체 일시정지는 유지합니다. 이미 전달 중인 입력의 최소 중복 방지 기록도 보존합니다.

웹은 진행·완료·실패를 표시합니다. 일부 Mac만 실패하면 해당 Mac의 버튼으로 재시도할 수 있습니다. 연결이 끊긴 Mac은 다시 연결한 뒤 초기화하며, 네트워크 전체 초기화를 지원하지 않는 구버전이 있으면 업데이트 안내를 표시합니다.

검증:

- 최종 Release 전체 **408/408**이 통과했습니다. 기존 가드 검사의 메인 액터 동기 대기를 비동기로 보완했고 종료 조건과 시간 제한은 유지했습니다. 앞선 두 번의 407/408 실패도 보존했습니다.
- 단일·전체 초기화 회귀 **16/16**. 동시 전송 전 취소, 전송 중 중복 방지, 여러 원본 Claude 훅의 깨움·재구성, 반복 초기화 뒤 최신 화면 감지, 빈 목록·종료 세션·서로 다른 자동 승인 설정과 HTTP 재전송·Origin/대상 Mac 검사를 확인했습니다.
- 실제 Swift 웹 처리기와 격리된 합성 Mac 두 대를 사용하는 Chromium/WebKit **12그룹**이 통과했습니다. **390×844·768×1024·1440×900**에서 중복 클릭당 Mac별 한 번 전달, 전체 초기화 도중 세션 열기, 부분 실패·한 Mac 재시도, 구버전·오프라인·빈 대상·연결 복구, 초안과 일시정지 보존 및 기존 세션별 초기화를 확인했습니다.
- Impeccable 검사 결과는 빈 목록이며 변경 범위의 접근성을 검토했습니다. Mac 합성 제품 창의 **1040×700·784×612** 밝은 화면에서 전체 초기화 글자와 배치를 확인했습니다. NSView 기반 어두운 화면 캡처에는 네이티브 도구 막대가 완전히 그려지지 않아 해당 시각 검증과 네이티브 버튼 실클릭은 미완료입니다. 실물 휴대폰은 시험하지 않았습니다.
- 원본 터미널에 시험 입력·초기화·캡처를 보내지 않았고 시스템 자동 실행·새 서비스, 관리자 상승이나 보안·권한·VPN 정책 변경도 없습니다.
