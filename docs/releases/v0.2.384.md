# AutoApprove 0.2.384 · 빌드 411

그룹 대화 그래프의 배치에서 ‘포스’를 고르면 상하 관계와 대화량에 따라 연결된 노드가 모입니다. 최근·전체 보기를 전환해도 위치가 유지되며 기존처럼 노드를 옮기거나 자동 배치로 되돌릴 수 있습니다.

여러 CLI를 다시 시작하면 한 탭에서 원래 셸로 돌아와 재실행 명령을 입력한 뒤 다음 CLI를 종료합니다. 원래 셸이 포그라운드로 돌아왔음을 확인한 경우 단독 ❯ 프롬프트도 처리합니다. 탭의 화면 읽기, 셸 확인, 입력 직전 변경 중 어디에서 기다리는지 진행 상태에 표시합니다.

닉네임·역할 버튼을 누르면 수신자의 최신 요청이 일반 대기 메시지보다 먼저 전달되고 그래프의 구성원 메시지 내역에 표시됩니다. 같은 범위로 반복한 미전송 요청은 최신 요청으로 합칩니다. 워커 MCP 프로필에서도 권한이 있는 구성원의 닉네임과 역할을 저장할 수 있습니다.
