# AutoApprove 0.2.370 · 빌드 397

원형 보기에서는 그룹장을 각 원의 중심에 두고 해당 그룹장의 직속·하위 구성원을 시계 방향으로 배치합니다. 여러 원은 노드와 이름표가 겹치지 않도록 간격을 두며, 그룹 간 대화는 기존 연결선으로 표시합니다. 처음 열 때 기본 배치는 원형이며 이전에 선택해 저장한 배치가 있으면 그 선택을 따릅니다.

세션 목록, 그룹 구성원, 그래프 노드에서 마지막으로 확인된 모델과 추론 수준을 볼 수 있습니다. 확인되지 않은 값은 각각 미확인으로 표시하며, 전체 값은 노드의 도움말과 선택 상세에서 확인할 수 있습니다.
