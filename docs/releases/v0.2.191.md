# AutoApprove 0.2.191 · build 218

직접 입력 중 같은 승인이 반복되는 문제를 수정하고, 오래 끊긴 연결과 멈춘 화면을 복구합니다.

- 입력 화면으로 바뀌어도 이미 전송한 승인 기록을 유지해 같은 요청에 Enter를 반복하지 않습니다.
  실제 작업·안정된 빈 입력창·다른 새 요청은 정상적으로 이어갑니다.
- Mac의 Terminal·iTerm2·지원 VS Code 앱에서 직접 키보드를 쓰는 동안 자동 입력을 양보합니다.
  키 내용은 수집하지 않으며 다른 앱에서 입력할 때는 백그라운드 승인을 유지합니다.
- Cloudflare의 일시적 실패를 정해진 횟수 뒤 포기하지 않고 분산 재시도합니다.
  네트워크 복귀·Mac 깨우기로 대기를 줄이고 PIN·게이트웨이를 유지합니다.
  명시적인 인증 거절과 사용자의 중지는 별도로 처리합니다.
- 공개 주소 초기 확인이 실패해도 자동으로 다시 확인합니다.
  연결 도구의 복구 대기 중에도 HTTPS 443 방식으로 전환할 수 있습니다.
- 관리 API의 Worker 갱신이 느리면 3초 뒤 기존 중계 연결을 시도합니다.
  중지된 이전 작업이 나중에 새 연결을 시작하지 않도록 합니다.
- 같은 IP로 돌아온 LAN에서도 오래된 읽기·경로·검색을 갱신합니다.
- 입력 보조 스크립트가 멈춰도 관리 페이지를 열고, 늦게 받은 기능은 확인된 입력 뒤 전환합니다.
  터미널 구성 파일은 병렬로 받으며 JS·CSS 오류/정지를 제한 시간 뒤 새 요청으로 복구합니다.
