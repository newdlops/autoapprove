# AutoApprove 0.2.426 · 빌드 453

세션 프로필을 저장할 때 선택한 프로세스의 ID와 시작 시각을 다시 확인합니다. 프로필 복원은 Terminal과 iTerm2의 입력 순서를 지키며, 새 Terminal 셸이 명령을 읽기를 기다리는 동안에는 다른 탭이 자동화를 사용할 수 있습니다.

세션 재시작과 오류 종료 복구는 대상 터미널의 프로세스, 그 상위 프로세스, 원래 CLI를 확인합니다. 복구 명령을 보내기 직전에 원래 셸과 포그라운드 작업을 다시 확인합니다. 입력 차례를 받지 못한 경우에는 재시도 횟수를 소모하지 않으며, 전달 결과가 불확실하면 원래 명령을 반복하지 않습니다.

Claude 로그인 중에도 Codex 계정 관리와 재연결을 사용할 수 있습니다. 로그인 CLI 준비는 백그라운드에서 진행하며, 준비 중 취소한 로그인은 인증 터미널을 열지 않습니다. 앱 자동 업데이트는 세션 재시작과 복구를 마친 뒤 적용합니다.

실제 macOS Terminal의 임시 탭 두 개로 검증했습니다. 첫 탭이 복원 명령을 읽는 시점을 2초 늦춰도 두 번째 탭의 입력은 174ms 만에 전달됐고, 모의 CLI는 한 번 실행됐습니다. 같은 Mac에서 7회씩 세 차례 측정한 재시작용 프로세스 조회의 중앙값은 전체 조회 6.2~6.7ms, 대상 터미널 조회 0.44~0.54ms였습니다.
