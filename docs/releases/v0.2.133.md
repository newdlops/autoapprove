# 0.2.133 · Claude 일반 선택 질문은 직접 응답

Claude의 프로젝트·환경·작업 선택과 복수 선택 질문은 자동 승인 모드에서도 사용자의 답변을 기다립니다. 웹의 질문 폼에서 고른 답을 원래 질문과 함께 Claude에 돌려줍니다.

자동 응답은 `Yes/No`, `예/아니오`, `네/아니요`, `응/아니오`, `Allow/Deny`처럼 명확한 확인·허용 질문으로 제한합니다. `Yes, use staging`이나 `No, run tests instead`처럼 작업을 고르는 문장은 확인으로 추정하지 않습니다. 반복 허용 선택지가 함께 있어도 이번 요청만 허용하며, 추천 표시만 있는 일반 선택지는 자동으로 고르지 않습니다.

일반 질문에 시스템 명령이 언급돼도 질문 자체를 실행 요청으로 간주해 자동으로 대체하지 않습니다. 실제 시스템 변경 명령의 권한 요청에는 기존 거절·안전한 대안 안내를 유지합니다.

Release 회귀 검사 359개가 통과했습니다. 실제 패키지의 Claude 훅에서는 일반·복수 선택 질문 8개를 자동 응답 없이 유지한 뒤 명시적인 HTTP 웹 답변만 전달했고, 기존 승인·재시작·응답 유실 복구도 확인했습니다.

macOS 14 이상 Apple Silicon용이며 빌드는 160입니다. 기존 발행자 인증서를 재사용했습니다. 설치 방법은 [설치 안내](../../README.md#설치)를 참고하세요.
