# AutoApprove 0.2.212 · build 239

Terminal이 실행 중인데 세션 프로필에서 “Terminal이 실행 중이 아닙니다” 안내로 중단하는 조회 경로를 수정합니다.

- 기본 Terminal의 실제 커널 PID 목록과 시스템 실행 파일 경로로 원본 프로세스를 찾습니다. 별도 앱 등록 목록의 빈 결과를 Terminal 종료로 판단하지 않습니다.
- 프로필 수집 중 원본 PID와 마이크로초 단위 시작 식별자를 고정하고 다시 확인합니다. 실제 소유자 확인도 같은 기준을 사용하며, 여러 Terminal 프로세스가 발견되면 하나를 임의로 선택하지 않습니다.
- 선택 탭 복원과 키 전달의 초점 확인은 정확한 원본 앱의 현재 AX frontmost 응답을 사용합니다. 기존 정확한 창·TTY·선택 탭 확인을 유지합니다.
- 프로세스 조회 검사에는 Terminal 내용·접근성 트리 조회나 키 전달이 없습니다. 별도 백그라운드 검사로 프로덕션 조회 팩토리를 독립 OS 프로세스 목록과 비교합니다.

검사·공개 배포·정식 `/Applications/AutoApprove.app` 설치 결과는 [검증 기록](../../VALIDATION.md)에 남깁니다. 실제 사용자 Terminal의 탭 선택·새 탭·CLI 복원은 도구 접근 정책으로 직접 실행하지 않았으며, 원래 오류를 내던 프로세스 조회와 격리 AppKit 검증을 구분합니다.
