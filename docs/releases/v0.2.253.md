# AutoApprove 0.2.253

로그인 전환 중 Goal을 일시정지한 직후 작업이 이미 끝나 중단 요청이 거절되는 경우를 개선했습니다. 같은 서버와 원래 실행 차례가 종료됐고 Goal·백그라운드 작업이 멈춘 것을 다시 확인한 경우 전환을 계속합니다.

종료 확인을 기다리는 동안 중단 명령을 다시 보내지 않습니다. 새 작업이 시작됐거나 Goal이 다시 활성화됐거나 서버·응답이 바뀐 경우에는 전환을 보류합니다. 대기 중인 입력은 유지합니다.

이 수정은 중단 완료 확인의 경합을 다룹니다. 독립 세션의 통합·분리와 실제 다른 계정·SSO 전환의 전체 검증은 계속 진행 중입니다.
