# AutoApprove 0.2.322 · build 349

앱을 다시 열 때 첫 세션 탐색이 끝나기 전에 보류 중인 그룹 초기화의 대상들을
종료로 기록하던 오류를 수정했습니다. 성공한 탐색 결과를 받은 뒤 원래 프로세스와
터미널을 확인해 대기 중인 요청을 처리합니다. `/clear` 전달을 이미 시도한
대상은 새 세션 ID만 확인합니다.

종료로 기록된 이전 요청은 결과 기록으로 유지됩니다. 다시 초기화할 대상만 골라
`clear_group_member`에 새 `requestID`를 지정할 수 있습니다.
[개별 초기화와 탭 표시 명령](v0.2.321.md)

릴리스 빌드에서 IP 네트워크를 차단한 그룹 검사 48개와 MCP 재연결 검사가
통과했습니다. 세션 탐색을 지연시킨 재시작 검사에서는 기록이 유지됐으며,
전달을 시도한 `/clear`가 다시 실행되지 않았습니다.
