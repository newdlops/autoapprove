# 0.2.277 · 로그인 그룹 이름 설정

- 계정 창의 ‘그룹 설정’에서 그룹을 선택하고 이름을 변경할 수 있습니다. 그룹의 물리적 홈, 로그인 정보와 연결된 대화는 그대로 유지합니다.
- 빈 이름, 중복 이름, 80자를 넘는 이름은 저장하지 않으며 저장 중·성공·실패 상태를 표시합니다.
- 이미 종료된 세션의 과거 연결 검토 기록이 공유 서버의 로그인 복구를 막는 문제를 수정했습니다. 현재 진행 중인 연결은 계속 검증합니다.
- 로그아웃된 서버에서도 세션 계정 화면의 ‘현재 로그인으로 재연결’을 사용할 수 있습니다. 활성 자식 Goal 등 서버가 안전한 중단을 허용하지 않는 경우에는 복구를 보류합니다.

기존 대화·세션을 다른 로그인 그룹으로 옮기는 기능은 아직 지원하지 않습니다. 이 버전은 그룹 이름 설정과 기존 복구 경로의 수정입니다.

검증: DEBUG·Release 빌드, 로그인 그룹 10개, 계정 전환 40개 및 계정 재연결 8개 검사. Release 재연결 8개도 통과했습니다. 실제 SwiftUI 시험 창에서 그룹 생성·이름 변경·빈 이름 저장 방지·긴 이름과 홈 경로·밝은 화면과 어두운 화면을 확인했습니다(600×660pt). 실제 사용자 세션을 옮기거나 실제 계정 인증 성공을 검증한 결과는 아닙니다.
