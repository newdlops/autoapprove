# AutoApprove 0.2.53 · 빌드 65

기존 Codex의 실행 파일 경로가 사라져 메시지·대기열 연결이 막히던 문제를 수정하고, 같은 네트워크의 Mac 사이에 자동 업데이트를 추가했습니다.

- Codex의 실행 중인 원래 서버에서 대기 입력을 직접 접수합니다. 원본 PID·시작 시각·TTY, 선택한 대화와 작업 폴더 확인을 유지합니다.
- 접수 ID·내용을 확인하며, 응답 불일치와 연결 종료 때는 중복 전송하지 않습니다.
- 최신 Mac은 자기 설치 앱을 제공하고 구버전 Mac은 체크섬·같은 게시자의 서명·버전·아키텍처를 검증한 뒤 스스로 교체합니다.
- **연결 설정 → 같은 네트워크에서 자동 업데이트**에서 끌 수 있습니다. 기본은 켜짐이며 웹 접속을 켠 동안 동작합니다.
- 별도 PTY·입력 전송·웹 질문·화면 공유가 진행 중이거나 덮개가 닫혀 있으면 적용을 기다립니다. 원본 Codex·Claude CLI와 기존 입력 서비스는 계속 실행됩니다.

각 Mac에 **0.2.53을 한 번 설치**하면 이후부터 자동으로 받습니다. 수신 기능이 없는 이전 버전은 첫 설치가 필요합니다. 휴대폰 설치나 외부 중계 서비스는 필요 없습니다.

설치 파일은 AutoApprove-0.2.53-macOS-arm64.dmg입니다. 실제 검증 범위와 다른 Mac의 적용 상태는 [VALIDATION.md](https://github.com/newdlops/autoapprove/blob/main/VALIDATION.md)에 기록합니다.
