# AutoApprove 0.2.245

셸 없이 login 바로 아래에서 실행되는 기존 Codex도 같은 창의 새 탭으로 관리형 서버에 연결할 수 있도록 복구 경로를 추가했습니다. 빈 복구 셸과 같은 창임을 먼저 확인하고, 기존 Codex를 정상 종료한 뒤 같은 대화 ID·저장 위치로 다시 엽니다. 결과가 불명확한 탭 생성·종료·실행은 반복하지 않습니다.

‘현재 로그인으로 세션 재연결’을 직접 요청하면 그 시점에 확인한 Codex 도구 호스트의 정상 종료도 함께 기다립니다. 새로 시작된 하위 작업·실행 중 작업·Goal·질문·작성 중 입력은 계속 보호합니다. 취소한 요청의 종료 허용은 남기지 않으며, 이전 프로세스가 실제로 종료되기 전에는 새 Codex를 시작하지 않습니다.

이후 저장 복구로 여는 Codex는 원본 셸을 유지합니다. Claude 복구 동작은 유지합니다.

빈 셸 대신 프로그램을 자동 실행하는 Terminal 프로필에서는 원래 세션을 유지하고 보류합니다. 실제 다른 Mac의 네이티브 탭 이동은 직접 검증하지 못했습니다. [검증 기록](../../VALIDATION.md).
