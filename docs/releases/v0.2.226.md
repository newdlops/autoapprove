# 0.2.226 · 질문 목차와 현재 읽는 위치

웹 관리자의 Codex 대화 기록을 본문과 질문 목차로 구성합니다. 메시지 선택기를 열지 않아도 어느 질문의 답변을 읽는지 확인할 수 있습니다.

- PC에서는 왼쪽 질문 목차에서 원하는 질문으로 이동하며, 스크롤에 맞춰 현재 항목을 강조합니다.
- 상단에 현재 읽는 질문을 유지합니다. 휴대폰과 태블릿은 목차를 기본 접어 본문 공간을 확보하고, 질문을 선택하면 목차를 다시 접습니다.
- 불러온 범위의 메시지 위치와 처음·최신 경계를 유지합니다. 앞뒤 기록을 이어 읽을 때 현재 위치를 보존하며, 질문이 많은 목차와 긴 코드도 각 영역 안에서 스크롤합니다.

읽기 전용 Codex 대화 API와 기존 터미널 전체 기록을 유지합니다. 원본 터미널 입력이나 작성 중인 메시지를 변경하지 않습니다. 검증 범위와 배포·설치 결과는 [검증 기록](../../VALIDATION.md)에 남깁니다.

Chromium·WebKit의 모바일/태블릿/PC 밝음·어두움 화면과 질문 이동·위치 동기화·긴 내용·오류 복구를 검증했습니다. 공개 설치 파일 4개를 재다운로드해 확인했고, 정식 경로 실행 **0.2.226/253**과 기존 원본 세션 **20/20개** 보존을 확인했습니다.
