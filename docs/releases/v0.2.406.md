# AutoApprove 0.2.406 · 빌드 433

세션 그룹 창의 ‘관계 그래프’에서 그룹 간 연결과 구성원 간 연결을 편집할 수 있습니다. 화살표는 상위에서 하위로 향합니다. 하나의 노드에 상위를 여러 개 지정하거나 양방향·순환 관계를 만들 수 있습니다.

그룹장은 MCP의 `get_group_topology`로 관리 범위를 조회하고 `set_group_relationship`로 연결 하나를 추가하거나 해제할 수 있습니다. 그룹 간 연결은 하위가 되는 그룹 쪽의 관리 권한을 확인합니다. 구성원 배정은 기존 그룹 안에서 이뤄지며, 진행 중인 작업은 원래 배정자에게 보고됩니다.
