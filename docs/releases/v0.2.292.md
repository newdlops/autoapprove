# AutoApprove 0.2.292

- 세션 그룹 상단의 **전체 세션 ID 갱신**으로 모든 구성원을 순서대로 조회합니다. 각 터미널의 `/status` 화면에서 ID를 읽는 기존 조회 방식을 사용합니다.
- 보류되거나 실패한 구성원은 기존 ID를 유지하고 다음 구성원을 계속 처리합니다. 갱신 수와 구성원별 오류를 표시합니다.
- 진행 순서를 표시하며, 중단을 요청하면 현재 조회가 끝난 뒤 남은 구성원부터 중단합니다.

검증: Release 빌드 성공. 격리 네이티브 앱에서 전체 갱신 버튼 클릭 후 실패해도 19개 모두 처리하는 것과 최종 건수·구성원별 이유 펼침을 확인했습니다. 화면은 700×480, 860×640, 1100×800 밝고 어두운 테마로 렌더링했습니다. 실제 사용자 터미널의 조회 성공과 중간 중단 클릭은 이번 검증에 포함하지 않았습니다. 기존 개별 조회의 입력창·메뉴 보류 조건을 그대로 사용합니다.
