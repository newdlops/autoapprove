AutoApprove 설치 안내

설치는 아래 명령을 터미널에 입력해 시작합니다.
다운로드한 설치 파일을 더블클릭하면 macOS에서 실행 전에 차단할 수 있습니다.

1. 기존 AutoApprove가 실행 중이면 메뉴 막대에서 종료합니다.
2. DMG를 열어 둔 상태에서 macOS의 터미널 앱을 엽니다.
3. 아래 한 줄을 터미널에 복사하고 Return을 누릅니다.

{{INSTALL_COMMAND}}

   앱 검사 → Applications에 복사 → 다운로드 차단 표시 제거 → 앱 실행이 이어집니다.
   관리자 권한이 필요하면 터미널에서 Mac 로그인 암호를 입력합니다.
   암호를 입력하는 동안 화면에 글자가 표시되지 않는 것은 정상입니다.
4. 앱이 열리면 DMG를 추출합니다.
5. 연결 설정에서 Terminal 또는 VS Code 연결을 설정합니다.
   VS Code 확장은 앱에 포함되어 있습니다. 알림도 허용해주세요.
6. 원하는 세션의 자동 승인을 켭니다. 처음 설치하면 기본값은 꺼짐입니다.

지원 환경: macOS 14 이상. DMG 파일명의 arm64는 Apple Silicon용입니다.
Claude Code와 Codex는 별도로 설치하고 터미널에서 실행해야 합니다.
SSH, Dev Containers, WSL은 지원하지 않습니다.

파일을 찾을 수 없다고 나오는 경우:
  같은 DMG를 여러 번 열면 디스크 이름 뒤에 숫자가 붙을 수 있습니다.
  터미널에 /bin/bash 를 입력하고 뒤에 공백을 한 칸 넣은 다음,
  현재 DMG 안의 install.sh를 터미널 창으로 드래그하고 Return을 누릅니다.

0.2.23 이하에서 '설치 및 실행.command'를 휴지통에 버리라고 나오는 경우도
위와 같이 /bin/bash 뒤에 해당 파일을 드래그해 실행할 수 있습니다.
DMG를 여는 것만으로 설치가 자동 실행되지는 않습니다.

설치 스크립트는 복사한 AutoApprove.app의 com.apple.quarantine 속성만
하위 파일까지 제거합니다. 권한이 부족하면 sudo로 같은 작업을 수행합니다.
다른 앱이나 시스템 전체의 보안 설정은 변경하지 않습니다.
기존 앱이 실행 중이면 종료를 안내하고, 파일 검사·복사·인증 실패 시에는
기존 앱을 교체하지 않습니다. 앱을 교체해도 설정과 승인 내역은 유지됩니다.

수동으로 설치하려면 AutoApprove.app을 Applications로 드래그합니다.
이 빌드는 ad-hoc 서명이며 Developer ID 서명과 Apple 공증을 받지 않았습니다.
개발자 확인 경고가 나타나면 출처를 확인한 뒤 Apple 안내를 따르거나,
위 터미널 명령으로 앱을 다시 설치할 수 있습니다.
https://support.apple.com/ko-kr/102445
신뢰할 수 있는 앱에 한해 시스템 설정 > 개인정보 보호 및 보안에서
'그래도 열기'로 해당 앱의 실행을 허용할 수 있습니다.

설정과 승인 내역은 앱 밖에 저장되므로 앱을 교체해도 유지됩니다.
~/Library/Application Support/AutoApprove/
