# AutoApprove 0.2.195 · build 222

고해상도 스크롤과 터미널·화면 입력의 송신 대기를 안정화합니다.

- 작은 휠 이동을 누적해 소수 픽셀이 매 이벤트마다 사라지던 문제를 수정합니다. 같은 지점·방향·보조키의 미전송 스크롤을 16ms 간격으로 합쳐 전송량과 입력 대기열을 줄입니다.
- 두 손가락 스크롤은 시작 지점에 고정합니다. 클릭·키보드·버튼 해제·다른 방향/대상의 입력 순서와 패킷 상한을 유지합니다.
- 브라우저 송신 버퍼가 찼다가 비워진 경우, 추가 키 입력이나 확인 응답 없이 대기 중 입력을 재개합니다. 필요한 동안만 제한된 간격으로 확인하고, 20초 이상 막히면 기존 복구 규칙에 따라 종료합니다.
- 연속 전송의 상태 알림을 합치고, 가장 오래된 확인 응답 타이머를 불필요하게 다시 만들지 않습니다. 확인 제한 시간을 연장하거나 미확인 입력을 재전송하지 않습니다.
- 기존 화면 조건부 전송·무응답 감지·구형 HTTP 호환·PIN·PortManager 동작을 유지합니다.
