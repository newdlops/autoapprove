# AutoApprove 0.2.418 · 빌드 445

세션 프로필 편집기에서 대화 ID가 비어 있는 Codex 항목의 **이 탭의 대화 ID 조회**를 누를 수 있습니다. Terminal과 iTerm2에서 현재 탭의 프로세스와 대화 이름을 확인하고, 이름으로 식별하기 어려우면 해당 탭의 빈 입력창에 `/status`를 보내 새 응답을 확인합니다. 기존 상태 카드와 새 응답을 구별해야 할 때는 `/pwd`로 경계를 표시합니다. 조회 결과는 프로필 저장에 사용합니다. 조회 중 원래 탭이나 대화가 바뀌면 저장을 보류하고, 새 대화의 시작 화면을 감지하면 이전 조회 결과를 폐기합니다. 기본 프로필 저장은 계속 터미널을 조작하지 않습니다.

창 미리보기를 다시 열 때 같은 터미널 앱의 다른 입력이 취소되던 문제를 수정했습니다. 화면과 기록을 확인하는 요청은 터미널이 사용 중일 때 잠시 차례를 기다립니다. Claude 메시지의 Enter와 같은 대화로 재시작하는 명령은 입력 전 경합이 확인되면 다시 시도하며, 전송 결과가 불분명한 명령은 반복하지 않습니다.
