# 0.2.138 · 일반 질문의 반복 모델 분석 생략

모델과 무관한 선택 질문은 모델 유지 판정을 위해 전체 대화 문맥을 다시 만들지 않습니다. 이미 감지한 질문 요약에서 모델 관련 내용을 먼저 확인한 뒤, 필요한 경우에만 기존 메뉴 분석을 실행합니다. 원래 모델 유지 판정에도 모델 언급이 필요하므로, 자동으로 선택할 수 있는 모델의 범위를 넓히거나 줄이지 않습니다. 일반 질문은 계속 웹에서 직접 답합니다.

실제 Release Core에 같은 합성 Cocoa 화면 16개를 500회 갱신하는 검사를 0.2.137과 수정본에서 세 쌍 교대 실행했습니다. 출력이 바뀌는 구간의 CPU 중앙값은 **8.149903 → 5.922947초**, 경과 시간은 **8.964204 → 6.637969초**였습니다. 변경 없는 화면 CPU는 **0.483074 → 0.498279초**로 비슷한 수준이며 이 구간의 절감을 주장하지 않습니다. 네 상태 각 4개와 갱신 0/500회, 입력·감사 기록·캡처 없음이 유지됐습니다. 사용자 터미널 조회와 서버를 실행하지 않은 합성 Core 비교이므로, 실제 앱 전체 CPU나 휴대폰·VPN 연결 지연의 개선율은 아닙니다.

Codex·Claude의 현재 모델 유지, 모델 변경 거절, 원본 대상 재검사, 일시정지·자동 승인 해제·수동 입력·질문 변경에 따른 취소와 중복 전송 방지는 그대로 유지합니다. 새로운 타이머·캐시·상주 서비스나 시스템·보안·VPN 설정 변경은 추가하지 않습니다.

최종 Release **367/367개**, 현재 모델 전용 **5/5개**가 통과했습니다. 실제 패키지의 격리된 훅에서 자동 응답 **12건**과 일반·복수·현재 모델이 불명확한 질문의 명시적인 웹 응답 대기 **12건**, 일시정지·재시작·응답 유실·중복 방지 검사를 통과했습니다. loopback 웹·MCP·합성 PTY·포트 복구, 입력 구성요소·발행자 서명과 DMG 무결성도 확인했습니다. 실제 사용자 터미널 입력이나 휴대폰 QA 결과는 아닙니다.

macOS 14 이상 Apple Silicon용이며 빌드는 165입니다. 기존 발행자 인증서를 재사용합니다. 설치 방법은 [설치 안내](../../README.md#설치)를 참고하세요.
