# AutoApprove 0.2.85

여러 터미널의 긴 출력을 한꺼번에 분석할 때 Mac 앱의 화면이 멈추는 구간을 줄였습니다. 터미널 화면의 승인·질문·오류 분석을 호스트별 백그라운드 작업에서 처리하고, 분석이 끝난 결과만 UI에 함께 반영합니다.

원본 CLI, 자동 승인·오류 이어가기, 사용자 초안과 시스템 변경 보호는 유지합니다. 분석 중 원본 세션이 교체되거나 연결이 해제되면 이전 결과를 적용하지 않습니다. 새로운 권한이나 자동 실행 서비스는 추가하지 않습니다.

각 Mac은 0.2.85 · 빌드 109로 업데이트해주세요. 휴대폰에는 설치할 것이 없습니다. 사용자가 강제 종료한 실제 멈춤 당시의 스택은 확보하지 못했으며, 이번 수정은 긴 출력 부하에서 재현한 UI 정지 경로를 개선한 것입니다.
