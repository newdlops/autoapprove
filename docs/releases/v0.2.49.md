# AutoApprove 0.2.49 · 빌드 60

여러 Mac을 사용하는 동안 목록 조회가 늦으면 휴대폰의 정상 터미널 입력까지 끊기던 문제를 수정했습니다.

- 전체 목록 요청이 성공해도 선택한 Mac의 상태 조회가 시간 초과되면, 해당 원본의 독립적인 화면 스트림과 키보드 포커스를 유지합니다.
- 화면 재연결 중에는 미전송 입력을 보관하고, 같은 원본의 최신 화면을 확인한 뒤 이어서 전달합니다. 결과를 확인하지 못한 전송은 재시도하지 않습니다.
- 목록의 Mac 연결 상태와 전체 제어는 확인된 상태대로 표시합니다. 온라인 목록에서 원본 세션이 사라지거나 권한·PID·시작 시각·TTY·실행 세대가 바뀌면 입력을 멈춥니다.

각 Mac을 최신 버전으로 업데이트하고 휴대폰 페이지를 한 번 새로고침해주세요. 새 PTY나 대화를 만들지 않으며 휴대폰에는 설치하지 않습니다.

검증 범위와 실제 휴대폰 확인 상태는 [VALIDATION.md](https://github.com/newdlops/autoapprove/blob/main/VALIDATION.md)에 기록합니다. 설치 파일은 `AutoApprove-0.2.49-macOS-arm64.dmg`입니다.
