# AutoApprove 0.2.431 · 빌드 458

실행 중인 Codex 그룹장에게 긴급 권한 요청이나 우선 회신 요청을 전달하면서 Escape 입력으로 Goal을 일시중지하던 문제를 수정했습니다. 완료 전인 Goal이 있거나 상태를 확인할 수 없으면 요청을 수신함에 보관합니다. 그룹장은 MCP에서 즉시 요청을 확인할 수 있고, 터미널 전달은 입력 가능한 시점에 진행합니다.

상위 그룹장이 없는 Codex 그룹장이 자기 자신에게 Goal 차단 검토를 요청해 자동 재개가 계속 보류되던 문제를 수정했습니다. 자동 진행이 켜져 있고 해당 그룹장에게 진행 중인 필수 대기가 없으면 기존 재개 절차를 따릅니다. 상위 그룹장이 있는 구성원의 차단 알림은 담당 그룹장에게 전달됩니다.

이전 버전에서 그룹장이 자기 자신에게 보낸 미처리 Goal 차단 알림은 수신 기록에 보존하고 전달 대기열에서 제외합니다.

사용자가 취소한 자동 재개는 앱을 다시 실행해도 같은 차단 화면에서 반복하지 않습니다.
