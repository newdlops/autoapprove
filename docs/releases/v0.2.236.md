# 0.2.236 · Codex 자동승인 줄바꿈·새 화면 복구

창을 좁혔을 때 일반 승인과 백그라운드 에이전트 승인 메뉴의 `Yes, proceed`·거부 문구·키보드 안내가 단어 중간으로 나뉘어 인식되지 않던 경로를 수정했습니다. 선택지 끝의 `(esc)` 조각을 하단 안내로 오인하던 경우와, 실행 이유의 `Allow …` 문장을 승인 제목으로 고르던 경우도 보완했습니다.

입력 직전 확인에서 화면이 바뀌어 **입력을 보내지 않았음이 확인되면** 해당 원본 탭을 새로 읽어 다시 판별합니다. 화면 크기 변경·스크롤이나 다음 출력 이벤트를 기다리지 않고 최신 요청을 확인합니다. 새 화면이 일반 질문이면 자동으로 답하지 않습니다.

재조회가 느리더라도 내용이 같은 기존 화면의 반복 수신 때문에 새 읽기를 버리지 않습니다. 읽는 도중 실제로 다른 화면이 들어오면 해당 화면을 우선합니다.

완전한 메뉴에서 선택된 1회 승인만 처리합니다. 잘린 화면·알 수 없는 선택지·일시정지·자동승인 끄기·새 질문을 보존하며, 전달 결과가 불명확하거나 이미 보낸 입력은 이 경로로 반복하지 않습니다. 명령·대화 원문과 원래 프로세스는 입력 직전 다시 검증합니다.

합성 화면·독립 PTY와 실제 승인 스크립트의 모의 Terminal로 검증합니다. 사용자 Terminal을 시험 조작하지 않았으며, 사용자가 관찰한 모든 정지 원인을 하나로 확정한 것은 아닙니다. [검증 기록](../../VALIDATION.md).
