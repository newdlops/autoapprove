# AutoApprove 0.2.396 · 빌드 423

- 그룹장은 `manage_group_task`에 현재 직속 구성원의 taskID를 지정해 작업을 인수(takeOwnership)하거나 보고 없이 종료(closeWithoutReport)할 수 있습니다. 대화 기록을 보존합니다.
- `assign_group_task`에 afterTaskID와 고유 requestID를 지정하면 선행 작업이 완료되고 대상이 대기 상태가 될 때 구성원의 예약 순서대로 배정합니다. 예약 취소는 manage_group_task의 cancelQueued입니다.
- `send_group_message(asTask: true)`는 정식 배정 경로를 사용합니다. 일반 메시지는 기존과 같이 보관함으로 전달됩니다.
- `retry_group_submission`은 원래 메시지·배정 ID, 현재 대화 및 입력창이 일치하는 경우 Enter를 전달합니다. enterSent는 제출 키를 보냈다는 뜻입니다.
- `get_group_status(view: "overview")`에서 마지막 보고 요약, 현재 소유자와 배정 시각, 대기열, 입력창, 남은 셸 수와 backgroundOnly를 확인할 수 있습니다.
- 터미널 하단의 ‘1 shell still running’을 인식하며 Claude의 실행 래퍼 아래 전용 프로세스 그룹과 현재 대화의 작업 출력 파일도 확인합니다. 개수만 확인된 작업은 countOnly로 표시합니다.
