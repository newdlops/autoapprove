# 0.2.229 · 도구·레포별 선택 복원

저장한 세션 프로필에서 Codex만, Claude만 또는 특정 레포의 세션만 골라 복원할 수 있습니다.

- 전체/Codex/Claude 필터와 레포 선택을 함께 적용합니다. 같은 Git 레포의 하위 작업 폴더를 묶고, 레포를 찾을 수 없으면 저장된 작업 폴더로 구분합니다.
- 이름·레포·작업 폴더·대화 ID를 검색하고 저장 순서·레포·도구·이름을 오름차순/내림차순으로 정렬합니다. 목록 정렬과 별개로 실제 복원은 저장된 창·탭 순서를 유지합니다.
- 개별 체크와 표시 항목 일괄 선택/해제를 제공합니다. 복원 버튼에 실제 대상 개수를 표시하며 필터 밖의 체크 항목은 실행하지 않습니다.
- 대화·창 세부 정보는 펼쳐서 보고, 프로필을 바꾸면 필터·선택·이전 복원 결과를 초기화합니다. 부분 복원 후 마지막으로 선택하는 탭도 복원 대상 안으로 제한합니다.

전체 Core **618/618**, 생산 컨트롤러의 선택 복원 검사 **22개**가 통과했습니다. 합성 실행기로 실제 Mac UI의 필터·검색·개별/일괄 선택·정렬·단축키·중복 방지를 확인하고, 별도로 세 창 크기의 밝은/어두운 렌더와 빈 결과·선택 없음·긴 오류를 점검했습니다. 실제 사용자 Terminal을 실행하는 복원 시험은 수행하지 않았습니다.

검사 및 배포 결과는 [검증 기록](../../VALIDATION.md)에 남깁니다.
