# AutoApprove 0.2.185 · build 212

Cloudflare 설정을 쉽게 시작할 수 있도록 연결 설정을 개선했습니다.

- **임시 주소 만들기** 버튼 하나로 필요한 연결 도구 설치와 웹 접속을 준비합니다.
  임시 주소의 내부 포트는 자동 배정하며 준비 중 취소할 수 있습니다.
- 고정 도메인은 Cloudflare 터널 화면 바로가기와 단계별 안내를 제공합니다.
  macOS 설치 명령 전체를 붙여넣으면 토큰만 추출하며, 도메인만 입력하면 HTTPS를
  보완합니다. 서비스 주소는 버튼으로 복사할 수 있습니다.
- Cloudflare의 공개 경로 설정을 마칠 때까지 연결 도구를 유지합니다.
  **공개 주소 확인**으로 다시 검사하며 실제 인증 게이트웨이 확인 후 링크·QR을 제공합니다.
- 연결 도구가 짧은 로그만 출력할 때 연결 완료 신호를 늦게 읽는 문제도 수정했습니다.

고정 도메인에는 본인의 Cloudflare 계정·등록된 도메인·터널 토큰이 필요합니다.
현재 검증 네트워크의 외부 TCP 7844 도달 불가로 실제 인터넷 경유 연결 검증은
남아 있습니다. 인증·입력·공개 경로 대기/재확인과 네이티브 설정 조작은 합성 환경에서
검증했으며 사용자 터미널은 외부에 공개하지 않았습니다.
