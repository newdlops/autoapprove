# AutoApprove 0.2.186 · build 213

Cloudflare 고정 주소 연결을 **한 번 승인 → 등록된 도메인 선택 → 연결**로 줄였습니다.
별도 서버 운영이나 터널 토큰 복사가 필요 없습니다.

- 공식 Cloudflare 브라우저 화면에서 사용자가 직접 승인하면 앱에서 활성 도메인을 선택합니다.
- 앱이 터널·DNS·인증 웹 접속·내부 포트를 준비합니다. 실제 공개 주소 확인 후 링크와 QR을 제공합니다.
- 기존 DNS는 유지하고 비어 있는 주소를 찾습니다. 통신 중 생성 응답이 유실돼도
  재시도할 때 이전 결과를 확인해 터널과 DNS 중복 생성을 줄입니다.
- 계정 승인 정보는 앱 전용 키체인에 보관하고 연결 도구에는 해당 터널의 실행 정보만
  전달합니다. 취소·앱 종료 시 이 앱이 실행한 승인/연결 도구와 임시 파일을 정리합니다.
- 임시 주소, 토큰 직접 입력, 기존 로컬 터널 연결도 계속 선택할 수 있습니다.

본인의 Cloudflare 계정과 활성 도메인이 필요하며 계정 승인은 사용자가 직접 완료합니다.
최종 467개 핵심 검사와 두 브라우저의 인증·격리 터미널 검사를 통과했습니다.
합성 계정/API·네이티브 조작과 공식 연결 도구의 설정 검증으로 승인/재시도 경로를 확인했습니다.
현재 검증 네트워크의 Cloudflare edge TCP 7844 도달 불가로 실제 사용자 계정의 DNS 생성과
인터넷 경유 접속은 미검증 범위로 남습니다.
