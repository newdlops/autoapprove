# 0.2.233 · Codex 브라우저로 간편 로그인

**연결 설정 → Codex → 브라우저로 로그인**을 누르면 기본 브라우저의 공식 로그인 페이지가 열립니다. 사용할 계정으로 로그인하면 AutoApprove에서 완료를 확인합니다. Mac의 이 흐름은 ChatGPT 기기 코드 설정을 켜거나 코드를 복사할 필요가 없습니다.

페이지가 열리지 않거나 닫았다면 **로그인 페이지 다시 열기**를 사용합니다. 여러 Codex 홈이 연결되어 있으면 대상을 선택할 수 있으며 취소와 진행 상태도 같은 화면에 표시합니다. 진행 중인 전환이 있으면 새 로그인을 기다립니다.

앱에서 로그인을 완료하면 자동 전환을 켜고 그 공통 서버에 연결된 열린 Codex 세션 전체에 새 계정을 반영합니다. **작업 순차 중단 → 모두 대기 확인 → 공통 서버 전환 → 원래 창·대화 재연결**을 앱 엔진이 처리하므로 연결 설정을 닫아도 이어집니다. 활성 Goal은 일시정지하고 Codex 백그라운드 작업은 공식 API로 종료한 뒤 실행 중인 차례를 정상 중단합니다. 대기 메시지는 삭제하지 않으며 남아 있으면 서버 전환을 기다립니다. 별도 Codex 홈으로 인증 정보를 복사하지 않습니다.

AutoApprove는 새 프롬프트나 작업 재개 요청을 보내지 않고 중단한 작업을 대기 상태로 둡니다. Codex 자체 입력창에 이미 예약한 사용자 입력은 Codex의 기존 처리 방식을 따릅니다.

공식 CLI의 기본 `codex login`이 브라우저 열기·로컬 콜백·인증 정보 저장을 처리합니다. AutoApprove는 비밀번호나 토큰을 읽거나 입력하지 않습니다. 브라우저 로그인의 URL은 공식 Codex 클라이언트·PKCE·루프백 콜백을 검증하며 인증 쿼리를 화면에 표시하지 않습니다. 웹에서 시작하는 기존 기기 코드 로그인과 PIN 인증은 유지합니다.

이전 버전의 빈 대화 `-32600` 수정은 유지합니다. 공통 서버가 대화 기록을 소유하므로 개별 TUI에 기록 파일이 열려 있지 않아도 전환할 수 있습니다. 원래 프로세스 전부가 현재 서버에 연결됐는지, 원래 대화 기록이 보존됐는지, 새 서버 계정과 최종 대기 상태가 맞는지 다시 확인해야 완료로 표시합니다. 화면 밖 대화를 억지로 불러오지 않으며 불명확한 중단·재시작 명령은 반복하지 않습니다. [검증 기록](../../VALIDATION.md).
