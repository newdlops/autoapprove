AutoApprove 설치 안내

1. 기존 AutoApprove가 실행 중이면 메뉴 막대에서 종료합니다.
2. DMG 안의 AutoApprove.app을 옆의 Applications 폴더로 드래그합니다.
3. 기존 앱을 바꿀지 물으면 교체를 선택합니다.
   Finder가 권한을 요청하면 시스템 창에서 Mac 로그인 암호를 입력합니다.
4. 복사가 끝나면 Finder의 응용 프로그램 폴더에서 AutoApprove를 엽니다.

앱을 복사해 설치하는 과정에는 터미널 명령이 필요하지 않습니다.
복사가 끝나면 DMG를 추출해도 됩니다.
기존 설정과 승인 내역은 유지됩니다.

처음 열 때 개발자를 확인할 수 없다는 경고가 나오는 경우:
  이 배포본은 Developer ID 서명·Apple 공증을 받지 않았습니다.
  공식 배포 파일임을 확인한 뒤 아래 방법으로 해당 앱을 허용하세요.
  1. 경고 창에서 '완료' 또는 '취소'를 누릅니다.
  2. Apple 메뉴 → 시스템 설정 → 개인정보 보호 및 보안을 엽니다.
  3. 아래로 내려가 AutoApprove의 '그래도 열기'를 누릅니다.
  4. 다시 표시되는 창에서 '열기'를 선택합니다.
  이 최초 허용은 macOS가 요구하는 절차이며 자동으로 생략하지 않습니다.
  회사에서 관리하는 Mac은 관리자 정책에 따라 허용이 제한될 수 있습니다.
  Apple 안내: https://support.apple.com/ko-kr/102445

'손상됨' 경고가 나오는 경우:
  DMG를 공식 릴리스에서 다시 받아 설치해주세요.
  다시 받아도 동일하다면 경고에 나온 파일 이름과 문구를 알려주세요.
  손상 경고만으로 파일 손상과 실행 차단의 원인을 구분할 수는 없습니다.

이 DMG는 앱을 복사하는 방식이며, 다운로드 차단 속성을 자동으로 제거하는
설치 스크립트는 실행하지 않습니다. DMG 형식만으로 macOS의 실행 경고가
사라지는 것은 아닙니다.

처음 사용하기:
  앱의 연결 설정에서 Terminal 또는 VS Code를 연결합니다.
  VS Code 확장은 앱에 포함되어 있습니다. 알림도 허용해주세요.
  원하는 세션의 자동 승인을 켭니다. 처음 설치하면 기본값은 꺼짐입니다.

휴대폰에서 실행 중인 Terminal CLI에 직접 입력하기:
  Mac의 연결 설정 → 원본 터미널 화면·입력 → '직접 입력 연결'을 누릅니다.
  정상 연결된 기존 입력 서비스는 재설치하지 않고 계속 사용합니다.
  새 연결은 macOS의 정식 서비스 등록 기능을 사용합니다. 등록 후
  시스템 설정 → 일반 → 로그인 항목 및 확장 프로그램에서 AutoApprove의
  백그라운드 실행을 허용합니다. 승인 대기 중이면 '허용 설정 열기'를 누르세요.
  새 등록에는 Developer ID로 서명하고 Apple 공증을 받은 앱이 필요합니다.
  현재 자체 서명 후보는 새 등록을 차단하고 기존 연결을 유지합니다.
  이전 관리자 셸 설치 경로는 사용하지 않습니다.
  실행 중인 CLI의 PID와 TTY를 유지하며 새 터미널이나 대화를 만들지 않습니다.
  이 직접 입력에는 손쉬운 사용 권한이 필요하지 않습니다.
  같은 핫스팟의 휴대폰 브라우저에서 연결 설정에 표시한 주소를 엽니다.
  휴대폰에는 앱이나 프로필을 설치할 필요가 없습니다.
  기본 화면은 텍스트 터미널입니다. 실제 Mac 창은 'Mac 창 보기'를 켤 때만
  공유하며, 이 선택 기능에는 Mac의 화면 기록 권한이 필요합니다.

무료 tmux 원본 공유 (0.2.44 빌드 55):
  이 방식을 사용하려면 공유할 각 Mac에 tmux를 설치해야 합니다.
  공유 대상 Codex·Claude도 tmux 안에서 실행해야 합니다.
  휴대폰에는 tmux나 별도 앱을 설치하지 않습니다.
  Homebrew를 사용하는 Mac의 설치 명령: brew install tmux
  설치 확인: tmux -V
  실행 중인 tmux 세션 확인: tmux list-sessions
  Mac의 연결 설정 → tmux로 같은 터미널 공유에서 '시작 명령 복사'를 누릅니다.
  Mac 터미널에서 붙여 넣거나 tmux new-session -A -s autoapprove를 실행한 뒤
  그 안에서 Codex 또는 Claude를 시작합니다. 이미 tmux 안에서 실행 중이면
  '연결 확인'만 하세요. 휴대폰에서 같은 원본의 색상·커서·입력을 사용합니다.
  이 공유에는 유료 Apple 개발자 계정, 관리자 입력 서비스, 손쉬운 사용,
  화면 기록 권한이 필요하지 않습니다. 정상 연결된 기존 입력 서비스도 유지됩니다.
  tmux 설치만으로 기존 Terminal 작업이 자동 전환되지는 않습니다.
  tmux 밖의 기존 CLI는 종료하거나 바꾸지 않습니다. 기존 대화를 이어가려면
  해당 CLI의 이어하기 기능을 사용자가 선택해야 합니다.
  웹 접속·재시도·연결 해제는 새 대화나 PTY를 만들지 않고 창 크기도 유지합니다.
  공식 설치 안내: https://github.com/tmux/tmux/wiki/Installing

지원 환경: macOS 14 이상. arm64 배포 파일은 Apple Silicon용입니다.
Claude Code와 Codex는 별도로 설치하고 실행해야 합니다.
SSH, Dev Containers, WSL은 지원하지 않습니다.

설정과 승인 내역은 앱 밖에 저장되므로 앱을 교체해도 유지됩니다.
