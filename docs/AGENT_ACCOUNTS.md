# 다른 Mac의 Codex·Claude 로그인

관리 페이지에서 대상 Mac의 **AI 계정**을 누릅니다. 실행 중인 세션이 없어도 사용할 수 있습니다. 같은 Wi-Fi·핫스팟에서는 현재 LAN 주소로 직접 연결하고, 외부에서는 기존 Cloudflare 주소로 접속합니다. 이 기능이 외부 터널을 자동으로 켜지 않습니다.

1. 선택한 Mac의 **접속 PIN**을 입력합니다. Mac의 **연결 설정 → 외부 접속**에서 PIN만 먼저 설정할 수 있으며 Cloudflare 연결은 필요하지 않습니다. 같은 페이지에서는 15분 동안 다시 입력하지 않습니다.
2. **Codex 로그인** 또는 **Claude 로그인**을 누릅니다. Codex는 표시된 코드를 복사하고 **공식 인증 페이지 열기**에서 입력합니다. Claude는 공식 페이지에서 인증한 뒤 표시된 일회용 코드를 이 창에 붙여넣고 **로그인 완료**를 누릅니다.
3. 대상 CLI가 정상 종료하고 로그인 상태가 확인되면 **로그인됨**으로 바뀝니다. **Codex 시작 / Claude 시작**을 누르면 대상 Mac의 기본 홈 폴더에서 별도 터미널을 엽니다. 자동 승인은 꺼진 상태로 시작합니다.

Mac마다 AutoApprove **0.2.196 이상**과 해당 CLI가 필요합니다. Codex 기기 코드 인증은 계정의 보안 설정 또는 워크스페이스 권한에서 허용돼 있어야 합니다. CLI를 찾지 못하면 대상 Mac에 설치하고 **로그인 상태 확인**을 누르세요. 키체인이 잠겼다면 해당 Mac에서 잠금을 해제하세요.

로그인은 AutoApprove가 사용하는 macOS 사용자와 로그인 셸의 기본 CLI 환경에 적용합니다. 별도의 `CODEX_HOME`·`CLAUDE_CONFIG_DIR`·프로필을 사용하는 기존 세션은 해당 환경에서 별도로 확인해야 합니다. API 환경변수가 우선하는 상태는 **API 설정 사용 중**으로 표시합니다. 계정 로그인과 구독·조직의 모델 사용 권한은 별개이며 확인을 위해 유료 모델 요청을 보내지 않습니다.

다른 앱의 작업 중인 터미널에 로그인 명령이나 인증 코드를 입력하지 않습니다. 로그인 전용 프로세스는 세션 목록·일반 터미널 기록·자동 승인에서 제외합니다. 창을 닫아도 최대 10분 동안 인증을 기다리므로 같은 페이지에서 다시 열어 이어갈 수 있습니다. 새로고침해 이전 관리 연결을 잃었다면 PIN을 확인한 뒤 진행 중 로그인을 취소하고 새로 시작할 수 있습니다. 취소는 해당 도구의 인증 프로세스만 끝내며 기존 로그인 정보를 지우지 않습니다.

통신이 끊기면 현재 입력을 다시 보내지 않고 **로그인 상태 확인**으로 결과를 확인합니다. 만료된 인증은 새 로그인으로 시작합니다. PIN 변경·해제는 진행 중인 인증과 관리 권한을 종료합니다. 앱 업데이트도 인증을 마치거나 취소할 때까지 기다립니다.

PIN·일회용 코드·인증 링크는 요청과 응답을 암호화해 전달하고 브라우저 저장소·일반 목록·전송 영수증에 보관하지 않습니다. 장기 인증 정보는 공식 CLI가 대상 Mac에 저장합니다. LAN은 기존 제품과 같은 신뢰할 수 있는 네트워크를 전제로 하며, HTTP로 받은 페이지 자체의 능동 변조까지 인증하는 기능은 아닙니다.

공식 안내: [OpenAI 기기 코드 인증](https://learn.chatgpt.com/docs/auth#login-on-headless-devices), [Claude 인증](https://code.claude.com/docs/en/authentication). 화면·전송 검증과 실계정 승인 범위는 [검증 기록](../VALIDATION.md)에 구분합니다.
