# 0.2.224 · 줄바꿈된 Claude 모델·사용량 상태 인식

좁은 화면에서 Claude 상태 줄의 모델명·컨텍스트·사용량 부분이 여러 행으로 나뉘면 정상 입력 대기를 미확인으로 남기던 경우를 보완합니다.

- 프로젝트·브랜치 구분자가 첫 행에 모두 보이고, 뒤의 연속 행이 기존 모델·사용량 문법과 일치할 때만 복원합니다. 단축키 안내·구분선을 넘어 문구를 합치지 않습니다.
- 실제 입력창과 CLI 단축키 안내가 필요합니다. 초안·숫자 메뉴·별도 질문·불완전하거나 알 수 없는 문구는 기존대로 구분합니다. 권한 질의에 사용하는 원본 화면은 변경하지 않습니다.
- 프로젝트·브랜치 자체가 줄바꿈된 경우는 새 문구와 구분할 근거가 부족해 미확인으로 유지합니다. 전체 창 크기·스크롤 문제를 해결했다고 주장하지 않습니다.

실제 libvterm 셀의 여러 폭·높이와 합성 원본을 검증 대상으로 사용합니다. 컴퓨터 조작 도구가 Terminal 앱 접근을 차단했으므로 실제 Terminal 창 크기·스크롤 조작 검증은 수행하지 못했습니다. 상세 결과와 나머지 연결 안정성 작업은 [검증 기록](../../VALIDATION.md)에 남깁니다.

최종 전체 Core **616/616**, footer 회귀 **7/7**, 폭 40~120칸·높이 24/40의 **70개 셀 조건**과 Core·HTTP·Chromium/WebKit의 상태/단절·복구 검사가 통과했습니다. 기존 30개 셀 진단에서는 미확인 **8개→0개**를 확인했습니다. 브라우저 쓰기 요청과 터미널 입력은 0회였습니다.

설치 파일 4개를 공개 다운로드로 검증하고 `/Applications/AutoApprove.app` 실행 **0.2.224/251**을 확인했습니다. 기존 원본 **19/19개**와 실제 Codex 대화 조회를 유지했습니다.
