# AutoApprove 0.2.430 · 빌드 457

세션 목록과 그룹을 새로고침하면 해당 대화의 모델과 추론 수준도 다시 조회합니다. Codex에서는 같은 설정 홈·대화 ID·작업 폴더를 확인한 뒤 현재 설정을 읽습니다. 같은 홈의 대화는 하나의 연결을 공유하고 대화 본문은 서버에 요청하지 않습니다. 서버에서 설정을 제공하지 않으면 해당 대화의 설정 기록을 확인합니다.

재시작할 때는 처음 CLI를 실행하면서 넘긴 추론 옵션을 제거하고 현재 대화에서 확인한 값을 한 번만 적용합니다. 수준이 해제됐거나 확인할 수 없으면 CLI에서 결정합니다. Claude 대화에서는 설정한 수준과 개별 턴의 처리 수준을 구분합니다.

기존 대화를 이어가는 세션 프로필은 조회·캡처·복원 시 최신 추론 수준을 반영합니다. 이전 버전에서 자동으로 저장한 값도 이 규칙을 따릅니다. 새 CLI의 시작 설정과 이번 버전부터 프로필 편집기에서 직접 선택한 추론 수준은 지정한 값으로 실행합니다.

Terminal 프로필의 창 배치를 읽을 때 현재 탭과 숨은 탭의 제목·순서를 조회합니다. 숨은 탭을 고유하게 식별할 수 없으면 배치 저장을 멈추고 어느 부분을 확인해야 하는지 안내합니다. 복원 중에는 기존 창의 선택을 유지하고, 사용자가 Terminal에서 작업하는 동안에는 새 탭이나 창을 만드는 동작을 보류합니다.

직접 키 입력은 원래 탭이 이미 선택되어 있고 해당 창의 터미널 입력 영역에 초점이 있을 때만 전달합니다. 다른 앱이나 탭으로 이동하면 남은 입력을 중단합니다. Terminal을 사용 중일 때 다른 탭의 선택을 바꿀 수 있는 셸 명령도 전송 직전에 보류합니다.
