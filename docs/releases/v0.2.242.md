# AutoApprove 0.2.242

- 기존 Codex가 대화 JSONL을 열지 않는 경우에도 실제 프로세스의 설정 홈과 새 `/status` 카드의 Session ID로 원래 대화를 확인합니다. 서버의 같은 UUID·폴더·루트 대화를 읽어 대조한 뒤 같은 창에서 연결합니다.
- 상태 조회와 종료·재실행은 전달 전에 예약을 저장합니다. 불확실한 입력은 반복하지 않고, 작업·질문·초안·하위 작업·활성 Goal은 끝날 때까지 기다립니다. 실제 서버 연결과 같은 대화의 로드를 확인해야 연결 완료로 처리합니다.
- 활성 Goal 때문에 기다리는 동안 화면이 바뀌어도 완료 후 현재 대화를 다시 확인해 연결을 진행합니다. 전달 결과가 불명확한 상태 조회는 자동 반복하지 않습니다.
- 종료 후 셸·연결 확인 중에는 2초 간격으로 진행합니다. 대기 사유를 대화 상태 카드·설정 홈·원본 셸로 구분하며 계정 전환 완료 표시는 연결된 세션 범위임을 명시합니다.

검증 기록은 [VALIDATION.md](../../VALIDATION.md)에 기록합니다. 다른 Mac의 실제 기존 세션은 원격 접속할 수 없어 이 머신의 앱 소유 합성 PTY와 실제 엔진으로 검증합니다.
