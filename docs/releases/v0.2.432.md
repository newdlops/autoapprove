# AutoApprove 0.2.432 · 빌드 459

Claude 또는 연결된 Codex 부모·서브에이전트에서 새 승인 대기 신호를 받으면 해당 터미널 화면을 우선 확인합니다. 여러 탭이 동시에 조회 대상이면 각 탭의 확인 예정 시각을 반영하고, 오래 밀린 탭에도 차례를 줍니다.

Codex 서브에이전트를 보는 동안 `Thread: Main [default]` 승인창이 뜨면 원래 대화를 열고 요청 내용을 다시 대조해 한 번 승인합니다. 이미 처리된 요청은 창만 정리합니다. 연이어 새 승인창이 뜨면 해당 요청을 별도로 확인합니다.

그룹원의 화면에서 직접 답해야 하는 승인 요청이 확인되면 그룹장 수신함에 바로 기록합니다. 자동 승인이 꺼져 있거나 해당 승인창에 자동 응답할 수 없는 경우에 적용합니다. 자동 응답이 가능한 요청과 일반 선택 질문에는 기존 대기 시간을 적용합니다.
