# AutoApprove 0.2.442 · 빌드 469

그룹의 Codex 구성원이 새 대화로 전환되면 이전 부모 대화와 서브에이전트의 상태가 그룹원 상태에 섞이지 않도록 수정했습니다. 서버가 부모 상태를 확인하지 못한 경우 원래 터미널에서 최근 관측한 작업·대기 상태를 반영합니다.

그룹 상태 조회는 Terminal과 iTerm에서 새로 확인할 탭을 앱별로 모아 읽습니다. 이미 모니터가 확인한 최신 화면도 재사용합니다.

새 대화 ID를 기다리는 동안에도 원래 터미널이 확인되면 작업 상태를 표시합니다. 응답의 `connectionState`는 `identity_unverified`이며, 대화가 확인될 때까지 터미널 상태만 제공합니다.
