# AutoApprove 0.2.363 · 빌드 390

대화 그래프에서 구성원을 선택하고 **미응답 질문 먼저 회신**을 누르면 해당 대화의 기존 작업을 보류하고 오래된 수신 질문부터 답하도록 요청합니다. 현재 작업 화면에 Esc 중단 안내가 확인되면 해당 터미널에서 중단을 요청합니다. 중단을 확인할 수 없는 터미널에서는 다음 입력 대기에 우선 전달합니다.

질문을 조회할 때 수신 확인된 질문도 포함합니다. 답변이 등록됐거나 대기 기한이 만료된 질문은 제외합니다. 회신 요청에는 원래 질문 ID로 보낸 구성원에게 답하고 보류한 작업을 이어가라는 지시가 포함됩니다.
