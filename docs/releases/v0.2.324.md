# AutoApprove 0.2.324 · build 351

개별·전체 세션 ID 갱신에 적용한 새 `/status` 확인을 MCP의
`reconnect_group_member`에도 적용합니다. 같은 UUID라도 이번 조회의 응답에서
확인되어야 성공입니다. 조회 직전의 화면과 확인 가능한 스크롤 기록을 비교해,
스크롤로 다시 보인 이전 응답을 새 응답으로 처리하지 않습니다.

터미널 바이트로 `/status`를 보내는 연결에서는 붙여넣기 이벤트를 완료한 뒤
Enter를 전달합니다. 빠른 연속 입력이 붙여넣기로 처리되어 명령이 Codex
입력창에 남는 문제를 고쳤습니다.

그룹의 ID는 새 응답을 확인한 뒤 저장합니다. 표시용 새로고침과 그룹 상태
조회는 현재 로컬 세션 정보를 읽습니다.

릴리스 회귀검사 291개를 통과했습니다. 격리된 공식 Codex 0.169.0에서 개별
갱신과 MCP 재연결을 실행해, 같은 UUID가 두 개의 새 상태 카드에서 각각
확인되는 것을 검증했습니다.
