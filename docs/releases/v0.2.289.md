# AutoApprove 0.2.289

- 관리 창의 **세션 그룹**에서 그룹장을 지정하고, 구성원마다 상위 구성원을 정해 트리로 관리합니다. 순환하는 연결이나 없는 상위 구성원은 저장하지 않습니다. 중간 구성원을 제거하면 그 하위 구성원이 한 단계 위로 올라가고, 그룹장을 제거하면 평면 목록으로 돌아갑니다. 이전 버전의 그룹 파일은 그대로 읽습니다.
- 상위 세션은 AutoApprove MCP의 `assign_group_task`로 직속 하위 구성원에게 작업을 지시합니다. AutoApprove가 작업자의 입력창에 지시를 한 줄로 입력하고 제출하므로, 작업자는 바로 새 턴을 시작합니다. 작업자가 대기 상태일 때만 전달합니다.
- 작업자가 응답을 마치면 마지막 응답의 요약을 지시한 세션의 터미널에 입력합니다. 지시한 세션이 작업 중이면 보관했다가 대기 상태가 되고 입력창이 비면 전달합니다. 지시한 세션이 다시 시작해도 같은 대화를 찾아 전달합니다.
- `get_group_status`는 트리, 구성원 상태, 진행 중인 작업, 도착한 보고와 작업자가 기다리는 질문을 돌려줍니다. 여기서 읽은 보고는 터미널에 다시 입력하지 않습니다.
- 작업자가 사용자 입력을 기다리며 멈추지 않도록 다음 처리를 추가했습니다.
  - 작업 지시에 사용자에게 확인을 구하지 말고, 결정이 필요하면 마지막 응답에 적고 마치라는 규칙을 함께 입력합니다.
  - 그룹 작업 중인 Claude 작업자가 `AskUserQuestion`을 호출하면 hook이 거절하고 같은 규칙을 돌려줍니다. 질문은 완료 보고에 담겨 지시한 세션에 전달됩니다. 자동 승인이 바로 답하는 예/아니오 확인은 그대로 처리합니다.
  - 작업을 받은 작업자의 자동 승인이 꺼져 있으면 지시를 입력하기 직전에 켭니다. 지시가 터미널에 전혀 입력되지 못하면 원래대로 끕니다. 전체 일시정지는 풀지 않고, 일시정지 중이라 작업자가 멈출 수 있다고 지시한 세션에 알립니다.
  - 작업자가 터미널 선택지 질문에서 8초 넘게 멈추면 질문과 선택지를 지시한 세션의 터미널에 입력합니다. 지시한 세션은 `answer_group_question`으로 선택지 번호를 골라 답합니다. 화면의 질문이 바뀌었으면 답하지 않고, 권한 확인 화면에는 이 도구로 답할 수 없습니다.
- 선택지 대신 글을 직접 입력해야 하는 질문과 Codex의 비동기 질문은 지시한 세션이 답할 수 없습니다.

새 도구는 MCP를 다시 연결하거나 세션을 다시 시작한 뒤 사용할 수 있습니다. MCP 등록 방법은 [사용 설명서](https://github.com/newdlops/autoapprove#휴대폰-질문메시지와-테스트-화면-mcp)를 참고하세요.
