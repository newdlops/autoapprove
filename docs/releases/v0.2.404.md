# AutoApprove 0.2.404 · 빌드 431

세션 그룹에서 그룹장의 역할 메뉴를 열어 **상위 그룹장**을 지정할 수 있습니다. 상위 그룹장은 직속 하위 그룹장에게 작업을 배정하고 보고를 받으며, 하위 그룹장은 자기 구성원에게 일을 배정합니다. ‘없음 (최상위)’을 선택하면 지정한 관계를 해제합니다. 기존 그룹은 위계를 설정하기 전까지 동등한 그룹장 구성을 유지합니다.

Terminal의 화면 조회나 macOS 자동화 권한 확인이 멈추면 해당 호스트의 자동 입력을 보류합니다. 장기 호출이 실제 반환될 때까지 슬롯을 유지하고, 15초의 복구 대기 시간 후 읽기 성공을 확인합니다. 키보드 활동을 확인할 수 없을 때도 수동 확인 상태로 전환합니다.

| 현재 소스 경로 | 호출 대상과 동작 | 경합 처리 |
|---|---|---|
| `refreshScreenHost`, `readRemoteScreen` → `TerminalAppleEvents` | Terminal의 정확한 TTY를 대상으로 화면·선택 창·제목 조회 | 실제 Apple Event당 최대 2초, 모니터·뷰어 읽기 전체 5초. 호스트별 1건, 프로세스 전체 2건, 바쁜 호스트의 신규 조회는 보류 |
| `TerminalWindowCapture` → `HostAutomationPermission` | 원본 앱과 이벤트 범위의 TCC 확인 | 동일 범위 진행 중 조회 병합, 완료 값 0.5초 캐시, 비대화식 조회 2초. 권한 동의 경로는 명시적 연결에서만 실행 |
| `AutomationScript` → `osascript` | Terminal·iTerm2 탭 읽기 또는 입력 | 동일 호스트 슬롯을 공유하고 쓰기를 대기열에 축적하지 않음. 입력 결과를 확인하지 못하면 원본 확인 필요 |
| `NativeKeyboardActivity` → CoreGraphics | 물리 키보드 활동·수정 키·전면 앱 확인 | 독립 스레드 1개, 조회 중복 방지. 100ms가 지난 표본·조회 실패는 입력 보류 |
| `terminal-timings` → `automationIPC` | 실제 호출 수·조회 병합·거부·시간 초과·늦은 응답·진행 중 호스트·지연 백분위 | 메모리에 최근 256건의 처리 시간만 유지 |

전체 회귀 검사는 `python3 scripts/check-watchdog.py .build/debug/autoapprove-checks`로 실행합니다. 기본 제한은 검사당 120초, 전체 30분입니다. 제한에 도달하면 마지막 검사 이름을 출력하고 해당 검사 프로세스 그룹을 종료합니다.

릴리스 패키징 시 앱과 CLI의 dSYM을 실행 파일 UUID와 대조해 비공개 진단 디렉터리에 보관합니다.

격리 시험에서 한 호스트의 권한 조회를 65초 동안 멈췄습니다. 같은 권한을 묻는 추가 요청 20개는 최초 조회에 합쳐졌고, 호출자는 2.01초에 시간 초과를 받았습니다. 다른 호스트의 조회 158건이 성공했고 메인 스레드에서 측정한 20ms 주기 타이머의 실제 간격은 p99 36.4ms였습니다. 늦은 결과 1건은 폐기됐습니다.

그룹장 변경은 네이티브 역할 메뉴의 지정·해제와 저장을 확인했습니다. 중첩 그룹의 트리·원형 배치, 그룹장의 역방향 지시 거절, 상위 Codex의 하위 Claude 작업 배정 및 완료 보고를 가상 그룹에서 검사합니다.

릴리스 후보의 임시 Terminal 탭 두 개를 30분 동안 반복 조회해 445회 모두 응답을 확인했습니다. 시험 종료 시 진행 중인 IPC와 시간 초과는 모두 0건이었습니다. 같은 탭의 단기 비교(각 16회)에서 화면 조회 p50은 34.4ms에서 41.9ms, p95는 43.8ms에서 63.2ms로 늘었습니다. 이 비교에는 빌드 중의 호스트 부하가 포함됩니다. 실제 업무 탭에 승인 입력을 보내거나 운영 장애의 최초 대기 순환을 재현하는 시험은 수행하지 않았습니다.
