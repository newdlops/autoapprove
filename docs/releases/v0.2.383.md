# AutoApprove 0.2.383 · 빌드 410

관리 창의 MCP 연결 복구 메뉴에서 선택한 세션 또는 이 Mac의 전체 세션을 복구할 수 있습니다. 세션 행을 우클릭하면 그 세션만 복구합니다. 전체 복구는 검색과 필터에 가려진 실행 중 세션도 포함합니다.

Claude Code에서는 빈 입력창에서 AutoApprove 서버 재연결을 요청합니다. Codex는 해당 대화의 AutoApprove 서버 연결을 조회합니다. 이미 연결된 Codex 세션은 그대로 두고, 재연결이 필요한 Codex와 Antigravity는 확인 후 같은 탭에서 같은 대화로 CLI를 다시 열어 등록된 서버를 불러옵니다. 확인되지 않은 Claude 연결은 결과에서 재시작을 선택할 수 있습니다. 각 세션의 새 MCP 초기화가 확인되면 완료로 표시합니다. 서버 등록이 없거나 공유 서버의 초기화를 해당 세션에 귀속할 수 없으면 결과에 표시합니다.
