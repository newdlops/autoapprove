# AutoApprove 0.2.157 · 빌드 184

웹 관리 페이지에서 지난 연결 카드와 확인한 종료 세션이 나타났다 사라지며 레이아웃이 흔들리는 두 경로를 수정했습니다.

- 첫 조회에서 아직 상태가 없는 원격 Mac은 접힌 ‘이전 연결’에서 확인합니다. 실제로 연결된 응답을 받으면 본문에 표시하며, 이미 보고 있는 원본 연결은 유지합니다.
- 서버에 저장된 오류 확인은 정확한 Mac·세션·오류 ID별로 기억합니다. 확인 전에 시작된 늦은 목록 응답이 같은 경고와 종료 세션을 다시 띄우지 못합니다. 새 오류·다른 Mac의 오류는 표시하고, 저장 실패 시 다시 확인할 수 있습니다.
- 페이지 메모리에는 확인 식별자·시각만 최대 1,024개 보관합니다. 추가 조회·타이머·서비스 없이 기존 목록 갱신을 사용합니다.

수정 전 제품 웹 자원과 합성 응답으로 최초 목록의 이동 **540px / 276px / 66px**와 확인한 기록의 재등장을 재현했습니다. 수정 후 Chromium·WebKit의 **390×844 / 768×1024 / 1440×900**에서는 같은 이동이 **모두 0px**였고, 늦은 응답도 확인 상태를 유지했습니다. 반복 조회·키보드 포커스·새 오류·다른 Mac 격리·저장 실패·정리/복원·304·실제 온라인 응답·터미널 열기/복귀도 검사했습니다. 실물 휴대폰 검증은 포함하지 않습니다.

최종 Release 전체 **381/381** 검사와 서명 패키지 통합 검사 **3개**가 통과했습니다. 설치 파일에 포함된 웹 자원으로도 Chromium·WebKit 각각 **8그룹**을 통과했고, 밝음·어두움과 세 화면 크기의 이미지를 확인했습니다. 검증한 코드·웹 자원·기존 발행자 서명이 일치하며 DMG의 무결성·체크섬·설치 구성을 확인했습니다.

Native 프로세스 버퍼·포맷터 최적화 후보는 CPU·대기 시간 회귀로 채택하지 않았습니다. 동시 조회와 시간대 복원 회귀 및 선택적 병렬 측정 경로만 보완했고, 제품의 Swift Core는 0.2.156을 유지합니다.
