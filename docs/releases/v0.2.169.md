# 0.2.169 · 빌드 196

AutoApprove가 덮개 상태를 근거로 Mac에 직접 잠자기를 명령하던 경로를 제거합니다. 작업이 끝나거나 배터리·온도 조건으로 잠자기 방지를 해제할 때, 앱과 기존 감시 프로세스는 자신이 설정한 방지만 해제합니다. `pmset sleepnow` 실행 코드와 새 권한 규칙의 해당 명령도 제거했습니다. 이미 설치된 시스템 권한 규칙을 자동으로 수정하지는 않습니다.

작업 중인 기존 잠자기 방지, 작업 종료 후 유예 시간, 배터리·온도 조건은 유지합니다. 덮개 상태가 반복해서 바뀌어도 작업 중인 방지는 해제하지 않으며 감시 프로세스를 추가로 만들지 않습니다. 잠금 해제나 잠긴 화면을 깨우는 기능은 추가하지 않았습니다.

이 수정은 AutoApprove의 명시적인 강제 잠자기 요청을 없애는 조치입니다. macOS가 실제로 덮개 닫힘을 보고해 내장 화면을 끄는 현상까지 해결한 것으로 보아서는 안 됩니다. Apple의 일반 화면 잠자기 방지 assertion은 유휴 상태를 대상으로 하며 덮개 닫힘에 의한 화면 꺼짐을 보장해서 막지 않습니다([Apple IOPMLib 계약](https://github.com/apple-oss-distributions/IOKitUser/blob/main/pwr_mgt.subproj/IOPMLib.h)). 시스템·보안 정책 변경, 새 관리자 권한, 자동 실행 항목 또는 별도 상주 서비스는 추가하지 않습니다.
