# AutoApprove 0.2.422 · 빌드 449

세션 프로필에서 창·탭 배치를 읽을 때 화면에 보이는 Terminal 탭은 창 ID로 바로 확인합니다. 숨은 탭은 해당 창을 잠시 선택하고 원래 탭으로 돌아온 뒤 다음 창을 확인합니다. 이 과정에서 다른 앱을 활성화하지 않습니다. 키 입력은 탭 선택·복원과 겹치지 않으며, 배치가 도중에 바뀌면 다시 읽도록 안내합니다.

세션을 다시 시작할 때는 선택한 탭에서 이미 전달 중인 입력을 마친 뒤 CLI를 종료합니다. 원래 셸이 돌아오기를 기다리는 동안 다른 탭의 자동화와 재시작은 계속됩니다. 재실행 직전에는 원래 셸과 빈 프롬프트를 확인합니다.
