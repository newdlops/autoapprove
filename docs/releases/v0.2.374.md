# AutoApprove 0.2.374 · 빌드 401

전체 세션 ID 갱신에서 Claude Code, Codex, Antigravity의 원래 탭과 대화 ID를 전체 실행 세션과 대조합니다. 다른 탭에서 이전 대화가 열렸거나 조회 중 대상 대화가 바뀌면 해당 구성원을 보류합니다. 저장에 성공한 구성원은 확인된 탭 식별 정보도 함께 갱신합니다.

세션 그룹과 진단에 탭·대화 불일치 및 중복 메시징 이름을 표시합니다. 이미 별도 하위 구성원으로 등록된 대화는 기존 그룹장의 “하위 구성원에서 그룹장 연결 복구…”에서 TTY와 UUID를 대조하여 연결할 수 있습니다. 기존 그룹장 ID와 권한, 두 구성원의 작업 이력을 보존합니다.
