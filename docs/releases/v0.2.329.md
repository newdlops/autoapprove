# AutoApprove 0.2.329 · 빌드 356

Codex와 Claude 그룹원이 같은 Mac에서 작업 결과, 질문 답변, 외부 작업을 기다릴 수 있습니다. 작업별 대기 조건은 `get_group_status`의 `waits`에 표시됩니다. 같은 명령에 `includeWaitGraph: true`를 지정하면 Mermaid 그래프를 함께 받습니다. `all`은 지정한 결과가 모두 필요하고, `any`는 하나만 도착해도 진행합니다.

- `wait_group_dependencies`에 그룹 ID와 고정된 `waitID`, 기다리는 `taskIDs` 또는 자신이 보낸 `questionIDs`를 전달합니다. 외부 결과를 포함하려면 `external: true`를 사용합니다. 기한은 기본 300초이며 `timeoutSeconds`로 바꿀 수 있습니다.
- 결정이 필요하면 `ask_group_question`에 `blocksProgress: true`와 고정된 `messageID`를 지정합니다. 지정된 수신자가 `reply_group_question`의 `inReplyTo`에 원래 질문 ID를 넣으면 답변이 해당 질문에 연결됩니다. 받은 질문에 답하려고 다른 결과를 기다릴 때는 `forQuestionID`를 지정합니다.
- 순환이 생기면 새 자동 대기를 보류하고 해당 경로를 반환합니다. 수신 확인과 기한 만료는 결과를 대신하지 않습니다. 기한 후 답변도 원래 질문에 연결됩니다.
- `update_group_wait`의 `externalReady`로 외부 결과 도착을 기록하고 `cancel`로 불필요한 대기를 해제합니다. 대기를 등록한 배정 작업은 결과를 낸 워커가 원래 `taskID`와 요약으로 `complete_group_task`를 호출해 마칩니다. 질문을 보낸 턴이 끝나도 배정은 유지됩니다.
