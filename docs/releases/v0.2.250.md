# AutoApprove 0.2.250

Codex 로그인 확인과 서버 연결 조회의 응답성을 개선했습니다. 검증된 네이티브 CLI는 로그인 셸을 거치지 않고 실행하며, npm·nvm 래퍼는 한 번 얻은 환경을 같은 조회에서 재사용합니다. 다른 Mac의 느린 셸 초기화 때문에 정상 서버를 확인하지 못하던 경로를 줄였습니다.

계정 창의 **현재 로그인 확인**은 읽기 전용입니다. 자동 전환을 꺼도 계정·플랜·저장된 로그인과 서버 계정의 비교 결과·확인 시각을 볼 수 있습니다. 서버 조회를 기다리는 동안에도 로그인과 홈 선택을 사용할 수 있습니다. 조회 실패 시 마지막 확인값을 구분해 유지하고, 홈 변경·로그인 시작/취소/만료/완료 뒤의 오래된 응답을 폐기합니다. 조회 중 서버 계정이 바뀌면 비교 성공으로 표시하지 않습니다.

로컬 진단 명령 `autoapprove doctor --codex-account`와 선택 홈을 위한 `--codex-home`을 추가했습니다. 결과는 해당 Mac의 사용자 전용 IPC로만 전달하며 공개 세션 목록에는 계정 정보를 넣지 않습니다. 이 조회가 작업을 중단하거나 계정을 전환하지 않습니다.

이번 릴리스는 조회·로그인 UI와 경합 수정입니다. 독립 세션의 계정별 통합·분리는 아직 제공하지 않습니다. 실제 Codex 0.166의 임시 홈 시험에서 공식 대화 복구만으로 Goal 기록이 이관되지 않는 것을 확인했으며, 전체 목표는 계속 진행 중입니다. 실제 다른 계정의 인증·SSO 전환 완료는 별도 검증이 필요합니다.
