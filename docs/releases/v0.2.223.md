# 0.2.223 · Claude 입력 대기 상태 인식 복구

Claude의 정상 입력 대기 화면에서 사용자 상태 줄이 짧게 표시되거나 5시간·주간 사용량을 함께 표시할 때 웹 관리자와 앱이 계속 **상태 미확인**으로 남는 문제를 수정합니다.

- 프로젝트·브랜치·모델만 있는 상태 줄, `ctx …`만 있는 상태 줄, `ctx … | 5h … 7d …` 형식을 인식합니다. 기존 주간 사용량 형식도 유지합니다.
- 실제 입력창과 CLI 단축키 안내가 함께 있어야 입력 대기로 판정합니다. 작성 중인 초안·숫자 선택 메뉴·알 수 없는 추가 문구는 각각 입력 중 또는 미확인으로 유지합니다.
- 원본 프로세스·TTY 검증, 승인 정책, 입력 전달과 재전송 범위는 변경하지 않습니다.

실제 미확인 세션에서 하단 구조를 확인하고 본문을 저장하지 않은 채 관찰된 형식을 가상 데이터 회귀에 반영했습니다. 전체 연결·크기 변경·스크롤 안정성 목표는 계속 검증 중이며 이 수정만으로 완료를 주장하지 않습니다. 상세 결과는 [검증 기록](../../VALIDATION.md)에 남깁니다.

같은 실제 화면 9개를 기존/최종 Core로 비교해 **미확인 9개→입력 대기 9개**를 확인했습니다. 최종 전체 Core **615/615**, footer 회귀 **6/6**, 실제 Core·격리 HTTP·Chromium/WebKit의 여섯 합성 원본 상태/복구 검사가 통과했습니다. 브라우저 쓰기 요청·터미널 입력은 0회였습니다. 좁은 폭의 상태 줄 줄바꿈과 실제 Terminal 스크롤 검증은 별도 진행 중입니다.

정식 릴리스의 설치 파일 4개를 공개 다운로드로 검증하고 `/Applications/AutoApprove.app` 실행 **0.2.223/250**을 확인했습니다. 기존 원본 **19/19개**를 유지했고 설치 전 미확인 Claude **9개 모두** 같은 원본에서 입력 대기로 복구됐습니다.
