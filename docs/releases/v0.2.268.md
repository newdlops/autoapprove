# 0.2.268 · Terminal 입력 준비 최적화

- 정확한 TTY·선택 탭·최소화 여부를 하나의 조회 조건으로 묶었습니다. 일반적인 한 번의 입력에서 창 검증에 필요한 macOS 왕복 조회가 8회에서 2회로 줄었습니다.
- 실시간 입력에서 창을 바꿀 때 별도 스크립트 프로세스를 실행하지 않습니다. 정확한 TTY를 찾아 선택하고, 같은 창 ID에 한해서 복원·앞으로 가져오기·최종 확인을 수행합니다.
- 화면 내용 대조가 필요한 메시지·선택지와 일반 전송은 기존 준비를 유지합니다. 원본 프로세스, 선택 탭, 포커스와 권한은 입력 직전에 계속 확인합니다. 입력을 자동 재전송하지 않습니다.
- 조회 횟수와 준비 경로의 회귀 검사를 통과했습니다. 실제 사용자 환경의 지연 감소 수치는 설치 후 측정해야 합니다.
