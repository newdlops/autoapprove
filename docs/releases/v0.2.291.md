# AutoApprove 0.2.291

- 세션 그룹 구성원에 **세션 ID 갱신** 버튼을 추가했습니다. 사용자가 누르면 원래 터미널에 `/status`를 입력하고 새 상태 화면에서 현재 대화 ID를 읽어 그룹에 저장합니다.
- 원래 프로세스·TTY·작업 경로가 유지되고 입력창이 빈 대기 상태에서만 조회합니다. 작업·질문·승인·초안이 있으면 보류합니다. 조회 실패나 저장 충돌 시 기존 ID를 유지합니다.
- Codex는 기존 상태 카드의 모델·폴더·권한·지침·Session 필드를 확인합니다. 과거 상태 카드에 남은 ID만으로 갱신하지 않습니다.
- 그룹장과 구성원 트리는 유지합니다. 자동 주기 조회는 포함하지 않습니다.

검증: Debug·Release 빌드와 그룹 검사 12/12 통과. 네이티브 화면을 700×480, 860×640, 1100×800의 밝고 어두운 테마로 렌더링했습니다. 최소 밝은 화면과 넓은 어두운 화면을 시각 확인했고, 격리 앱에서 갱신 버튼 클릭 및 연결 불가 오류 표시를 확인했습니다. 실제 터미널 조회 성공과 Claude 상태창 자동 복귀는 아직 검증하지 않았습니다.
