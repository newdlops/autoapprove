# AutoApprove 0.2.46 · 빌드 57

휴대폰 웹에서 여러 질문을 선택하고 답변하며, 같은 원본 대화로 새 메시지를 보낼 수 있습니다.

- 터미널 하단의 **질문·메시지**에 질문 폼과 새 메시지 입력을 추가했습니다. 새 질문과 주기적 갱신 중에도 현재 탭의 선택·초안을 유지합니다.
- Claude의 연결된 `AskUserQuestion`은 단일·복수 선택·추가 설명을 원래 훅으로 전달합니다. 답변에 방향키나 텍스트 키 입력을 주입하지 않습니다.
- Codex 질문과 새 메시지는 실행 중인 프로세스·같은 대화를 검증한 뒤 메시지 대기열로 전달합니다. 다른 CLI의 새 메시지는 기존 원본 입력 연결을 사용합니다.
- 로컬 stdio MCP의 `ask_user`, `get_user_answers`, `list_screens`, `start_screen_share`, `stop_screen_share`를 제공합니다. 등록 명령은 README와 설치 안내에 있습니다.
- MCP 테스트 공유는 기본 **Mac 전체 화면**입니다. 화면 녹음 권한이 필요하며 휴대폰이 열어 볼 때만 이미지를 요청합니다. 휴대폰에서 공유 종료가 가능하고 기본 10분·최대 15분 뒤 자동 종료합니다.

휴대폰에는 설치가 필요 없습니다. 기존 터미널의 PID·TTY를 유지하며 웹 질문이나 화면 공유를 위해 새 PTY를 만들지 않습니다. 이미 반환된 Claude 훅·지원하지 않는 질문 화면은 원본 터미널에서 확인합니다. MCP 등록은 다음 CLI 실행 또는 MCP 재연결부터 적용되며 실행 중인 대화를 강제로 재시작하지 않습니다.

검증 범위는 [VALIDATION.md](../../VALIDATION.md)에 기록합니다. Mac 설치 파일은 `AutoApprove-0.2.46-macOS-arm64.dmg`입니다.
