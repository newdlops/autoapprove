# AutoApprove 0.2.314 · build 341

공식 Codex 0.169.0 원본 패키지를 유지하면서 기존 대화의 로그인 그룹 이동,
독립 세션 연결, 전용 로그인 분리와 Goal 복구를 다시 제공합니다.

선택한 터미널만 대상 로그인 홈으로 옮깁니다. 같은 원본 서버를 사용하는 다른
터미널은 원래 로그인 홈의 같은 대화로 다시 연결합니다. 대화 UUID·하위 대화·
페이지형 이력·그룹 역할·메시지 수신 확인·자동 승인 설정을 보존합니다.
진행 중인 명령은 중단될 수 있으며 자동으로 다시 실행하지 않습니다.

독립 세션의 자동 연결은 빈 입력창과 대기 상태를 확인한 뒤 순차 진행합니다.
새 독립 로그인은 전용 홈과 로컬 공식 서버를 사용해 하위 Goal 제어를 유지합니다.
기존 독립 홈의 자동 서버 시작 정책은 유지합니다.

결과를 받지 못한 Goal 요청은 같은 Goal ID·목표·예산·사용량과 현재 상태를
대조해 복구합니다. 이미 적용된 요청은 반복하지 않고, 새 로그인 홈의 더 최근
요청을 우선합니다. 홈 간 복구에는 완료된 이관 기록의 증명이 필요합니다.

Codex 그룹 호출은 프로세스나 터미널보다 대화 UUID와 로그인 홈을 우선해
식별합니다. 확인된 실제 부모의 기존 Claude 구성원 권한은 유지합니다.
MCP 프로세스에는 사용 환경에 맞는 UTF-8 로캘을 적용합니다.
패키지된 앱이 시작할 때 리소스 번들을 찾지 못해 종료되던 문제도 수정했습니다.

이번 이동 경로는 공식 0.169.0 실행 파일·서버·데이터 형식을 확인합니다.
호환되지 않는 형식은 터미널을 종료하기 전에 거부합니다. 비공개 전체 접속 ID
목록, 숨겨진 미전송 초안 보존, 하위 승인 전 임의 화면으로의 복귀는 제공하지
않습니다. 기존 수정판 서버·클라이언트의 자동 교체도 수행하지 않습니다.

검증은 [기능·네이티브 화면 검증 기록](../official-codex-recovery-validation.md)에
정리했습니다. 실제 공식 Codex와 격리 PTY를 사용했으며 사용자 터미널과 실제
로그인 정보는 검사에 사용하지 않았습니다. Claude 구현은 변경하지 않았습니다.
