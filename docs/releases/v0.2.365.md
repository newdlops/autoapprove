# AutoApprove 0.2.365 · 빌드 392

그룹에서 빠진 구성원이 보낸 질문의 재알림이 수신함 맨 앞에서 반복적으로 실패하던 문제를 수정했습니다. 전체 세션 ID를 다시 갱신할 필요 없이, 발신자가 빠진 미제출 메시지는 보관하고 현재 구성원 사이의 메시지를 계속 전달합니다. 기한 안에 같은 구성원 ID가 돌아오면 보류한 메시지도 다시 전달 대상으로 확인합니다.

우선 회신 목록과 자동 재알림은 현재 그룹에 있는 발신자의 질문을 대상으로 합니다. 그룹이 없거나 발신자·수신자가 빠진 경우와 수신 터미널의 대화 ID가 확인되지 않은 경우를 각각 구분해 표시합니다.
