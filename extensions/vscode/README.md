# AutoApprove Bridge

AutoApprove macOS 앱과 로컬 VS Code 통합 터미널을 연결합니다.

1. AutoApprove 앱을 실행합니다.
2. 확장을 설치합니다. 기존 창에는 `Developer: Reload Window`가 필요할 수 있습니다.
3. 연결 후 터미널에서 Claude Code 또는 Codex를 실행합니다.
4. 앱에서 해당 세션의 자동 승인을 켭니다.

기존 터미널도 등록되어 원래 터미널로 이동할 수 있습니다. 공식 VS Code API로 이미 지나간 출력을 복구할 수는 없으므로, 출력 감지는 확장과 앱이 연결된 상태에서 시작한 명령부터 지원합니다. Claude는 앱의 훅 연결도 사용할 수 있습니다.

0.2.3부터 앱에서 **터미널 열기**를 누르면 선택한 터미널의 프로젝트명·TTY 알림과 3초 동안의 상태 표시로 이동 대상을 알려줍니다.

원격 SSH·Dev Containers·WSL, shell integration이 없는 터미널은 출력 기반 자동 승인 대상이 아닙니다. 연결이 끊긴 출력 스트림은 자동 제어를 중지하며 다음 명령부터 다시 연결합니다.

확장은 화면을 로컬 Unix socket으로만 전달하며 외부 서버로 보내지 않습니다. 앱에서 자동 승인을 켠 세션의 요청에만 응답합니다. 화면·실행 세대·응답 기한이 달라진 요청과 같은 요청의 재전송은 거부합니다.
