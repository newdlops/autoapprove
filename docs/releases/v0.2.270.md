# 0.2.270 · Terminal 첫 접속과 재접속 최적화

- 백그라운드 묶음 조회의 첫 단계뿐 아니라 전체 세 단계의 소요 시간을 확인합니다. 합계 250ms 이상 걸린 묶음은 5분 동안 정확한 TTY별 조회로 전환해 반복되는 긴 조회를 줄입니다.
- 첫 접속·재접속 시 같은 원본의 완료된 실시간 화면이 180ms 이내라면 재사용합니다. 실제 관찰 시각과 커서를 유지하며, 대기 중인 느린 조회에는 합류하지 않습니다.
- 새 접속마다 현재 권한과 원본 프로세스를 확인합니다. 입력·소스 변경·연결 해제·권한 취소가 발생했거나 화면이 만료되면 재사용하지 않습니다.
- 공유 화면 조회가 내부에서 취소되어도 접속 중인 사용자의 화면은 새로 읽어 복구합니다. 최대 세 번으로 제한하며, 사용자가 접속을 닫았거나 권한·원본 검증이 실패한 경우에는 재시도하지 않습니다.
- 화면 조회 최적화이며 입력을 재전송하거나 새 터미널을 생성하지 않습니다. 실제 첫 화면 시간과 재연결 안정성은 설치 후 별도로 계측합니다.
