# 0.2.145 · 열지 않은 웹 터미널의 반복 비교 경량화

웹에서 보고 있는 구독자가 없는 터미널은 변경 알림을 위한 긴 화면 비교를 생략합니다. 원본 화면은 계속 갱신하고, 새로 열면 같은 세션의 최신 화면을 읽습니다. 자동 승인·위험 명령 검사와 입력 직전 원본 검증은 유지합니다.

같은 합성 Cocoa 화면·12세션의 실제 Core 처리 경로를 8쌍 교대 측정했습니다. 미구독 CPU 중앙값은 **1.016→0.647초**, 구독 종료 후에는 **1.044→0.644초**였습니다. 12개를 모두 구독한 경우는 **0.977→0.986초**로 비슷한 수준입니다. 이 결과는 특정 합성 처리 경로의 측정이며, 앱 전체 CPU나 휴대폰/VPN 지연의 개선율은 아닙니다.

전체 Release **369/369** 검사가 통과했습니다. 실제 loopback SSE로 첫 화면·텍스트/커서/색상 변경·종료 후 재접속을 확인했습니다. 기존 메시지 개별/전체 정리·되돌리기와 끊긴 Mac·경고 정리도 Chromium과 WebKit의 모바일·태블릿·데스크톱 크기에서 다시 검사했습니다. 실제 휴대폰의 키보드/IME 시험은 수행하지 않았습니다.

서명 패키지의 자동 응답 12건·수동 질문 대기 12건, 일시정지·재시작·응답 유실/단일 전달·격리 웹/MCP/PTY·입력 구성요소 및 DMG 검사도 통과했습니다.

PR #6의 커서 조회 경량화와 0.2.142의 웹 기록 정리 기능을 포함합니다. macOS 14 이상 Apple Silicon용이며 빌드는 172입니다. 기존 발행자 인증서를 재사용합니다. 설치 방법은 [설치 안내](../../README.md#설치)를 참고하세요.
