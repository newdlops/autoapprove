# 0.2.216 · Codex 대화 ID 자동 저장

- **현재 대화 자동 연결:** 공유 데몬을 사용하는 Codex는 터미널 프로세스가 대화 기록 파일을 직접 열지 않을 수 있습니다. 저장 시 이 경우에도 해당 Codex 설정 폴더·작업 폴더의 로드된 대화에서 **전체 대화 이름과 실제 터미널 제목이 유일하게 일치하는 ID**를 저장합니다. AutoApprove의 사용자 지정 표시 이름이나 대화 미리보기는 식별에 사용하지 않습니다.
- **바로 이어 열기:** 저장된 ID를 포함한 `codex resume <대화 ID>` 명령으로 복원합니다. 저장·다시 읽기·탭 복원 과정에서도 ID를 유지합니다. [공식 Codex CLI의 resume 설명](https://learn.chatgpt.com/docs/developer-commands?surface=cli#codex-resume).
- **모호한 경우:** 같은 이름이 여러 개이거나 제목이 일치하지 않으면 직접 대화를 선택할 수 있습니다. 폴더에 하나만 있거나 가장 최근이라는 이유로 대화를 선택하지 않습니다. 저장 중 실제 탭 제목이 바뀌면 오래된 ID로 저장하지 않습니다. ID를 비워 둔 항목의 새 CLI 실행은 유지합니다.
- **목록 처리:** 대화 이름은 선택 목록의 짧은 표시와 별도로 보존합니다. 목록의 다음 페이지도 읽으며 반복·잘못된 커서와 1,000개 상한을 확인합니다. 복원 준비에서 저장용 탭 선택·대화 목록 조회를 생략하는 기존 경로는 유지합니다.

**기존 백업:** 대화 ID가 비어 있던 파일은 자동으로 덮어쓰지 않습니다. 원하는 Codex 대화가 열려 있을 때 **프로필 관리 → 현재 창으로 갱신**으로 한 번 갱신하면 이후에는 저장된 대화를 이어 엽니다.

회귀 테스트와 배포·설치 기록은 [검증 기록](../../VALIDATION.md)에 남깁니다. 실제 Terminal 전체 복원은 이번에 자동 실행하지 않습니다.
