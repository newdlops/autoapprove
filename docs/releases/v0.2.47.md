# AutoApprove 0.2.47 · 빌드 58

휴대폰 웹 터미널의 일시적인 ‘연결 끊김’ 뒤 입력이 계속 막히는 문제를 수정했습니다.

- 화면 스트림이 끊기면 0.5초부터 최대 5초 간격으로 같은 원본 세션에 자동 재연결합니다. 화면 갱신이 8초 동안 멈춘 연결도 복구합니다.
- 기기 목록 조회 실패와 터미널 스트림을 분리해 정상 연결의 입력을 유지합니다.
- 재연결 중 키보드 포커스·한글 조합과 미전송 글자·방향키·Enter를 보관합니다. 같은 원본 연결을 확인한 후 순서대로 한 번씩 전달합니다.
- 입력 신선도는 브라우저의 수신 시각으로 확인해 Mac과 휴대폰의 시계 차이 때문에 입력이 막히지 않습니다.
- 다른 Mac을 거치는 중계에서 일시적인 네트워크 오류와 잘린 출력은 재연결합니다. 원본 세션 변경·권한 해제·잘못된 출력은 입력을 멈추고 초안을 보존합니다.
- 키보드가 열린 작은 화면에서 조작부의 여백을 줄여 터미널 영역을 확보했습니다.

이미 전송한 입력의 접수 여부가 불확실하면 자동 재전송하지 않습니다. 기존 PID·TTY와 대화는 유지하며 복구를 위해 새 PTY를 만들지 않습니다. 앱 업데이트 후 휴대폰의 열려 있는 페이지를 한 번 새로고침하면 적용됩니다.

검증 범위는 [VALIDATION.md](../../VALIDATION.md)에 기록합니다. Mac 설치 파일은 `AutoApprove-0.2.47-macOS-arm64.dmg`입니다.
