# AutoApprove 0.2.306 · 빌드 333

- Codex 그룹 ID 갱신이 짧은 키보드·원격 입력 보호 시간과 겹치면 최대 3초 동안 입력 종료를 기다린 뒤 다시 확인합니다. 진행 중인 입력이나 질문을 건너뛰지 않으며, 여전히 충돌하면 명령을 보내지 않습니다.
- 갱신 보류 이유를 실제 터미널 질문, 계정 전환, Goal 변경, 자동 승인 입력, 원격 입력 보호, 키보드·원격 조작 우선권으로 구분합니다. 모든 실패를 질문·승인으로 표시하지 않습니다.
- 기존 `get_session_groups` 응답에 `reconnectBlockedReason`을 추가했습니다. 오래 열린 MCP 연결에서도 기존 조회 도구로 재연결 보류 이유를 확인할 수 있습니다. `canReconnect`는 원래 연결과 권한의 존재를 나타내며, 즉시 입력 가능하다는 의미는 아닙니다.
- Codex 상태 조회 전달도 기존 그룹 메시지와 같은 최신 텍스트 읽기를 사용해 불필요한 창·커서 표시 조회를 피합니다. 실제 입력 충돌·프로세스 재검증과 Claude 경로는 유지합니다.

0.2.305의 상태 카드 판별 보완과 그룹 상위 관계 보존을 포함합니다. 사용자 VM·CLI·대화를 다시 시작하지 않습니다. 실제 세션의 보류 원인은 조회 당시의 `reconnectBlockedReason` 또는 UI 오류로 확인해야 합니다.
