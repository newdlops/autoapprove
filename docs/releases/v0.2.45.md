# AutoApprove 0.2.45 · 빌드 56

여러 권한 확인이 이어지거나 창 크기가 바뀔 때 자동 승인이 멈추는 문제를 수정했습니다.

- Codex·Claude의 권한 확인 제목이 여러 줄로 나뉘어도 인식합니다. 같은 질문의 줄바꿈은 새로운 승인으로 처리하지 않습니다.
- 이전 승인 입력을 처리하는 동안 다음 질문이 도착하면 입력 완료 응답 뒤 바로 재개합니다. 다른 세션의 승인은 독립적으로 처리합니다.
- 입력하지 않았다는 결과가 확정된 경우 지연 후 원본 질문을 다시 확인합니다. 화면 출력이나 창 크기 변경을 기다리며 멈추지 않습니다.
- Claude의 Bash·파일 생성·수정 패널을 구분하여 다음 질문이 이전 승인 상태를 물려받지 않도록 했습니다. 이전 출력과 줄바꿈 변화는 같은 요청으로 유지합니다.
- 입력 결과가 불확실하거나 실제 화면의 제목·선택지가 사라진 경우에는 자동 재전송하지 않습니다.

Core 140개 검사, 실제 터미널 셀의 42개 크기 조합, 격리된 PTY와 VS Code 브리지의 연속 승인·지연 응답을 확인했습니다. Terminal 자동 승인은 앱 포커스나 전체 키보드에 의존하지 않고 정확한 탭으로 전달합니다. 다른 앱의 실제 macOS 알림을 발생시키는 검사는 수행하지 않았습니다.

Mac 설치 파일은 `AutoApprove-0.2.45-macOS-arm64.dmg`입니다. 휴대폰에는 설치가 필요 없습니다. 무료 tmux 원본 중계와 기존 연결 설정을 유지합니다.
