# AutoApprove 0.2.433 · 빌드 460

프로젝트 파일, 빌드 산출물, 임시 파일의 삭제는 일반 승인 설정을 따릅니다. 상대 경로는 요청의 작업 폴더를 기준으로 확인합니다. 시스템·OS 경로 또는 디스크·볼륨 전체를 지우는 것으로 확인된 요청은 자동 승인 모드에서 차단합니다. 변수 등으로 삭제 대상을 확인할 수 없으면 원래 터미널에서 직접 결정할 수 있습니다. 이 기준은 셸 명령, 파일 삭제 도구, 패치 및 Codex 서브에이전트의 파일 변경 승인에 적용됩니다.

그룹장은 MCP 도구 `manage_group_subgroup`으로 자신의 하위 구성원을 선택해 서브그룹을 결성할 수 있습니다. `create`에는 상위 그룹의 `groupID`, 이름과 `memberIDs`를 지정합니다. 선택한 구성원의 `leaderMemberID`를 함께 보내면 결성과 동시에 임명됩니다. `appoint`와 `dismiss`로 해당 서브그룹의 그룹장을 추가하거나 해임할 수 있습니다. 상위 그룹의 구성원과 직책은 유지됩니다.

`get_group_topology`의 `canManageSubgroup`과 `subgroupParentID`에서 관리 범위와 상위 그룹을 확인할 수 있습니다. `dissolve`로 중간 서브그룹을 해산하면 해당 그룹의 대기 작업과 메시지 전달을 정리하고, 바로 아래 서브그룹은 한 단계 위에 연결합니다.
