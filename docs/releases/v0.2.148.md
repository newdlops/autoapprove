# 0.2.148 · 설치 파일 경량화

Release 앱과 CLI에서 로컬·디버그 심볼을 정리해 배포 크기를 줄였습니다. 실행 코드와 데이터, 공개 심볼의 이름·종류·주소, 메모리 매핑·보호 속성, 로더 정보와 UUID는 그대로 유지하고 기존 발행자로 정상 서명합니다. 진단용 원본은 앱 밖의 비공개 `.runtime/release-symbols/`에 보관합니다. 로컬 함수의 상세 분석에는 이 원본을 사용하며, 오프라인 함수 이름 복원도 확인했습니다. Debug 패키지는 심볼을 유지합니다.

같은 147/174 소스로 만든 서명된 비교 패키지의 결과입니다.

| 대상 | 기존 | 심볼 정리 후 | 감소율 |
| --- | ---: | ---: | ---: |
| App 실행 파일 | 14,138,400바이트 | 7,409,632바이트 | 약 47.6% |
| CLI 실행 파일 | 9,904,128바이트 | 6,157,664바이트 | 약 37.8% |
| 두 실행 파일 합계 | 24,042,528바이트 | 13,567,296바이트 | 약 43.6% |
| 압축 DMG | 10,359,773바이트 | 7,844,956바이트 | 약 24.3% |

격리한 MCP 보조 프로그램을 8쌍 교대로 실행한 초기 응답 중앙값은 43.8→23.6ms였습니다. 도구 목록 요청 16,000건과 정상 EOF 종료를 확인했습니다. 초기 footprint는 3,211,708→3,244,464바이트, 1,000회 요청 뒤에는 3,506,632→3,563,964바이트로 비슷한 수준입니다. 공유 페이지를 포함한 이 시험의 수치이며 전체 앱 CPU·메모리나 휴대폰 터미널 지연의 개선율은 아닙니다.

전체 회귀 **372/372**, 추가 Debug 경계 검사 **2/2**, 실제 실행 파일·32/64비트 universal 헤더의 코드/메타데이터 보존 및 외부 `nm` 비교를 통과했습니다. 이번 Core 소스는 0.2.147과 같습니다. 일반 선택 질문의 수동 응답·현재 모델 유지·위험 시스템 변경 거절과 안전한 대안 안내를 유지합니다. 새 서비스·자동 실행 등록이나 보안·권한·VPN 설정 변경은 없습니다.

최종 패키지의 자동 응답 12건·명시적 웹 응답을 기다리는 질문 12건, 일시정지·재시작·응답 유실과 중복 방지, 로컬 웹·MCP·격리 PTY·입력 번들·DMG 검사도 통과했습니다. 최종 DMG는 7,844,956바이트입니다.

macOS 14 이상 Apple Silicon용이며 빌드는 175입니다. 설치 방법은 [설치 안내](../../README.md#설치)를 참고하세요.
