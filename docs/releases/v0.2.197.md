# AutoApprove 0.2.197 · build 224

같은 네트워크에서 상태 대기 연결이 끊겼을 때 정상 Mac을 오프라인으로 표시하던 경로를 수정합니다.

- 상태 대기 조회의 끊김·무응답·일시적 서버 오류 뒤 일반 LAN 조회로 새 상태를 확인합니다. 기존 주소 복구와 노드 ID 검증을 사용하며 새 조회까지 실패하면 연결 끊김을 표시합니다.
- 계정 인증의 키체인 조회를 UI·통신 처리에서 분리합니다. 동시 요청은 조회 하나를 공유하고, 지연된 인증 요청에 제한 시간을 적용해 목록·터미널 통신이 함께 멈추는 상황을 줄입니다.
- PIN 변경·해제와 앱 종료는 진행 중인 이전 인증 조회를 무효화합니다. 권한 거부·다른 Mac·잘못된 응답은 성공으로 처리하지 않고, 키 입력과 인증 코드를 자동 재전송하지 않습니다.
