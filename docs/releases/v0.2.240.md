# 0.2.240 · 관리형 Codex 서버 자동 준비

AutoApprove가 시작하거나 새 Codex 홈을 발견하면 서버를 자동 확인합니다. 지원되는 CLI에서 서버가 없는 경우 앱이 직접 시작하고 실행 상태를 확인합니다. 계정 창의 준비 버튼을 먼저 누를 필요가 없습니다.

실행 중인 서버는 그대로 사용하며, 실패·확인 불가 상태는 자동으로 반복하지 않습니다. 관리자 실행당 홈별 한 번 시도하며 계정 창의 수동 확인·준비는 유지합니다. 계정 자동 전환 설정은 변경하지 않으며, 독립 세션은 서버 시작만으로 이동하지 않습니다.

Apple Silicon·macOS 14 이상 대상입니다. 다른 Mac에 직접 접속한 검증은 아닙니다.
