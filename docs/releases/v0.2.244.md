# AutoApprove 0.2.244

이미 진행 중인 계정 전환에서 재연결을 요청하면 기존 전환의 결과를 확인합니다. 새 로그인 요청이나 서버 재시작 예약을 추가하지 않습니다. 자동 서버·계정 확인과 겹친 요청은 현재 확인을 기다린 뒤 진행합니다.

중단 요청의 응답을 놓쳐 ‘확인 필요’가 된 경우에도 현재 상태를 다시 읽습니다. 같은 로그인·서버·대화·실행 차례에서 예약된 작업이 실제로 대기 상태가 된 것을 확인하면 기존 전환을 이어갑니다. 결과가 불명확한 중단 요청과 서버 재시작은 반복하지 않습니다. 신원이 바뀌거나 작업이 여전히 실행 중이면 보류합니다.

로그인 대기, 기존 전환의 보류 이유, 서버 상태 확인 중을 서로 다른 안내로 표시합니다. [검증 기록](../../VALIDATION.md). 다른 Mac의 실제 전환 완료 여부는 직접 확인하지 못했습니다.
