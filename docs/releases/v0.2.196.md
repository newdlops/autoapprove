# AutoApprove 0.2.196 · build 223

관리 페이지에서 다른 Mac의 Codex·Claude CLI에 로그인할 수 있습니다.

- Mac별 **AI 계정 → PIN 확인 → 공식 인증 → 완료 확인** 흐름을 추가합니다. 같은 네트워크는 LAN으로 직접 연결하고 외부에서는 기존 Cloudflare 경로를 사용합니다.
- Codex는 기기 코드, Claude는 공식 인증 링크와 일회용 코드 입력으로 진행합니다. 완료 후 선택한 Mac에서 해당 CLI를 바로 시작할 수 있습니다.
- 로그인 전용 프로세스를 일반 세션·출력·자동 승인과 분리하고, 기존 터미널은 유지합니다. 취소·만료·미설치·끊김을 구분하고 불확실한 코드를 자동 재전송하지 않습니다.
- PIN·인증 데이터는 로그인 창에서만 불러오는 암호화 모듈로 보호합니다. PIN 변경 시 관리 권한을 폐기하고 로그인 중에는 앱 업데이트를 기다립니다.
