# AutoApprove 0.2.343 · 빌드 370

## 그룹 메시지 전달

- 이름을 바꾼 Claude 세션에도 그룹 메시지를 입력합니다. Claude Code는 바꾼 세션 이름을 입력창 위 테두리 안에 표시하는데, 이전에는 이 테두리를 입력창으로 알아보지 못해서 메시지를 보관만 하고 입력하지 않았습니다.
- 메시지를 보관할 때 사유를 구체적으로 기록합니다. 세션이 작업 중인 경우, 입력창에 작성 중인 글이 있는 경우, 선택지나 확인 화면이 열려 있는 경우, 터미널이 입력을 받을 수 없는 경우, 입력창 모양을 판독하지 못한 경우를 구분합니다.
- 에이전트가 보낸 질문, 답변, 일반 메시지가 10분 동안 입력되지 않으면 보낸 쪽에 한 번 알립니다. 알림에는 받는 구성원, 경과 시간, 보관 사유를 적고, 같은 내용을 다시 보내지 말라고 안내합니다.
- 진단에 "세션 그룹 메시지 전달" 점검을 추가했습니다. 전달이 막힌 구성원 수, 미전달 건수, 가장 오래된 메시지 시각, 보관 사유를 보고합니다.
- 화면에서 상태를 읽지 못한 Claude 세션은, Claude가 직접 기록한 세션 상태(대기, 작업 중)로 상태를 판단합니다.
- 그룹을 만들거나 구성원을 추가하면, 그룹장에게 구성원 이름을 정해 달라고 한 번 요청합니다. 그룹장이 없으면 구성원마다 요청합니다.

## 대화 그래프

- 노드의 색 계열은 에이전트 종류를, 모양은 지금 상태(작업 중, 대기, 응답 필요, 전달 막힘, 상태 미확인)를 나타냅니다. 주황은 답을 기다리는 질문에만 씁니다.
- 기본 보기는 답을 기다리는 질문과 최근 30분 동안 오간 메시지입니다. 주고받은 메시지가 많을수록 선을 굵게 그리고, 새로 생긴 선은 잠시 강조합니다. "전체" 보기에서는 지난 기록과 만료된 질문을 흐리게 볼 수 있습니다.
- 배치는 트리와 원형 가운데 고를 수 있고, 고른 배치는 다시 열어도 유지합니다. 창이 좁으면 노드를 겹치지 않고 스크롤합니다.
- 오른쪽 패널은 구성원을 고르기 전에는 상태가 포함된 구성원 목록을 보여 줍니다. 요약 줄의 "응답 필요"와 "전달 막힘" 숫자를 누르면 해당 구성원을 고를 수 있습니다.
- 메시지나 구성원 상태가 바뀌면 그래프에 바로 반영합니다. 노드를 끌면 노드와 연결선이 포인터를 바로 따라옵니다.
