# AutoApprove 0.2.311 · 빌드 338

0.2.310에 이어, AutoApprove 앱이 주기적으로 반복하는 작업 두 가지의 비용을 줄였습니다. 같은 터미널 탭 24개 조건에서 앱의 CPU 사용률이 약 4.4%에서 약 2%로 낮아졌습니다.

## OS 권한창 검사

OS 권한창 검사는 1초마다 실행됩니다. 지금까지는 실행할 때마다 실행 중인 모든 앱의 번들 ID와 PID를 LaunchServices에 다시 묻고, 권한창을 띄우는 Apple 앱의 코드 서명을 처음부터 다시 검증했습니다. 이 작업이 앱 CPU 사용 시간의 약 35%를 차지했습니다.

- 권한창을 띄우는 Apple 앱 9종만 번들 ID로 찾습니다. 실행 중인 앱 전체 목록은 권한창을 요청한 앱을 찾아야 할 때만 읽습니다.
- 통과한 서명 검증 결과는 PID, 실행 시각, 번들 경로가 같은 프로세스에 한해 5분 동안 재사용합니다.
- 권한창의 버튼을 누르기 직전에는 지금처럼 소유 앱의 서명과 시작 시각을 새로 검증합니다.

30초 동안 수집한 프로파일 표본에서 이 검사가 차지한 표본 수가 373건에서 25건으로 줄었습니다.

## 그룹 작업 보고 전달

그룹장이 수신 확인하지 않은 작업 보고가 남아 있으면 전달 작업이 2초마다 반복됩니다. 지금까지는 반복할 때마다 남은 보고 수만큼 그룹 설정 파일을 다시 읽고 수신함 데이터베이스의 쓰기 트랜잭션을 열었습니다.

- 그룹 설정 파일은 반복마다 한 번만 읽습니다.
- 이미 수신함에 저장되었고 아직 수신 확인을 받지 못한 보고는 수신함이 자체 재시도 일정에 따라 다시 알립니다. 보고 내용과 수신 확인 규칙은 바뀌지 않습니다.

## 검증

전체 회귀 검사 **279/279**가 통과했습니다. 설치한 앱의 CPU 사용 시간은 60초당 2.65초에서 120초당 약 2.3초(60초당 약 1.2초)로 줄었습니다. 측정하는 동안 다른 작업 때문에 시스템 부하 평균이 11~128 사이로 오르내려서, 수치에 오차가 있습니다. 상세 결과는 [VALIDATION.md](../../VALIDATION.md)에 기록합니다.
