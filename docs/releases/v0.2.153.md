# AutoApprove 0.2.153 · 빌드 180

터미널 창 크기 조절 중 충돌 보고에 대한 추가 안정화입니다. 0.2.151에서 테두리 표시용 크기 조회를 제거한 데 이어, 커서와 원본 창 확인에 남아 있던 `window.bounds()` 조회도 제거했습니다.

- 원본 TTY와 선택한 탭·창 ID를 확인한 뒤 macOS의 현재 창 메타데이터를 읽습니다. 창 소유자 검증과 입력 직전의 원본 확인은 유지합니다.
- 커서 확인은 현재 OS 좌표를 사용합니다. 창 크기가 달라져 접근성 정보와 일치하지 않으면 해당 커서 정보만 생략합니다. 잘못된 크기·무한대·NaN·좌표 계산 넘침은 거절합니다.
- 터미널에 창 크기를 묻는 Apple 이벤트와 스크립트 결과의 중복 좌표를 줄였습니다. 테두리는 기존처럼 장식 창 하나를 재사용하며 자동 승인 감시 중에는 표시하지 않습니다.

실제 사용자 Terminal의 크기를 바꾸거나 충돌을 재현하지 않았습니다. 이 변경을 Terminal 충돌의 원인 규명이나 완치로 주장하지 않습니다. 시스템 자동 실행 등록·권한 상승·보안 도구·VPN·권한 설정 변경은 없습니다.
