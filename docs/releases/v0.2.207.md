# AutoApprove 0.2.207 · build 234

기본 Terminal의 Codex가 오래 `Working`으로 남아 있을 때 **30분 진척 확인**을 수행합니다. 화면 표시만으로 모델이 중지됐다고 단정하지 않고, 진행 상황을 확인한 뒤 기존 작업을 이어가도록 요청합니다.

- **대상:** 이 Mac의 기본 Terminal에서 자동 승인이 켜진 Codex 세션입니다. 연결 설정의 **Codex 진척 확인 → 이 Mac의 Codex 자동 진행 확인**, 웹 세션의 **이 Mac의 Codex 자동 확인**에서 켜거나 끕니다. 기본값은 켜짐입니다.
- **기준:** 타이머·스피너를 제외한 화면 변화와, 정확히 연결된 대화 기록의 갱신을 봅니다. 기록 연결이 없으면 화면 출력을 기준으로 삼습니다. 앱 재시작·긴 관찰 공백 뒤에는 30분을 새로 셉니다. 이 시간은 모델 중지의 확정 기준이 아닙니다.
- **복구:** 원래 PID·실행 시각·TTY·입력 대상을 새로 검증해 Esc를 한 번 보냅니다. 중단 뒤 빈 입력창이 반복 확인되면 완료한 변경·검증 결과·막힌 지점·다음 단계를 보고하고 기존 요청을 이어가도록 한 번 전송합니다. 이미 끝난 차례가 대화 기록에서 확인되면 새 요청을 자동으로 보내지 않습니다.
- **조작:** 세션의 **진행 확인·이어가기**로 수동 확인을 시작하고, 진행 중에는 **진행 확인 취소**를 누릅니다. 전체 일시정지·자동 승인 OFF·사용자 입력·승인/질문 대기·연결/대상 변경은 후속 입력을 멈춥니다. 취소 전에 이미 전달된 입력은 원래 Terminal에서 확인하세요.
- **미확인 결과:** 중단이 확인되지 않거나 입력 결과가 불확실하면 **진척 확인 필요**로 표시하며 자동 재전송하지 않습니다. 같은 감시 구간의 자동 확인은 최대 3회로 제한합니다. 전송 전후 기록을 남기며 재시작 뒤 미확인 입력도 자동 반복하지 않습니다.

자동 감지·입력 순서·경합 검사는 격리된 합성 Terminal과 실제 Core HTTP/브라우저로 검증했습니다. 실제 사용자 Terminal에서 의도적으로 작업을 중단해 시험하지 않았습니다. 자세한 검사·배포·설치 결과는 [검증 기록](../../VALIDATION.md)에 있습니다.
