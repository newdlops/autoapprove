# AutoApprove 0.2.205 · build 232

세션 프로필 저장 중 `TypeError: null is not an object (evaluating 'window.selectedTab().tty') (-2700)`로 실패하던 문제를 수정했습니다.

- 저장 대상 탭이 없는 Terminal 창은 선택 탭이나 창 메타데이터를 읽지 않고 건너뜁니다. 빈 창이 함께 있어도 저장 대상 창의 수집을 계속합니다.
- 대상 탭은 있지만 Terminal이 선택 탭을 반환하지 않으면 해당 선택 상태만 비워 두고 창 묶음·탭 순서·설정 프로필·제목을 저장합니다. 원래 탭을 임의로 선택하거나 이동하지 않습니다.
- 대상 탭이 실제로 사라졌거나 중복되면 불완전한 프로필 저장을 거부합니다. 권한과 읽기 실패도 기존 오류로 전달합니다.

업데이트한 앱에서 **세션 프로필(⌘⇧P) → 새 프로필**을 다시 눌러 저장하세요. 기존 프로필은 **프로필 관리 → 현재 창으로 갱신…**으로 갱신합니다.

재현·검사와 실제 Terminal 접근 도구의 제한은 [검증 기록](../../VALIDATION.md)에 있습니다.
