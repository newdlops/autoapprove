# AutoApprove 0.2.50 · 빌드 61

휴대폰에서 질문에 답하고 Codex 대기 입력을 비우며 테스트 화면을 바로 공유할 수 있습니다.

- 질문 편집 상태 갱신 중에도 선택한 응답을 보내면 확인 뒤 한 번만 전달합니다. 실패 이유는 질문 안에 표시하며 초안·선택을 보관합니다.
- **질문·메시지 → 대기 입력**에서 Codex의 실제 `queued follow-up inputs`를 보고 비울 수 있습니다. 현재 목록의 최대 100개를 삭제하고, 새로 들어온 입력과 실행 중인 작업은 유지합니다. 삭제한 질문 답변은 취소 상태로 돌아갑니다.
- 최신 Codex에서 대화가 자동으로 연결되지 않으면 **Codex 대화 연결**에서 실행 중인 대화를 한 번 선택할 수 있습니다. 터미널을 재시작할 필요가 없습니다.
- **테스트 화면**을 누르면 선택한 Mac의 기존 MCP 공유를 바로 열거나 전체 화면 공유를 시작합니다. 별도 프로그램이나 휴대폰 설치는 필요 없습니다. 공유는 10분 뒤 만료되며 직접 종료할 수 있습니다.

각 Mac을 0.2.50으로 업데이트하고 휴대폰 페이지를 새로고침해주세요. 대기 입력 관리에는 해당 Codex 서버의 대기열 API가 필요합니다. 화면 녹음 권한은 macOS 설정에서 사용자가 허용해야 합니다. 기존 터미널·대화를 재시작하거나 새 PTY를 만들지 않습니다.

검증 범위와 실제 휴대폰 확인 상태는 [VALIDATION.md](https://github.com/newdlops/autoapprove/blob/main/VALIDATION.md)에 기록합니다. 설치 파일은 `AutoApprove-0.2.50-macOS-arm64.dmg`입니다.
