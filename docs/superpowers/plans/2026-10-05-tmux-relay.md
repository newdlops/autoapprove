# tmux 원본 중계

유료 Apple 개발자 계정 없이, 각 Mac에 설치한 tmux의 기존 pane을 휴대폰 브라우저와 공유한다. 일반 출력·입력에는 관리자 서비스, 손쉬운 사용, 화면 기록 권한을 요구하지 않는다. 이미 tmux 밖에서 실행 중인 CLI는 종료하거나 이전하지 않는다. 공유할 새 CLI는 Mac에서 `tmux new-session -A -s autoapprove` 안에 실행한다.

기존 연결 설정의 시스템 글꼴, SF Symbols, 의미 색상, 24pt 여백과 스크롤을 재사용한다. tmux 설정을 원본 터미널 권한 설정 위에 두고 설치 상태, 같은 창의 연결 상태, 시작 명령 복사를 제공한다. 설치 없음·세션 없음·연결 중·연결됨·연결 해제·오류를 구분한다. 휴대폰의 기존 터미널·키보드·자동 승인 스위치를 그대로 사용한다.

원본 선택은 CLI의 PID·시작 시각·TTY와 tmux 서버 PID·시작 시각·소켓·pane ID를 함께 고정한다. 크기에 영향을 주지 않는 control mode로 원본 변경을 받고 ANSI 셀·커서 위치를 전달한다. 조회에는 읽기 명령만 사용한다. 입력은 해당 pane에 tmux의 공개 입력 명령으로 보내며, 다른 pane 동시 입력 옵션이 켜져 있으면 거부한다. 웹 조회·접속·해제는 pane 생성·CLI 재시작·크기 변경·세션 종료를 수행하지 않는다. 자동 승인은 기존 명시적 ON/OFF 설정을 유지한다.

검증은 사용자 세션과 다른 전용 소켓의 테스트 CLI에서 수행한다. 실제 색상·커서·한글 및 제어 키 바이트, 대상 교체·종료·동시 입력 차단, 관찰자 해제 후 원본 유지, 출력 반영 속도를 확인한다. 빌드·기존 Core 검사와 별도로 설정 light/dark 렌더링, 모바일 390×844·태블릿 768×1024·데스크톱 1440×900에서 브라우저 직접 입력과 상태 표시를 확인한다. 실제 휴대폰 및 SentinelOne 최종 판정은 도구로 확인하지 않은 범위로 명시한다.
