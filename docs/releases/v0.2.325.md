# AutoApprove 0.2.325 · build 352

Codex 그룹원의 개별·전체 ID 갱신과 MCP 재연결은 현재 실행 세션에 연결된
로컬 대화 기록에서 UUID를 먼저 확인합니다. 로컬 기록으로 확정할 수 없으면
해당 세션에 연결된 최근 MCP 호출의 대화 UUID를 확인합니다. 갱신은 터미널에
입력하지 않아, 작업 중이거나 입력창에 작성 중인 내용이 있어도 조회할 수 있습니다.

공유 서버에서 호출자의 UUID만 확인되는 경우에는 그 UUID가 속한 그룹 정보를
조회할 수 있습니다. 새 UUID를 터미널에 연결하려면 해당 실행 세션을 확인해야
합니다. 그룹원 ID는 출처를 확인한 뒤 저장하며, 로컬 기록이 생기거나 대상
Codex가 `get_session_groups`를 호출하면 다시 조회할 수 있습니다.

MCP 호출 정보는 최대 2분 동안 사용합니다. 연결이 종료되거나 원래 터미널의
초기화가 확인되면 해당 정보를 폐기합니다. 자동 관찰과 수동 갱신이 같은
ID를 확인하면 두 요청 모두 같은 결과로 완료합니다.

전체 디버그 회귀검사 322개와 네트워크 차단 그룹 검사(디버그 50개,
릴리스 48개)를 통과했습니다.
격리된 공식 Codex 0.169.0에서 로컬 기록만으로, 그리고 MCP 호출만으로
각각 그룹원의 UUID를 저장하는 동작을 확인했습니다.
