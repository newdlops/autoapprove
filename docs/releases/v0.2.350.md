# AutoApprove 0.2.350 · 빌드 377

- 대화 그래프의 "닉네임 정하기 요청"이 동작하지 않던 문제를 고쳤습니다. 그룹장은 요청을 받았지만, 사용자가 보낸 요청인지 확인할 수 없고 사용할 도구도 보이지 않는다며 처리하지 않았습니다.
- AutoApprove 가 보내는 알림은 이제 보낸 사람을 "AutoApprove 알림"으로 표시하고, `get_group_messages` 로 원문을 확인하는 방법을 함께 적습니다. 이전에는 받는 구성원 자신의 이름과 ID를 보낸 구성원으로 적어서, 위조된 메시지처럼 보였습니다.
- 닉네임 요청에는 요청이 어디서 왔는지(버튼을 누른 요청인지, 구성원을 추가해 자동으로 보낸 요청인지), Claude Code 에서 쓰는 도구 이름(`mcp__autoapprove__set_group_member_title`), 도구가 보이지 않을 때 불러오는 방법을 적습니다.
- 요청을 한 줄로 보내서 구성원 목록이 붙여넣은 글 블록으로 바뀌지 않습니다.
- 이미 요청한 구성원이라도 버튼을 다시 누르면 한 번 더 요청합니다. 구성원을 추가할 때 자동으로 보내는 요청은 지금처럼 구성원마다 한 번만 보냅니다.
