# AutoApprove 0.2.297

- 그룹 목록 조회·자동 새로고침에서 `/status`를 입력하던 동작을 제거했습니다. 대화 ID 탐색 재시도와 2분 만료로 조회 명령이 입력 큐에 반복해서 쌓이지 않습니다.
- 세션 ID 갱신은 프로세스에서 확인한 현재 ID 또는 같은 실행 세션에서 확인한 조회 결과를 우선 사용합니다. ID가 없을 때만 사용자가 요청한 갱신에서 빈 대기 입력창을 확인하고 `/status`를 전송합니다. 동시에 같은 터미널을 조회하는 요청은 차단합니다.
- 이전 자동 이어가기의 결과 확인 대기가 읽기 목적의 ID 조회를 막지 않도록 했습니다. 실제 작성 중인 입력·실행 중인 작업·질문·승인은 계속 보호합니다. 대기 상태 확인 실패를 모두 입력창 내용 때문이라고 안내하지 않습니다.
- 터미널 실행 상태와 대화 ID 확인 상태를 구분하고 그룹 창의 관찰 결과를 자동 반영합니다. 작업 전달은 기존의 정확한 대화 ID 매칭을 유지합니다.
- 0.2.296의 프로필 복원 실패 격리와 미전송 탭 연결 실패 시 새 창 복원도 포함합니다.

검증: 그룹 ID 조회·중복 입력 방지·실제 입력 보호 및 연결 매칭 회귀 검사, macOS 앱 빌드, 기존 그룹 창 렌더 확인.
