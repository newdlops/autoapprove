# AutoApprove 0.2.202 · build 229

Codex·Claude Code 창의 대화를 여러 프로필 파일로 저장하고, 재부팅 뒤 선택해 다시 엽니다. Mac Terminal의 Computer Use 허용창 제출도 보완했습니다.

- 관리 창의 **세션 프로필** 또는 **⌘⇧P → 새 프로필**에서 현재 창을 불러와 이름을 정하고 저장합니다. 창별 작업 폴더·CLI 종류·대화 ID·복원 앱을 보관합니다. 프로필은 여러 개 만들고 편집하거나 현재 창으로 갱신할 수 있습니다.
- 프로필을 선택하고 **선택한 세션 복원**을 누르면 저장한 대화를 새 Terminal/iTerm2 창에서 이어갑니다. 이미 실행 중인 대화·복원 중인 항목은 중복으로 열지 않으며, 폴더가 없거나 전달 결과를 확인하지 못하면 항목별로 안내합니다. 이전 명령이나 새 작업 지시를 자동으로 입력하지 않습니다.
- **프로필 폴더**에서 개별 JSON 파일을 보고, **프로필 관리** 메뉴에서 이름을 편집하고 파일을 내보내거나 휴지통으로 옮깁니다. **가져오기**로 다른 프로필 파일을 추가합니다. 저장된 프로필은 빈 세션 목록이나 앱 재시작으로 자동 덮어쓰지 않습니다.
- 공유 서버 방식의 Codex처럼 현재 창의 대화 ID를 확정할 수 없으면 저장 전에 해당 폴더의 대화를 직접 선택합니다. 최근 대화를 임의로 골라 저장하지 않습니다. 프로필 파일에는 대화 본문·인증 정보가 들어가지 않으며, 복원할 Mac에 해당 CLI 대화 기록이 남아 있어야 합니다.
- `Allow Computer Use to use …?` 창은 전체 승인창과 1번 Allow 선택을 다시 확인한 뒤 **단독 Enter**로 제출합니다. 숫자와 Return을 함께 붙여넣는 기존 경로와 구분합니다. 일반 명령/다른 호스트의 입력 방식을 유지합니다.
- 승인 전달 직후 짧게 지나가는 실제 작업 상태를 한정된 추가 읽기로 확인해, 동일한 허용창이 바로 다시 뜰 때 이전 승인 기록에 막히는 경우를 줄입니다. 같은 창·빈 화면·입력 초안은 새 요청의 증거로 쓰지 않습니다. OFF·일시정지·원본 PID/시작 시각/TTY 검증과 중복 방지를 유지합니다.
- 승인 확인 안내가 단어 중간에서 줄바꿈돼도 완전한 안내 문구를 인식합니다. 불완전한 문구·이후 새 입력·일반 질문은 계속 거부합니다.

검사와 실환경 관찰의 범위는 [검증 기록](../../VALIDATION.md)에 있습니다.
