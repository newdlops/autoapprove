# 0.2.215 · N번째 탭과 창별 복원 순서

- **N번째 탭:** 두 번째 탭에만 있던 접근성 객체 재생성 처리를 모든 탭 추가에 적용합니다. 이전 AX 막대·탭 객체가 유지되어야 한다는 가정을 제거하고, 탭 수 증가·원래 탭 다음의 추가 위치·남아 있는 객체의 순서를 확인합니다. 정확한 원래 TTY와 새 TTY를 각각 선택해 같은 현재 탭 묶음과 위치를 검증한 뒤 명령을 전달합니다.
- **창별 완료:** 한 창의 선택된 항목을 순서대로 열고 저장된 선택 탭까지 복원한 뒤 다음 창으로 넘어갑니다. 모든 창을 연 다음 임의 순서로 이전 창에 돌아가던 선택 복원 단계를 제거했습니다.
- **재시도:** 확인하지 못한 탭이나 명령을 자동으로 반복 실행하지 않습니다. 정확한 프로세스·창·TTY·빈 셸 검사와 불확실한 그룹의 후속 중단을 유지합니다. 저장된 프로필 형식과 화면은 유지합니다.

프로필 상한 128개까지 **2~128번째 각각의 추가 × AX 객체 재생성 4종, 총 508건**을 검사합니다. 세 창의 **7·4·9개 탭**을 뒤섞인 저장 순서로 받아도 창별 열기·선택 완료 순서가 맞는지 확인했습니다. 관련 탭 29개·기존 프로필 8개 검사가 통과했습니다.

전체 회귀는 **596/597**이며, 실패 1건은 이전 버전과 같은 별도 루프백 주소 재사용 검사의 `NWError 49`입니다.

격리된 실제 AppKit 창에서 프로덕션 opener로 **1→20개 탭**, 네이티브 막대·탭 객체 재생성 **9회**, 실제 AX 그룹·순서·선택 확인이 통과했습니다. Terminal 실행과 키 전달은 주입된 어댑터입니다. 컴퓨터 조작 도구가 실제 Terminal 접근을 거부하므로 사용자 Terminal 전체 복원 성공을 확인한 결과와 구분합니다. 상세 회귀·배포·정식 설치 결과는 [검증 기록](../../VALIDATION.md)에 남깁니다.
