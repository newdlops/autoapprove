# 0.2.238 · 상단 계정 아이콘과 Codex 재연결

메인 화면 상단의 사람 모양 **계정·로그인** 아이콘에서 별도 계정 창을 엽니다. **⌘⇧L**과 창 메뉴로도 열 수 있고, **완료·Esc**로 닫아도 진행 중인 로그인·전환은 계속됩니다. 연결 설정에서도 같은 창을 엽니다.

수동 재연결이 서버 위치를 확인하는 동안 자동 계정 검사가 시작돼 정상 연결도 “서버·세션이 바뀌었습니다”로 처리하던 경합을 수정했습니다. 조회 전에 재연결을 예약하고 중복 요청을 막습니다. 취소·앱 종료·실제 대상 변경 검증은 유지합니다.

**연결 다시 확인**은 이 Mac의 연결 정보를 다시 읽습니다. 연결이 확인된 홈에서만 **현재 로그인으로 세션 재연결**을 사용할 수 있습니다. 일시적으로 연결을 확인하지 못한 경우 서버가 없다고 단정하지 않으며, 오류 후에는 연결 상태를 새로 읽습니다. 전체 계정 창에서는 서버 조회가 실패해도 선택한 홈의 브라우저 로그인을 시작할 수 있습니다. 특정 세션에서 시작하는 로그인은 해당 세션의 연결을 계속 검증합니다.

지원 배포는 **Apple Silicon Mac · macOS 14 이상**입니다. 사용자명·Codex 홈·CLI 설치 경로·서버 소켓을 머신마다 확인하며 이 개발 머신의 값을 배포에 고정하지 않습니다. 서로 다른 홈과 CLI 경로를 넣은 세 가지 격리 프로필로 검증했습니다. 실제 두 번째 Mac에서의 실행은 아직 확인하지 않았습니다. 자동 전환은 기존과 같이 연결 증거가 확인되는 공식 관리형 Codex 0.166.0 이상이 대상입니다.

실제 사용자 세션을 중단하거나 계정을 전환하는 방식으로 시험하지 않았습니다. 합성 서버·계정·PTY를 이용한 검사와 별도 네이티브 화면 검증 범위는 [검증 기록](../../VALIDATION.md)에 기록합니다.
