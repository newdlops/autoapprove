# AutoApprove 0.2.251

한 Codex 홈의 로그인 전환이 보류됐을 때 다른 홈의 자동승인까지 멈추던 문제를 수정했습니다. 서버 연결이 확인된 독립 세션은 계속 승인하고, 전환 중인 원본 세션과 연결을 아직 확인하지 못한 세션은 대기합니다.

전환 전에 대기 중인 자동 입력을 정리하고 전달 완료를 기다리는 범위도 해당 홈으로 제한했습니다. PID·시작 시각·TTY를 함께 확인하며, 앱을 다시 열어도 같은 차단 범위를 유지합니다.

계정별 세션 통합·분리 기능은 아직 개발 중입니다. 이번 수정이 실제 브라우저 로그인·SSO 또는 선택 세션 이관 전체의 완료를 뜻하지는 않습니다.
