# AutoApprove 0.2.83

Wi-Fi 교대 연결 개발을 취소하고 검사본에 추가했던 기능·설정·권한 요청·웹 안내를 제거했습니다. Mac의 Wi-Fi를 자동으로 바꾸지 않습니다.

0.2.81의 자동 승인·오류 복구·웹 관리·원본 터미널 입력을 유지합니다. 0.2.82 검사본을 받은 Mac도 같은 네트워크의 제거 버전으로 업데이트할 수 있도록 버전만 올립니다. 실행 중인 원본 CLI를 다시 시작하거나 기존 입력 서비스를 재설치하지 않습니다.

휴대폰 설치는 필요 없습니다. Mac의 기존 자동 승인·알림·마우스 신호·잠자기·화면 공유 설정은 유지됩니다.
