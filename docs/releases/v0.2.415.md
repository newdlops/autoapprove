# AutoApprove 0.2.415 · 빌드 442

동시에 요청한 세션 새로고침이 하나의 프로세스 조회를 기다린 뒤 최신 목록을 사용합니다. 첫 프로세스 조회가 지연돼도 이미 확인된 세션의 화면과 Codex 기록 감지는 시작됩니다. 프로세스 분류와 Claude 등록 정보 조회는 백그라운드에서 처리합니다.

여러 터미널 호스트를 선택해 새로고침하면 호스트별로 동시에 확인합니다. 같은 호스트에서는 겹치는 범위의 조회 결과를 공유하고, 아직 읽지 않은 탭은 앞선 조회가 끝나면 확인합니다. 재연결 전의 화면이나 오류가 새 연결에 반영되는 문제를 수정했습니다.

그룹 권한 설정과 개별 설정을 연이어 변경하면 같은 세션의 같은 권한에는 나중에 요청하여 적용된 설정이 유지됩니다. 다른 구성원과 겹치지 않는 권한은 계속 적용됩니다.
