# AutoApprove 0.2.323 · build 350

그룹의 개별·전체 세션 ID 갱신을 누르면 Codex의 원래 탭에서 `/status`를 한 번
조회해 새 응답의 대화 UUID를 확인합니다. macOS Terminal에서는 탭을 선택하거나
창을 앞에 띄우지 않고 조회합니다. 빈 입력창이 확인된 Codex는 작업 중에도 조회할
수 있고, 작성 중인 초안이나 질문·승인 입력은 보호합니다.

새 응답을 확인할 수 없거나 조회 중 원래 세션이 바뀌면 기존 ID를 유지합니다.
새 응답으로 반증된 이전 실행 기록은 갱신한 ID를 덮어쓸 수 없습니다. 연결된
구성원은 해당 프로세스부터 조회하고, 원래 연결을 찾을 수 없으면 같은 UUID를
가진 실행 세션만 확인합니다. Claude는 실행 세션에 연결된 등록 정보로 확인합니다.

전체 갱신에는 ID 변경, 기존 ID 확인, 보류·실패 수를 각각 표시합니다. 실패 사유는
기존 결과 목록에서 확인할 수 있습니다. 이 변경은 [#14](https://github.com/newdlops/autoapprove/issues/14)의
갱신 최신성 문제를 다룹니다. 혼합 그룹 진단과 MCP 호출자 식별은 별도 범위입니다.

릴리스 회귀 검사 291개, 외부 IP 네트워크를 차단한 그룹 검사 50개, MCP 로컬
연결 검사에 통과했습니다.
격리된 Mac 그룹 창에서 전체 갱신을 실행해 변경·확인·실패 수와 실패 사유를
확인했습니다. 원래 작업 중인 터미널에는 검증용 조회를 보내지 않았습니다.
