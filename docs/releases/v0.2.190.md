# AutoApprove 0.2.190 · build 217

터미널 입력을 지속 연결에서 순서대로 연속 전송해 확인 응답을 기다리는 시간을 줄입니다.

- 기존 원본과 PTY의 식별·권한·입력 순서를 유지합니다. 확인된 유휴 연결은 자동 복구하고,
  전달 여부가 불확실한 입력은 다시 보내지 않으며 미전송 텍스트를 보존합니다.
- 웹 터미널 상단에 입력 왕복 지연을 표시합니다. 연결 설정의 **연결 품질**에서 공개 주소
  왕복·처리 지점·연결 도구 지연·손실·재연결 횟수를 확인하고 다시 측정할 수 있습니다.
- Cloudflare HTTPS 443 중계는 입력 확인을 대량 출력보다 우선하며 큰 출력을 압축합니다.
  구형 중계와 WebSocket을 사용할 수 없는 환경은 기존 HTTP 입력으로 연결합니다.
- 연결할 때 소유한 Worker 코드만 갱신합니다. DNS·도메인·연결 비밀을 보존하며,
  업데이트가 지연돼도 기존 중계로 접속합니다.
