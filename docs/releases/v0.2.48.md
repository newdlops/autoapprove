# AutoApprove 0.2.48 · 빌드 59

연속 입력 중 백그라운드 창 조회가 실패하면 웹 터미널의 입력 연결까지 중단되던 문제를 수정했습니다.

- 백그라운드 승인 감시의 임시 오류가 선택한 원본 터미널의 화면 캐시·입력 대상·진행 중 조회를 지우지 않도록 분리했습니다.
- 선택한 원본 화면을 잠시 읽지 못하면 같은 세션으로 자동 재연결하고, 그동안 작성한 미전송 입력을 이어서 전달합니다.
- 실제 자동화 권한 거부는 원본 화면·입력 연결을 차단합니다. 오래된 화면·PID·시작 시각·TTY·전경 프로세스 검증과 접수 불명 입력의 재전송 방지는 유지합니다.

실제 Swift HTTP/SSE와 Chromium의 두 브라우저에서 감시 오류를 주입하며 연속 한글 입력·포커스·정확한 단일 전달을 검증했습니다. 원본 PID·TTY·대화를 유지하며 복구를 위해 별도 PTY를 만들지 않습니다.

휴대폰 페이지를 한 번 새로고침하면 적용됩니다. 검증 범위와 남은 실제 휴대폰 확인은 [VALIDATION.md](https://github.com/newdlops/autoapprove/blob/main/VALIDATION.md)에 기록하며 설치 파일은 `AutoApprove-0.2.48-macOS-arm64.dmg`입니다.
