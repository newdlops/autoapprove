# AutoApprove 0.2.284 · 세션 복원의 내장 클라이언트 유지

프로필 복원 시 서버 버전에 맞춰 외부 Codex CLI를 실행하던 경로를 수정했습니다. 앱 내장 0.167.1 클라이언트와 실행 중인 0.167.2 서버의 조합이 확인된 경우, 앱 내장 클라이언트로 기존 서버에 연결합니다. 외부 실행 파일·서버·자동 시작 설정은 변경하지 않습니다.

확인하지 않은 다른 서버 버전에서는 외부 CLI로 조용히 전환하지 않고 AutoApprove 업데이트가 필요하다고 알립니다. 앱에 이미 포함된 런타임을 그대로 재사용하며 새 Rust 패치나 빌드는 포함하지 않습니다.

격리된 로컬 사례에서 공식 0.167.2 클라이언트는 자동 처리된 자식 승인에 응답하면 `Not available in TUI yet for thread …`를 재현했습니다. 같은 0.167.2 서버에 현재 앱의 내장 클라이언트를 연결한 경우 승인 창이 정리되고 자식 명령과 턴이 완료됐습니다. 이 확인은 승인 사례이며 일반 질문 전체의 해결을 검증한 것으로 확대하지 않습니다.

Release 앱 빌드와 Debug 런타임 선택 검사 1/1을 통과했습니다. 전체 검사 묶음과 UI 시각 검사는 반복하지 않았습니다. 진행 중인 기존 터미널은 이 변경만으로 실행 파일이 교체되지 않으며, 이 수정은 새 프로필 복원부터 적용됩니다.
