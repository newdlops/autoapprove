# AutoApprove 0.2.298

- 그룹 작업·보고 전달에 필요한 원본 텍스트 읽기를 커서·선택 창 등 화면 표시용 조회와 분리했습니다. 표시 정보 조회의 시간 초과 때문에 작업 전달까지 막히는 경로를 제거했습니다.
- 원본 TTY의 최신 텍스트, 프로세스 신원, 질문·입력 충돌 검사는 유지합니다. 텍스트 자체를 읽지 못하면 전송하지 않으며, 실패 원인은 승인 내역에 기록합니다.
- 자동 `/status` 입력 제거 등 0.2.297 수정은 유지합니다.

검증: 표시 정보 조회 실패 상태에서 그룹 작업 전달 성공, 텍스트 채널 실패 시 입력 0회 및 미접수 기록 제거, 기존 Claude 전달·그룹 보고 관련 검사, macOS 배포 빌드.
