# AutoApprove 0.2.290

- 부모 대화가 연결된 Codex에서도 명령 승인 요청을 실제 터미널 화면으로 확인하고 자동 승인합니다.
- 서버의 승인 감시는 자식 대화만 처리하여 부모 터미널 입력과 중복 응답하지 않습니다.
- 일시정지, 자동 승인 끄기, 현재 화면과 선택 검증, 시스템 변경 보호를 유지합니다.

그룹의 /clear 이후 대화 ID 자동 갱신 문제는 이번 릴리스에서 해결되지 않았습니다.

검증: Release 빌드 성공. 명령 승인 1/1, 파일 편집 승인 3/3, 시스템 보호 14/14, 그룹 11/11 통과. 부모·자식 동시 승인과 중복 방지 시뮬레이션은 변경 소스의 Debug 빌드에서 통과했습니다. 해당 시뮬레이션의 Release 재실행은 `@testable` 모듈 설정 제한으로 실행되지 않았습니다. 전체 검사 모음은 이번 릴리스에서 실행하지 않았습니다.
