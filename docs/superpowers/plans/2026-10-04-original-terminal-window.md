# Original terminal window and ANSI sharing

The user wants Terminal, iTerm2, Orca and VS Code-family original sessions to show and control the same work on Mac and phone. Default to an SSH-style original terminal with output and direct keys. Preserve PID, start time, TTY, input streamID and the original owner's source identity. Capture a verified window only after the user turns on Mac window view; OFF, reload, session switch and hidden browser revoke this view. Default GET, SSE and connect never capture or request screen permission. Retain the VS Code ANSI reader across app reconnects, keep exact-object input usable when historical output is unavailable, and offer explicit verified editor-window viewing. Read Orca's owner-provided complete ANSI snapshot through control-only daemon RPC and render cells/cursor without attaching or starting another PTY. Do not install anything on the phone or add an external service.

The design is recorded in DESIGN.md. This is an addition to the existing original-session HTTP/SSE and input flow. It does not take ownership of an already running PTY. Mac screen-sharing and Accessibility access must be granted by the user. GET requests never request permissions or activate a window.

1. Add native window rendering to the original frame. Resolve the exact selected Terminal tab and immutable window ID, capture that one window with ScreenCaptureKit, and verify the target before and after capture. Share bounded pending/cache work. Reject inactive, changed and oversized frames. Preserve ordinary text frames and other adapters. Add explicit original-connect permission/reveal handling with existing peer forwarding and receipts. Verify identity, no-fork and image-state behavior with injected native fixtures.
2. Render the native image inside the existing terminal area with fit, zoom and contained panning. Preserve actual colors/cursor without a fake overlay. Expose permission, inactive, unavailable and disconnected states and the explicit original-connect action. Keep compose optional when native direct input is unavailable. Exercise real Chromium JPEG/SSE fixtures, source/input identity, zero PTY creation, compact frames and three viewports; inspect the resulting screens separately.
3. Add the Mac permission controls and screen-capture usage description, build 0.2.43/52, and verify relevant native, browser and relocated-package checks. Inspect native permission states. Create and verify the DMG. Install with backup and saved-setting/approval-record checks; do not stop a new live app-owned PTY without approval. Read-only installed checks must prove default nativeDisplay absence and distinguish text from explicit window capture. Publish only a reviewed, verified release and record remaining permission or physical-phone checks honestly.

Ownership: the native agent owns Core/capture and native fixtures; root owns web and Mac settings UI, browser fixtures, design/docs, version, packaging and release integration. Shared native build cache is used sequentially.

Additional acceptance checks: reject cached images after tab/process changes; require VS Code peer-specific AX window marker, exact visible input and unique terminal name; reject expired/retired reveal requests before activation and use exact Terminal.show without a generic command that can create a PTY. GET must not trigger Automation consent. Orca must fence runtime/PTY/incarnation before/after reads and immediately before writes; a reused handle cannot retarget a still-running CLI. ANSI rendering must preserve RGB, Unicode cell widths, UTF-16 style/cursor offsets, alternate screen and cursor modes. Relay-only sources keep optional composed content as a readable draft and disable unsupported submission.

Permission follow-up: a granted macOS Accessibility record was bound to an older ad-hoc cdhash and failed to match the installed app after updates. Keep a persistent, signer-bound publisher certificate rather than a binary hash or identifier-only requirement. Validate mutual update compatibility and reject another signer with the same bundle ID. Terminal direct keys should use the trusted main app's exact-owner CGEvent path after original CLI/TTY/window verification, removing child-process AX and System Events dependencies; tests must inspect injected real event payloads without posting to user sessions. User-facing OS permission grants remain explicit.
