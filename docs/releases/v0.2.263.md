# AutoApprove 0.2.263 · 빌드 290

Terminal 직접 입력에서 root 입력 서비스 설치·호출을 제거했습니다. 앱에 보조 서비스나 launch daemon을 포함하지 않으며, TTY 바이트 주입 코드를 제거했습니다. 입력은 실행 중인 AutoApprove 앱의 손쉬운 사용 권한으로 전달합니다.

Mac의 **연결 설정 → 터미널 중계·화면 공유 → 손쉬운 사용 허용**에서 권한을 확인하세요. Terminal 내용을 확인하는 기존 자동화 권한은 필요합니다. 화면 기록은 Mac 창 보기를 선택할 때만 사용합니다. 입력할 때 원본 Terminal 창이 앞으로 나올 수 있습니다.

문자·특수 키·선택지는 같은 원본의 키 이벤트로 전달하고, 여러 줄 텍스트와 메시지는 붙여넣기로 전달합니다. 붙여넣기 결과를 확인한 뒤 Return을 보냅니다. 앱 입력은 직렬화하며 PID·시작 시각·전경 작업·정확한 창과 탭·포커스·권한을 입력 직전에 확인합니다. 일부 입력 후 결과를 확인하지 못하면 자동 재전송하지 않습니다.

예전 버전에서 이미 설치한 시스템 입력 서비스는 이 버전에서 호출하거나 자동 교체하지 않습니다. 기존 시스템 파일을 제거하려면 관리자 권한이 필요할 수 있으며, 새 앱은 제거를 명목으로 관리자 실행을 요청하지 않습니다. tmux·VS Code 등 별도 연결과 잠자기 유지 기능은 기존 경로를 사용합니다.
