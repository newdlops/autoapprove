# AutoApprove 0.2.192 · build 219

Cloudflare 웹과 호스트의 버전을 확인하고 더 높은 정식 버전으로 맞춥니다.

- 웹 상단에 웹·호스트 버전과 **최신 버전 확인**을 표시합니다.
- 호스트가 더 높으면 **최신 화면 열기**로 새 페이지를 엽니다. 원래 페이지의 작성 중인 입력은 유지합니다.
- 웹이 더 높으면 정식 릴리스를 확인하고 **호스트 업데이트**로 적용합니다. 같은 버전에서도 새 정식 릴리스를 찾을 수 있습니다.
- 공식 배포의 아키텍처별 ZIP·SHA-256·게시자 서명을 검증하고 끊긴 다운로드를 이어받습니다. 미공개 버전을 근거로 하위 버전을 설치하지 않습니다.
- 고정 주소의 외부 연결은 명시적인 업데이트 요청 후 재시작하고 기존 PIN을 복원합니다. 기존 로그인은 새 게이트웨이에서 다시 인증합니다.
- 덮개·입력·앱 소유 PTY·화면 공유·자동 업데이트 끄기와 임시 주소 변경 보호를 유지합니다.
- PortManager의 실제 루프백 주소를 따르고 업데이트 후에도 같은 실행 환경을 유지합니다. PortManager 설정은 변경하지 않습니다.
- 앞으로 정식 릴리스에 설치 DMG와 함께 웹 업데이트용 서명 ZIP·체크섬을 게시합니다.
