# AutoApprove 0.2.410 · 빌드 437

보낼 때 send_group_message, ask_group_question, reply_group_question에 priority를 normal 또는 urgent로 지정할 수 있습니다. 일반 메시지의 기본값은 normal입니다. 작업 배정의 permissionPriority는 해당 작업에서 그룹장에게 올라오는 권한 요청에 적용되며 기본값은 urgent입니다.

그룹장은 get_group_messages에 category=permissionRequest와 priority=urgent를 지정해 긴급 권한 요청부터 확인할 수 있습니다. category=message는 일반 전달을 조회합니다. set_group_message_priority는 자기 수신함에서 아직 전달 대기 중인 항목의 우선순위를 변경합니다.

실제 작업자가 기다리는 긴급 권한 요청은 다른 대기 메시지보다 먼저 전달됩니다. 그룹장이 작업 중이고 빈 입력창과 중단 키가 확인되면 원래 대화에 Esc를 보내고 입력이 가능해진 뒤 요청을 전달합니다. 일반 메시지의 urgent는 전달 순서에만 적용됩니다. 권한 선택은 기존 answer_group_question 절차를 따릅니다.
