# 0.2.140 · 반복 안전 검사 CPU 경량화

위험 명령 판정에서 공백을 제거할 때, 단일 ASCII 문자는 정해진 여섯 공백 여부를 직접 확인합니다. 조합형 문자·특수 공백·CRLF 등 나머지 Character는 기존 Unicode 처리를 사용합니다. NFC 정규화·명령 후보 검색·전체 위험 판정·설치 스크립트의 최신 내용 확인은 유지합니다. 판정 결과를 새로 캐시하거나 안전 검사를 생략하지 않습니다.

0.2.139의 실제 Release Core와 같은 합성 Cocoa 화면 16개·500회 감시를 총 8쌍 교대 측정했습니다. 변경 없는 화면의 CPU 중앙값은 **0.426291→0.301778초**, wall은 **0.437199→0.308152초**였습니다. 출력 변경 CPU **5.044236→5.016721초**, wall **5.295963→5.338318초**는 비슷한 수준이며 이 구간의 가속을 주장하지 않습니다. 작업·유휴·승인·질문 상태 각 4개와 publication 0/500회를 유지했습니다. 원본 터미널 읽기·입력·캡처·서버 없이 측정한 처리 경로의 결과이며 앱 전체 CPU·메모리나 실제 휴대폰·VPN 지연의 개선율이 아닙니다.

기존 정책과의 합성 **16,170건** 판정 및 공백 제거 바이트 비교를 통과했습니다. 모든 ASCII 문자, 조합형·한글·emoji·특수 공백과 최신 로컬 설치 스크립트를 포함합니다. 일반 선택 질문은 직접 답하며, Allow·세션 한정 허용·기존 모델 유지와 시스템 변경 거절·안전한 대안 안내 규칙을 유지합니다.

macOS 14 이상 Apple Silicon용이며 빌드는 167입니다. 기존 발행자 인증서를 재사용합니다. 새 서비스·타이머·관리자 권한이나 보안·VPN 설정 변경은 추가하지 않습니다. 설치 방법은 [설치 안내](../../README.md#설치)를 참고하세요.

최종 검증: Release 전체 368/368, 패키지 자동 응답 12건·수동 질문 대기 12건, 일시정지·재시작·응답 유실·중복 방지, 웹·MCP·격리 PTY와 입력 구성요소 검사가 통과했습니다. 측정한 Core의 module·객체·소스와 최종 빌드가 같고, 패키지 코드·웹 리소스·서명·DMG 무결성도 확인했습니다. 사용자 터미널에는 시험 입력을 보내지 않았습니다. 이번에 새 브라우저 시각 검사나 실제 휴대폰 조작 검사를 수행하지는 않았습니다.
