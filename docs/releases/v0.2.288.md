# AutoApprove 0.2.288

- 관리 창의 **세션 그룹**에서 Codex·Claude Code 세션을 묶고 이름과 구성원을 관리합니다. 그룹은 앱을 다시 실행해도 유지됩니다.
- 원래 대화 ID와 설정 홈이 확인된 세션만 재연결하며, 확인하지 못한 구성원은 별도 표시합니다. 동일한 대화가 여러 실행에 연결된 경우 자동으로 선택하지 않습니다.
- AutoApprove MCP의 `get_session_groups`는 현재 세션의 그룹과 구성원을 제공합니다. 에이전트는 같은 도구의 기존 메시지 기능을 사용하며, AutoApprove는 별도의 메시지 큐를 만들지 않습니다.
- 공유 Codex 서버가 호출 세션을 구별하지 못할 때는 `conversationID`에 현재 대화 UUID를 지정할 수 있습니다. 지정한 UUID는 호출자의 주장으로 구분하며, 해당 종류의 유일한 실행 세션과 대조합니다.
- Claude의 메시지 이름은 실행 중인 세션에서 확인되면 `messagingName`으로 제공합니다. 중복되거나 미확인인 이름은 Claude의 기존 메시지 기능에서 실제 수신 대상을 확인해야 합니다. Codex와 Claude 사이의 메시지 전달은 이번 버전에 포함하지 않습니다.

MCP 등록 방법은 [사용 설명서](https://github.com/newdlops/autoapprove#휴대폰-질문메시지와-테스트-화면-mcp)를 참고하세요. 기존 세션은 MCP를 재연결하거나 다음 실행에서 새 도구를 사용할 수 있습니다.
