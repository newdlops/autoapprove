# AutoApprove app icon

`AppIcon.png` is the original generated master (1254×1254 RGBA). Created with the built-in image generation tool on 2026-09-21. No external brand mark is used. `scripts/package-icon.mjs` derives the standard 16–1024 pixel macOS icon representations and `dist/AppIcon.icns`; packaging copies the icon into the app bundle.

Direction: a midnight navy terminal tile with a white prompt chevron and mint approval check. Small-size recognition, restrained depth and a transparent surround are the acceptance criteria. Native in-app controls continue using SF Symbols.

## Generation prompt

```text
Use case: logo-brand
Asset type: final macOS application icon, 1024 x 1024 square PNG with real alpha transparency outside the icon.
Primary request: Design a beautiful, distinctive polished icon for AutoApprove, a native macOS utility that manages developer terminal sessions and approves execution permission requests.
Subject and composition: One large front-facing softly rounded-square midnight navy terminal tile, centered, occupying about 88% of the canvas with generous transparent margins and a very subtle soft contact shadow. Within it a bold warm-white terminal chevron on the left and a large vivid mint-green checkmark on the right, together forming one balanced, instantly recognizable graphic. The chevron and check have the same substantial stroke weight, smooth corners, clean silhouettes and ample breathing room. Restrained shallow dimensionality, precise machined edges and soft upper-left studio light on the navy tile; the two symbols are crisply inlaid or very slightly raised. A beautiful premium Mac developer tool icon, calm and tactile, legible at 16 and 32 px.
Color palette: midnight navy tile, warm-white chevron, mint-green checkmark. Keep the icon self-contained, no dramatic color gradients.
Constraints: a single finished icon asset, no mockup, no surrounding UI, no extra objects, no letters or words, no brand logos, no robot, no shield, no sparkle, no glass, no neon glow. Straight-on view without perspective tilt. Truly transparent background outside the rounded tile, not a checkerboard drawing. Keep the terminal/check graphic large and simple.
```
