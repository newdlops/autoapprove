# AutoApprove 0.2.331 · 빌드 358

세션 그룹 창의 ‘메시지 보내기’에서 같은 그룹의 두 세션을 선택할 수 있습니다. ‘응답 받기’를 켜면 질문으로 보냅니다. 끄면 회신을 기다리지 않는 메시지로 보냅니다.

일반 그룹 메시지, 질문, 답변은 입력 가능한 대상에게 본문을 전달합니다. 한 줄 입력 한도를 넘는 본문은 로컬 수신함의 원문으로 참조할 수 있습니다. 앱은 전달한 입력과 동일한 대화의 응답이 확인되면 그 원문을 원래 질문에 연결합니다.

제출 여부가 불확실한 직접 전달은 로컬 수신함에 남으며 앱 재시작 뒤에도 자동으로 다시 입력되지 않습니다. 다른 메시지의 전달은 계속됩니다. 기존 작업 지시와 승인 위임은 기존 도구에서 사용할 수 있습니다.
