# AutoApprove 0.2.417 · 빌드 444

세션 프로필을 기본 설정으로 저장하면 현재 CLI의 프로세스와 대화 기록에서 세션을 확인합니다. 초안을 열고 선택한 항목을 파일에 저장하는 동안 Terminal이나 iTerm2에 화면 조회, 탭 선택, 키 입력을 요청하지 않습니다. 대화 ID를 확인할 수 없는 항목은 편집기에서 이어갈 대화를 선택하거나 새 CLI 실행을 지정할 수 있습니다.

기존 프로필을 갱신하면 같은 도구·설정 폴더·작업 폴더·대화로 확인한 항목에 저장된 창 배치를 적용합니다. 새 프로필에서 기본 설정으로 저장한 Terminal 세션은 한 창의 탭으로 복원합니다.

현재 배치가 필요하면 프로필 창에서 **저장할 때 현재 창·탭 배치 읽기**를 선택하세요. 이 옵션은 Terminal의 실제 창 묶음, 탭 순서, 선택 탭과 설정을 수집합니다. 처음 창 목록을 읽는 요청은 읽기 전용으로 처리하며, 다른 작업이 잠깐 사용 중이면 제한된 시간 동안 순서를 기다립니다.
