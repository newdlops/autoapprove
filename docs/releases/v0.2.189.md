# AutoApprove 0.2.189 · build 216

직접 지정한 **숫자 PIN**으로 외부 관리 페이지에 접속할 수 있습니다.

1. 클라이언트의 **연결 설정 → 내 접속 PIN**에서 숫자 6~12자리를 설정합니다.
2. 짧은 주소나 QR로 웹을 엽니다. 링크에 긴 접속 키를 붙이지 않습니다.
3. 지정한 PIN을 입력합니다. 앞의 0도 사용할 수 있습니다.

PIN은 키체인에 salt와 PBKDF2-SHA256 검증값으로 보호해 저장합니다.
잘못된 입력과 동시 요청에 횟수 제한을 적용합니다. PIN 변경·해제는 이전 로그인과
접속 키를 폐기하며, 기존 페이지의 미전송 입력은 직접 다시 연결할 때까지 보존합니다.
PIN을 설정하지 않은 연결의 기존 키·QR 방식은 유지합니다.
