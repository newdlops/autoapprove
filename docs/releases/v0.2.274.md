# 0.2.274 · 표시 투영 화면의 중복 감시 조회 감소

- 완료된 원본 관찰의 원문·커서·표시 투영을 함께 공유해, 별도 표시 화면에서도 감시의 중복 조회를 줄입니다.
- 같은 원본·변경 세대·관찰 시각과 원문을 대조하며 180ms 이내의 완료된 읽기만 사용합니다. 감지 처리와 실제 관찰 시각은 유지합니다.
- 일반 화면과 원문·표시 화면이 서로 다른 경우의 공유 횟수·시각·커서 보존을 회귀 검사합니다. 현재 권한·입력 우선권·원본 변경 검증도 유지합니다.
- 실제 키 입력부터 화면 반영까지의 지연은 별도 실측 대상입니다.
