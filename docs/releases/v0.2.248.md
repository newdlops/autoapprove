# AutoApprove 0.2.248

‘현재 로그인으로 세션 재연결’이 과거의 ‘직접 입력 연결 필요’ 오류 기록에 계속 막히는 경우를 수정했습니다. 이 오류는 키를 보내기 전의 실패이므로 새 사용자 요청에서 현재 대화와 Goal을 다시 확인해 연결을 준비합니다. 유사한 문구·응답 유실·부분 전송·이미 확인한 중단은 재전송하지 않습니다.

손쉬운 사용과 키 입력 권한이 이미 있는 Mac에서는 원래 창·탭·Codex 프로세스를 검증하는 키보드 경로로 Goal을 중단합니다. 불안정한 직접 입력 도우미의 가용성 캐시에 의존하지 않습니다. 권한이 없으면 기존 직접 입력 경로를 사용하며, 전송을 시작한 뒤 다른 방식으로 재시도하지 않습니다.

독립 실행 중인 Goal 두 개를 공통 관리형 서버 하나로 순차 편입하는 시험을 추가했습니다. 두 대화 ID와 Goal을 각각 유지하고, 서버 전환은 한 번, 각 Goal 재개는 한 번임을 검증합니다. 연결 단계와 보류 이유도 승인 기록에 남겨 추적할 수 있습니다.

검증은 소유 PTY와 실제 엔진·커널 신원 검사를 사용했습니다. 창 메타데이터와 키 게시 sink는 주입했으며, 다른 Mac의 실제 키 전달·사설 연결 기록을 직접 검증한 것은 아닙니다. [검증 기록](../../VALIDATION.md).
