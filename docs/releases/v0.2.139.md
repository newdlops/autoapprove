# 0.2.139 · PR #4의 확인 문구·셸 조회 경량화

[PR #4](https://github.com/newdlops/autoapprove/pull/4)를 포함합니다. 한 선택지의 거절·세션 허용·반복 허용·긍정 응답을 판별할 때 같은 Unicode 정리와 힌트 제거 결과를 공유합니다. 중첩된 힌트와 문장부호에서는 정리를 한 번 더 하는 의미가 달라질 수 있어, 기존에 필요했던 첫 번째·두 번째 정리 단계는 유지합니다. 서로 다른 질문 사이에 승인 결과를 캐시하지 않습니다.

셸 이름 조회에서는 보통의 경로에 매번 파일 URL을 만들지 않습니다. 빈 경로·점 경로·NUL이 포함된 경로는 기존 Foundation URL 처리를 유지합니다. 실행 세션의 식별과 복구 대상 확인은 바꾸지 않습니다.

0.2.138의 일반 질문 분석 경량화와 이전 PR #3도 포함합니다. 한 번 허용 우선·세션 한정 허용, Codex·Claude의 기존 모델 유지, 일반 작업 질문의 수동 응답과 시스템 변경 거절 규칙을 유지합니다. 새로운 타이머·서비스·관리자 권한이나 보안·VPN 설정 변경은 추가하지 않습니다.

macOS 14 이상 Apple Silicon용이며 빌드는 166입니다. 기존 발행자 인증서를 재사용합니다. 설치 방법은 [설치 안내](../../README.md#설치)를 참고하세요.

검증: Release 전체 검사 368/368, 기존 승인 문구 판정과의 18,906건 일치, 셸 경로 2,288건 비교를 통과했습니다. 최종 패키지의 자동 응답 12건·수동 질문 대기 12건, 웹·MCP·격리 PTY, 서명·리소스·DMG 무결성도 확인했습니다. 사용자 터미널에는 시험 입력을 보내지 않았습니다. 이번 배포에서 실제 휴대폰 조작이나 앱 전체 속도 비교를 새로 수행하지는 않았습니다.
