# AutoApprove 0.2.327 · 빌드 354

세션 그룹 창에서 여러 구성원을 그룹장으로 지정할 수 있습니다. 각 그룹장은 그룹장 직속 구성원에게 작업을 지시하고 질문에 답하며, 그룹 초기화와 탭 표시 변경을 요청할 수 있습니다. 완료 보고는 작업을 지시한 그룹장의 수신함에 한 번 전달됩니다. 구성원 한 명의 그룹장 역할을 해제하면 나머지 그룹장이 계속 관리합니다. 기존 단일 그룹장과 프로필에 저장된 그룹 구성도 이어집니다.

Codex 그룹의 세션 ID를 갱신할 때 원래 Terminal·iTerm2 탭의 현재 제목을 읽습니다. 해당 Codex 로그인 홈과 작업 폴더의 로컬 대화 기록에서 전체 이름이 하나만 일치하고, 로컬 서버에서 그 대화가 열려 있음을 확인하면 입력창을 건드리지 않고 ID를 저장합니다. 이름이 중복되거나 초기화 화면이 보이면 이름으로 ID를 확정하지 않습니다.

사용자 지정 제목 등으로 대화를 식별할 수 없고 Terminal에 이전 상태 카드가 남아 있으면, 빈 입력창에 `/pwd`를 보낸 뒤 `/status`를 조회합니다. 같은 카드가 다시 그려져 화면에 남은 카드 수가 늘지 않아도 작업 폴더 응답 뒤의 새 카드에서 ID를 읽을 수 있습니다. 입력 중인 초안이나 승인창이 있으면 조회 명령을 보류합니다.
