# 0.2.230 · 저장 창별 선택 복원

저장한 프로필에서 특정 Terminal 창의 세션만 골라 복원할 수 있습니다.

- 도구 필터 옆의 `모든 창`에서 저장된 창 번호를 선택합니다. Codex/Claude·레포·검색 조건과 함께 적용됩니다.
- 각 항목에 창·탭 번호를 표시하고 `창·탭` 정렬을 제공합니다. 표시 정렬을 바꿔도 실제 복원은 저장된 창·탭 순서를 따릅니다.
- 창 번호는 저장 시점의 번호입니다. 창 정보가 없는 이전 Terminal 기록과 iTerm2 기록은 호스트별 `창 정보 없음`으로 구분합니다.
- 선택한 창 밖의 체크 항목은 복원하지 않으며 버튼에 실제 대상 개수를 표시합니다.

선택 복원 검사 **35개**, 기존 창·탭 회귀 검사 **37개**가 통과했습니다. 합성 실행기를 연결한 실제 Mac 화면에서 특정 창만 복원, 창+Codex 교집합, 빈 결과와 창 정보 없음 분류를 확인했습니다. 세 크기의 밝은/어두운 렌더도 별도로 확인했습니다. 실제 사용자 Terminal을 실행하는 복원 시험은 수행하지 않았습니다.

검사 및 배포 결과는 [검증 기록](../../VALIDATION.md)에 남깁니다.

공개 파일 4개의 재다운로드 검증과 정식 설치를 완료했습니다. 실행 버전은 **0.2.230/257**이며 교체 전 원본 세션 **21/21개**가 보존됐습니다. 설치 앱에서도 기존 저장 프로필의 3개 창 분류를 확인했습니다.
