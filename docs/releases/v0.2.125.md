# AutoApprove 0.2.125

웹 터미널에서 같은 원문과 에이전트의 선택형 질문 탐지 결과를 재사용합니다. 질문이 없는 화면도 재분석하지 않으며, 저장된 답변 상태와 원본·권한·입력 검증은 매번 갱신합니다. 기존 프레임을 사용하므로 별도 화면 보관소는 추가하지 않습니다.

합성 178KB 화면을 128회 처리한 3회 중앙값에서 CPU 시간은 일반 출력 1.180→0.091초(92.3%), 선택형 질문 4.602→0.108초(97.7%)로 줄었습니다. 해당 반복 처리 경로의 결과이며 실제 휴대폰·VPN의 전체 연결 지연 감소율을 뜻하지 않습니다.

감시 화면 분석은 화면당 512KiB, 원문 합계 8MiB, 최대 32세션으로 제한해 큰 출력도 재사용합니다. TTY별 화면 검색을 한 번의 색인으로 처리하고, 백그라운드 자식 확인과 detached HEAD Git 정보 조회의 반복 작업을 줄입니다. HTTP/SSE 전송 시 응답 크기를 확인하면서 중복 JSON 직렬화를 제거했습니다.

오류 후 이어가기 검증에서도 긴 출력의 중복 정규화·행 분할과 전체 행 검색을 줄였습니다. 원본 입력란과 기존 전송 영수증 확인은 유지합니다.

Terminal 화면 내용은 기존처럼 각 TTY를 정확히 지정해 읽습니다. 새 서비스나 권한, 휴대폰 설치는 추가하지 않습니다.
