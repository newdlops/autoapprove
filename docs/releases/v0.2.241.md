# 0.2.241 · 데몬 자동 시작 설정과 기존 대화 연결

관리형 서버가 실행 중이어도 일반 `codex`의 `daemon_auto_start`가 꺼져 있으면 기존 내장 서버 세션은 그대로 남을 수 있습니다. AutoApprove가 선택한 홈의 유효 설정을 읽고 공식 `codex features enable daemon_auto_start`로 켠 뒤 다시 확인합니다. 이미 실행 중인 서버는 재시작하지 않으며, 다른 설정을 덮어쓰지 않습니다. 정책·권한·응답 확인 실패는 안내하고 반복 적용하지 않습니다.

기존 Terminal·iTerm의 독립 Codex 대화는 원본 프로세스·시작 시각·TTY·셸과 실제 열린 대화 기록을 확인한 뒤 순서대로 연결합니다. **작업·활성 Goal·질문·초안·하위 작업이 남아 있으면 유지하고 대기합니다.** 원본 대화를 특정할 수 없거나 해당 터미널의 연결이 꺼져 있으면 종료하지 않습니다. ChatGPT 내부 Codex는 대상이 아닙니다.

빈 입력 대기의 대상에만 `/exit`를 한 번 보내고, 원래 셸이 돌아온 것을 확인해 같은 홈·작업 폴더·대화 ID로 `--remote unix:// resume`를 실행합니다. 새 창·새 대화·`--last`·임의 이어가기 프롬프트는 사용하지 않습니다. 새 프로세스의 원본 셸·TTY·실제 서버 연결과 같은 대화의 로드를 확인한 뒤 완료로 표시하며 기존 자동 승인 선택을 유지합니다.

종료와 재실행은 전달 전에 기록합니다. 앱 재시작·응답 유실로 결과가 불명확하거나 확인 시간이 지나면 같은 입력을 자동 재전송하지 않고 확인 필요 상태로 둡니다. 계정 창에서 자동 시작 켜짐/꺼짐과 기존 세션 연결 진행·대기·보류를 구분합니다. 전체 일시정지·사람 입력·앱 종료 중에는 후속 터미널 입력을 보류합니다.

Apple Silicon·macOS 14 이상 대상입니다. 사용자 계정과 분리한 공식 CLI 설정 검증 및 앱 소유 합성 PTY의 같은 셸·대화 재실행을 검증합니다. 실제 사용자 Terminal을 강제로 이전하는 실험이나 다른 Mac 실기 완료로 표시하지 않습니다. 활성 작업을 중단해 즉시 옮기는 기능은 포함하지 않습니다.
