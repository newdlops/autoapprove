# 0.2.137 · Allow 승인 복구와 현재 모델 유지

Codex의 도구 허용 메뉴가 기능에 따라 두 개·세 개·네 개 항목으로 나타나는 경우를 지원합니다. 기존에 누락되던 `Allow / Allow for this session / Cancel`도 자동 처리합니다. 한 번 허용하는 항목을 우선 선택하고, 그 항목이 없으면 명시적인 `Allow for this session`을 사용합니다. 영구적인 `Always allow`를 대신 선택하지 않습니다.

[PR #3](https://github.com/newdlops/autoapprove/pull/3)의 Cocoa 화면 비교 최적화도 포함합니다. 화면 하단이 그대로이고 본문만 바뀌는 경우, 작은 UTF-16 버퍼로 비교해 문자별 변환 비용을 줄입니다. 버퍼 경계의 surrogate와 잘못된 UTF-16은 기존 UTF-8 투영 결과에 맞춰 처리하며, 화면 내용이나 터미널 연결 정책은 바꾸지 않습니다.

모델 선택 질문에서는 명확한 ‘기존 모델 유지’·‘Keep current model’ 또는 `(current)`·`[현재]` 표시가 있는 모델을 유지합니다. 질문이 현재 모델의 이름을 명시한 경우도 해당 항목을 찾습니다. ‘다른 모델로 바꿀까요?’에는 `No`, ‘현재 모델을 계속 사용할까요?’에는 `Yes`로 답합니다. 현재 모델이 두 번째 이후 항목이어도 같은 원본 터미널의 선택을 전달합니다. 추천 항목이나 첫 항목을 현재 모델로 추측하지 않으며, 현재 모델이 불명확하거나 여러 개로 표시된 경우에는 직접 답할 수 있게 둡니다.

Codex 대기 질문, Claude 질문 훅, 지원되는 원본 터미널의 번호형 단일 선택에 적용합니다. 전송 직전 원본 프로세스·TTY·현재 질문을 다시 확인하고, 일시정지·자동 승인 끄기·수동 입력·질문 변경 시 예약을 취소합니다. 전달되었거나 결과가 불명확한 모델 선택은 같은 메뉴의 이전 출력이 바뀌거나 앱이 재시작되어도 다시 보내지 않습니다. 일반 작업·환경 선택과 복수 선택은 계속 직접 답합니다. 시스템 변경 요청에는 기존 거절·안전한 대안 안내를 유지합니다.

Release 회귀 **367/367개**, 현재 모델 전용 **5/5개**, Allow 관련 **5/5개**가 통과했습니다. 합성 원본 입력 검사에는 두 CLI 종류, 현재 모델이 두 번째 항목인 경우, 전달 응답 유실·이전 출력 변경·앱 재시작, 일시정지·자동 승인 해제·수동 입력·질문 변경을 포함합니다. 실제 사용자 터미널과 실제 휴대폰에서 수행한 입력 검사는 아닙니다.

PR #3의 화면 비교 **157,074건**과, 하단을 유지하면서 본문만 갱신하는 합성 16세션의 상태·입력 없음·감사 기록 없음·갱신 범위 보존 검사도 통과했습니다. 이번 검사는 기존 버전과 앱 전체 성능을 비교한 측정은 아닙니다.

실제 패키지의 격리된 훅에서 허용·세션 허용·현재 모델 유지·모델 변경 거절 **12건**의 자동 응답과 일반·복수 선택·현재 표시가 없는 모델 질문 **12건**의 명시적 웹 답변 대기를 확인했습니다. 대기 중 일시정지·재시작, 응답 유실 복구와 중복 방지도 통과했습니다. 패키지의 버전·서명, loopback 웹·MCP·합성 PTY·포트 복구, DMG 내용·체크섬 검사도 통과했습니다.

macOS 14 이상 Apple Silicon용이며 빌드는 164입니다. 기존 발행자 인증서를 재사용합니다. 설치 방법은 [설치 안내](../../README.md#설치)를 참고하세요.
