# 0.2.271 · 큐에 쌓인 Codex 질문 표시 복구

- 로컬 대화 기록 파일을 열지 않는 Codex도 이미 연결한 원래 대화를 검증한 뒤 읽기 전용 질문 기록을 확인합니다. 같은 폴더의 다른 대화를 임의로 선택하지 않습니다.
- 미응답 질문은 이후 대화가 이어져도 ‘질문·메시지’에서 선택지와 답변 입력을 표시합니다. 접수된 답변은 기존 지난 질문 목록에 남습니다.
- Codex 앱에서 제출한 구조화된 답변은 정확한 질문 ID·항목 번호·문구로 대조해 이미 답한 질문이 다시 나타나지 않게 했습니다.
- 질문 조회 실패를 빈 목록과 구분해 표시하고 작성 중인 답변을 보존합니다. 답변 전에는 현재 프로세스·대화·질문을 다시 검증하고, 전송 결과가 불명확하면 재전송하지 않습니다.
