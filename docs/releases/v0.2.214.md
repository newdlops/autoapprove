# 0.2.214 · 두 번째 탭의 프로필 복원 확인

- **첫 두 탭:** 한 탭의 접근성 탭 막대·탭 객체가 두 탭이 될 때 교체되는 경우를 처리합니다. 이전 객체와 같아야 한다는 조건 대신 원래 TTY와 새 TTY를 각각 선택해 같은 새 탭 막대의 서로 다른 탭인지 확인합니다.
- **후속 탭:** 이미 여러 탭인 묶음에는 기존 탭 순서 보존 검사를 적용합니다. 같은 창 확인에 실패하면 명령을 보내지 않고, 결과가 불확실한 탭이나 명령은 반복 실행하지 않습니다.
- **저장 정보:** 기존 프로필의 탭 구성과 CLI·작업 폴더·설정 폴더·선택한 대화 정보로 복원합니다. 파일 형식과 프로필 화면은 유지합니다.

수정 전 코드에서 새 재현 검사가 사용자 화면과 같은 ‘새 탭의 묶음과 순서를 확인하지 못했습니다’로 실패했고, 수정 후 탭 관련 26개 검사를 통과했습니다. 전체 회귀는 593/594이며, 이전 버전과 같은 별도 루프백 주소 검사에서 `NWError 49`가 발생했습니다.

격리된 실제 AppKit 창으로 탭 선택·그룹·추가를 확인합니다. Terminal 실행·키 전달은 주입된 검사 어댑터이며 실제 사용자 Terminal 전체 복원 성공을 확인한 결과와는 구분합니다. 상세 검증·배포·설치 결과는 [검증 기록](../../VALIDATION.md)에 남깁니다.
