# AutoApprove 0.2.283 · 세션 프로필의 정확한 대화 저장·복원

- 앱 시작 직후 캐시된 제목이 오래되어도 실제 Terminal 탭의 전체 대화 이름으로 저장할 대화를 확인합니다.
- 명시적으로 연결한 대화는 서버에서 검증하고, 복원 전에도 실행 중인 대화를 식별하여 중복 실행을 막습니다. 같은 폴더의 최신 대화를 추측하지 않습니다.
- 대화 ID가 확인되지 않으면 저장 전에 대화를 선택해야 합니다. 새 CLI로 저장하려면 복원 방식을 직접 선택합니다. 기존 파일은 계속 읽을 수 있습니다.
- 프로필 목록과 저장 결과에 대화 이어가기와 새 CLI 실행을 구분합니다. 대화 확인 실패의 실제 원인을 표시합니다.
- 앱에 포함된 CLI보다 최신 서버가 이미 실행 중이면, 서버가 보고한 관리형 CLI의 소유자·파일 신원·버전·소켓을 다시 확인하고 같은 서버에 연결합니다. 실행 중인 서버를 교체하거나 자동 시작 설정을 변경하지 않습니다.
- CLI 실행 전 실패는 명령 미전달로 표시하여 정상적으로 재시도할 수 있습니다. 전달 결과가 불확실한 경우는 기존 중복 실행 방지를 유지합니다.

Debug 프로필 검사 16개, Release 프로필 검사 14개, 창·탭 검사 37개와 컨트롤러 선택 검사 35개를 통과했습니다. 실제 네이티브 저장·선택 복원·재시도 중복 방지를 조작했고, 700×480·860×640·1100×800 및 편집기 700×620의 밝음/어두움 렌더링을 확인했습니다.

실제 설치본에서 별도 빈 대화를 프로필 파일로 가져와 새 Codex로 재개했습니다. 저장한 UUID가 실행 인자·서버 응답과 일치하고 입력 대기 상태임을 확인했습니다. 원래 세 CLI 프로세스의 PID·시작 시각·TTY는 유지했습니다. Terminal 화면 접근은 조작 도구의 안전 정책으로 거절되어 화면 자체를 시각 검증했다고 주장하지 않습니다. 검증용 대화에 모델 작업은 보내지 않았습니다.
