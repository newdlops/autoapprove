# 0.2.162 · 빌드 189

여러 웹 요청이 같은 Mac 목록을 동시에 조회할 때 JSON을 반복 생성하는 비용을 줄였습니다. **모든 세션 초기화·연결된 Mac 모두 초기화**와 기존 세션별 초기화도 포함합니다.

진행 중이고 상태가 같은 요청들만 하나의 인코딩을 공유합니다. 첫 응답은 작업 스레드에서 본문과 관찰 시각을 완성해 그대로 전달하고, 합류한 요청에는 각자의 관찰 시각을 반영합니다. 마지막 소비자가 끝나면 결과를 해제하며 다음 조회를 위한 본문 캐시나 새 폴링은 추가하지 않았습니다.

Origin·대상 Mac 검사, 현재 상태를 확인하는 조건부 304와 원본 입력 보호는 유지합니다. 한 요청의 취소가 다른 요청을 취소하지 않고, 취소·서비스 재시작은 준비 작업이 끝나기를 기다리지 않고 HTTP 대기를 해제합니다. 늦게 돌아온 이전 상태가 현재 검증자를 덮지 않도록 다시 확인합니다.

정식 0.2.161과 같은 공개 HTTP fixture를 **8쌍씩 교대 실행한 새 80프로세스**에서 모든 사전 한도를 통과했습니다. 각 값은 8개 프로세스 결과의 중앙값입니다.

| 합성 작업량 | CPU 시간, 이전 → 수정 | 전체 처리 시간, 이전 → 수정 | 요청 지연 p95, 이전 → 수정 |
| --- | --- | --- | --- |
| 19세션, 단일 요청 128회 | 69.47 → 70.30ms | 69.84 → 69.96ms | 0.809 → 0.722ms |
| 19세션, 8개 동시·256회 | 115.62 → 37.58ms | 115.66 → 26.29ms | 3.678 → 1.170ms |
| 96세션, 8개 동시·128회 | 196.46 → 36.32ms | 201.95 → 27.92ms | 12.671 → 2.063ms |
| 변경 없는 304, 4,096회 | 319.51 → 327.91ms | 322.55 → 332.98ms | 0.653 → 0.697ms |
| 다른 Origin의 403, 4,096회 | 42.29 → 42.75ms | 39.67 → 40.49ms | 0.079 → 0.082ms |

동시 조회의 CPU는 약 **67.5%/81.5%** 줄었습니다. 별도로 측정한 메인 액터 콜백 대기 p95는 단일 **0.590→0.182ms**, 동시 **2.409→0.671ms**, 96세션 **11.613→0.664ms**였습니다. 이는 제어 콜백 탐침이며 실제 자동 승인 지연이 아닙니다. 단일 CPU는 약 1.2%, 304 CPU는 약 2.6% 늘었고 다섯 조건의 프로세스별 최대 RSS 변화는 약 −1.7~+1.7%였습니다.

실제 HTTP 파서·처리기에 합성 세션을 넣은 비교이며 수신 소켓·LAN·원본 Terminal·휴대폰·VPN의 전체 지연이나 설치 앱 전체 CPU 절감률을 측정한 것은 아닙니다. 전송 JSON 바이트 수는 같으며 이번 변경을 압축률 개선으로 주장하지 않습니다. 앞선 continuation 후보는 단일 CPU/시간과 403 시간 한도를 넘겨 제외했고 그 실패와 새 비교를 모두 보존했습니다. 한도를 변경하거나 이전 시간 표본을 재사용하지 않았습니다.

최종 Release 전체 **418/418 · 295.796초**, 관련 대시보드 **18/18**, 페이로드 **6/6**이 통과했습니다. 새 검사 10개는 정확한 JSON·관찰 시각·검증자, 오래된 상태, 취소·서비스 종료 즉시 해제, 8개 소비자 공유·취소 격리·재생성과 32회 취소 경합을 확인합니다. 기존 전체 초기화 회귀도 포함합니다. 서명 패키지 통합 검사 **3종**과 DMG 읽기 전용 마운트 검증이 통과했고, App/CLI의 코드 38개 section·runtime과 웹 13개 파일이 검사한 빌드/소스와 일치합니다. 기존 발행자 서명·요구식과 키체인 검색 목록을 유지했습니다. 상세 범위는 [검증 기록](https://github.com/newdlops/autoapprove/blob/v0.2.162/VALIDATION.md)에 있습니다.

원본 터미널에 시험 입력·초기화·캡처를 보내지 않았습니다. 시스템 자동 실행 등록·새 상주 서비스·관리자 상승·보안·권한·VPN 정책 변경도 없습니다. UI의 JS·CSS·레이아웃은 0.2.161과 같고 새 브라우저 시각 검사나 실물 휴대폰 검사는 수행하지 않았습니다.
