# AutoApprove 0.2.434

- Claude Code의 세션 평가와 피드백 초안에 건너뛰기 단축키가 표시되면, 연결된 원래 입력창을 다시 확인하고 `0`을 한 번 보냅니다. 세션의 자동 승인 설정을 꺼도 동작하며 전체 자동화 일시정지와 사용자 입력 우선권을 따릅니다.
- AutoApprove에서 Claude 탭을 프로필로 열거나 같은 대화로 재시작하면 Claude의 내장 설문 끄기 설정도 적용합니다.
- Claude Code와 Codex에서 승인창이 터미널 높이를 넘을 때, 제목이 잘려도 승인 메뉴 고유의 선택지와 하단 키 안내가 보이는 첫 화면에서 승인 대기를 표시합니다. 자동 승인에는 전체 요청 확인이 필요합니다.
