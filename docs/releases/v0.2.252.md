# AutoApprove 0.2.252

계정·로그인 창에서 이름을 붙인 로그인 그룹을 만들고 선택할 수 있습니다. 각 그룹은 별도 Codex 홈을 사용하며, 선택한 그룹의 현재 계정 확인과 브라우저 로그인을 기존 화면에서 진행합니다. 그룹은 앱을 다시 열어도 유지됩니다.

그룹 생성만으로 로그인하거나 서버를 시작하지 않습니다. 중복 이름과 손상되거나 교체된 그룹 홈은 오류로 표시하며 기존 자료를 초기화하지 않습니다. 로그인 중에는 그룹 생성과 선택을 잠급니다.

이번 기능은 별도 로그인 공간 준비 단계입니다. 기존 세션을 다른 그룹으로 옮기는 통합·분리와 실제 다른 계정·SSO 전환 검증은 계속 진행 중입니다.
