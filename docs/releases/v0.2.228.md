# 0.2.228 · 감긴 피드백 선택 문구와 초안 보호

피드백 카드의 `review`, `send`, `dismiss`가 줄 중간에서 감기면 빈 입력창을 대기로 오인하던 경계를 보완합니다. 작성 중인 초안이 카드 때문에 미확인으로 남는 경우도 함께 수정합니다.

- 고정된 `1/2/0` 선택 문구의 글자 사이 공백·줄바꿈을 허용해 카드가 활성화된 빈 입력창을 대기로 판정하지 않습니다.
- 입력창에 실제 초안이 있으면 입력 상태를 유지합니다. 최근 18개 비어 있지 않은 행의 확인 범위와 기존 명령·권한 요청 판정은 유지합니다.
- 24~80열 사이의 모든 폭과 24/40행, 일반 문자열·외부 NSString을 대상으로 카드·초안·일반 대기와 오래된 화면 경계를 회귀 검사합니다.

검사 및 배포 결과는 [검증 기록](../../VALIDATION.md)에 남깁니다. 실제 Terminal 수동 크기·스크롤 시험과 외부 Cloudflare TLS 경로의 미완료 검증은 별도로 유지합니다.

전체 Core **618/618**과 새 대상 검사가 통과했습니다. 동일한 57개 폭의 합성 셀 재검사에서 대기 오인은 **7개 → 0개**로 줄었습니다.
