# AutoApprove 0.2.313 · 빌드 340

Codex 그룹의 호출자를 MCP 호출별 대화 UUID로 먼저 식별합니다. 공유 MCP 프로세스가 다른 터미널로 관측되거나 화면의 세션 ID가 아직 확인되지 않아도, 호출의 대화 UUID와 계정 홈이 저장된 구성원과 일치하면 자기 그룹을 조회하고 수신함을 사용할 수 있습니다. 프로세스 일치가 이 대화 증거를 덮어쓰지 않습니다.

같은 대화를 다른 작업 폴더나 새 터미널에서 재개한 경우에도 대화 UUID와 계정 홈으로 연결을 찾고 실행 위치를 갱신합니다. 서로 다른 대화·계정 또는 중복된 실행 위치는 임의로 연결하지 않습니다. Claude의 기존 식별 경로는 유지합니다.

MCP 프로세스는 유효한 UTF-8 언어 환경을 보존하며, 환경이 없거나 C 로케일이면 macOS의 선호 언어를 사용합니다. LANG·LC_CTYPE·LC_ALL을 함께 맞춰 한국어 등 비 ASCII 문자를 처리하도록 합니다.

이번 버전에는 앞서 진행 중인 로그인 그룹 이동·복원 및 Goal 자동 복구의 미검증 변경을 포함하지 않습니다. 기존 공식 Codex 런타임과 지원 범위를 유지합니다.

검증: 격리된 stdio MCP와 임시 Unix 소켓에서 호출별 대화 전환, 실행 프로세스 정보 무시, 위조 인자 제거, 상충하는 대화 ID 거절을 확인했습니다. 공식 Codex 0.169.0 서버·임시 계정 홈·가짜 로컬 모델에서도 실제 MCP 메타데이터의 대화 UUID와 계정 홈 식별이 통과했습니다. C 로케일로 시작한 프로세스와 자식 프로세스에 macOS 선호 언어의 UTF-8 로케일이 적용되는 것도 확인했습니다. 사용자 터미널 입력이나 실제 그룹 메시지 전송은 검사에 사용하지 않았습니다.
