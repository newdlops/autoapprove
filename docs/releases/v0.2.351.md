# AutoApprove 0.2.351 · 빌드 378

- 대화 그래프의 구성원 목록 위에 "전체 다시 정하기" 버튼을, 구성원 상세에 "이 구성원 이름 다시 정하기" 버튼을 두었습니다. 이름이 이미 정해진 구성원도 언제든 다시 요청할 수 있습니다. 이전에는 임시 이름으로 보이는 구성원만 요청할 수 있었습니다.
- 요청은 그룹장에게 보내고, 그룹장이 없으면 각 구성원에게 보냅니다. 요청을 받은 그룹장이나 구성원은 구성원마다 지금 하는 일을 확인해 이름과 함께 맡은 일을 한 줄 역할로 정합니다.
- `set_group_member_title` 에 선택 항목 `role`(한 줄, 1~120자)을 더했습니다. 설정한 역할은 그룹 구성원 정보에 저장되어 `get_session_groups` 와 `get_group_status` 결과에 포함되고, 대화 그래프의 구성원 상세에서는 이름 아래에 보입니다.
- 구성원을 추가할 때 자동으로 보내는 요청은 지금처럼 구성원마다 한 번만 보냅니다.
