# AutoApprove 0.2.203 · build 230

Mac 기본 Terminal의 창·탭 구성을 세션 프로필에 함께 저장합니다. 한 창에 있던 여러 대화가 복원 때 각각 별도 창으로 나뉘던 동작을 바꿨습니다.

- **세션 프로필(⌘⇧P) → 새 프로필**에서 현재 Terminal의 창 묶음·탭 순서·선택 탭·탭별 Terminal 설정 프로필 이름과 사용자 지정 제목을 저장합니다. 프로필 화면과 저장 화면에서 창/탭 위치를 확인할 수 있습니다.
- 복원할 때 같은 창의 대화는 탭으로 모으고, 다른 창의 대화는 별도 창으로 엽니다. 새로 여는 그룹의 탭 순서와 선택 탭을 반영합니다. 이미 실행 중인 대화는 이동하지 않고 해당 창에 누락 탭을 추가합니다.
- 창 정보가 없는 이전 프로필도 읽을 수 있습니다. 해당 프로필의 Terminal 세션은 한 창의 탭으로 모아 엽니다. **프로필 관리 → 현재 창으로 갱신**하면 현재 구성을 새로 저장합니다.
- 같은 창에 새 탭을 만드는 데는 AutoApprove의 **손쉬운 사용 권한**이 필요합니다. 대상 Terminal 프로세스와 선택한 창을 재확인하고 새 탭의 TTY를 확인한 뒤에만 대화 명령을 전달합니다. 탭 생성 실패·결과 미확인 시 후속 탭을 멈추며 개별 창으로 우회하지 않습니다.
- 저장된 Terminal 설정 프로필이 해당 Mac에 없으면 안내 후 해당 그룹을 중단합니다. 이 기능은 설정 프로필 이름을 참조하며 Terminal 전체 설정이나 사용자 명령을 내보내지 않습니다. 대화 기록은 복원할 Mac에 남아 있어야 합니다.
- 새 파일 형식은 이전 앱에서 열 수 없도록 버전을 구분해 탭 구성이 조용히 무시되지 않게 했습니다. 기존 iTerm2 복원 방식은 유지합니다.

자동 검사·네이티브 화면 확인·실제 Terminal UI 검증 제한은 [검증 기록](../../VALIDATION.md)에 있습니다.
