# 0.2.279 · 자동승인 보류 원인 안내

자동 승인 스위치가 켜져 있어도 이전 로그인 전환이 확인 필요 상태로 남아 있으면 입력이 보류될 수 있습니다. 이제 세션 상세 맨 위에서 보류 사유와 계정·로그인 진입점을 확인할 수 있습니다.

- 실제 입력 차단과 같은 조건으로 안내합니다. 확인된 독립 서버의 세션에는 다른 그룹의 보류를 표시하지 않습니다.
- 서버 연결을 확인하지 못한 세션에 적용된 보류도 안내합니다.
- 보류 중에는 서브에이전트 상태만 읽고, 승인 요청 감시 중이라는 정상 문구 대신 보류 이유를 표시합니다.
- 기존 계정 창에서 남은 전환을 중지하면 보류 안내가 해제됩니다. 기존 작업을 임의로 재개하거나 서버를 다시 시작하지 않습니다.

검증: DEBUG 빌드, 서버별 보류·복원·취소 후 실제 주입 승인 transport 회복 검사, 서브에이전트 소켓 통합 검사. 실제 SwiftUI 합성 화면 600×660pt의 밝음/어두움에서 줄바꿈과 버튼 배치를 확인하고, 안내 버튼 콜백 및 전환 취소 후 안내 해제를 확인했습니다. 실제 실행 환경에서도 남은 전환을 취소한 뒤 서버 승인 확인 기록이 다시 발생했습니다.

이번 변경은 보류 조건을 완화하지 않습니다. 로그인 그룹 간 기존 대화 이동, 세션별 app-server 선택·변경, 자식 Goal 일시정지·재개는 아직 구현 중입니다.
