# AutoApprove 0.2.249

웹관리자의 각 Mac에 **진단** 버튼을 추가했습니다. 해당 Mac의 Codex 서버·실제 세션 연결 증거·권한·재연결 단계를 조회하고, 종료된 원본의 과거 기록을 현재 문제와 구분합니다. 다른 Mac의 상태를 터미널 명령어로 복사해 전달할 필요가 줄어듭니다.

**Codex 진단 시작**을 누르면 대상 Mac에서 별도 진단용 Codex가 수집된 상태를 분석합니다. 기존 대화와 Goal은 유지합니다. 진단용 로그인 홈을 선택하고 질문을 덧붙일 수 있으며, 진행 상태·취소·근거와 권고 사항·JSON 내보내기를 제공합니다. 대상 Mac에도 이 버전 이상과 로그인된 Codex가 필요합니다.

진단 자료는 운영 상태의 허용된 항목으로 제한하고 인증 정보와 대화·Goal 본문을 포함하지 않습니다. 진단용 Codex는 도구를 비활성화한 읽기 전용 별도 프로세스로 실행하며, 진단 요청이 세션 복구나 Goal 중단을 실행하지 않습니다. 자동 복구는 이번 기능에 포함하지 않습니다.

재연결 기록의 표시도 보완했습니다. 종료된 원본의 오래된 보류 문구는 현재 오류로 남기지 않고, 다른 로그인 홈의 실제 보류와 진행 중인 연결 상태는 유지합니다.
