# 0.2.234 · Codex 로그인 반영 멈춤 복구와 세션 계정 표시

이미 브라우저 로그인을 마쳤는데 기존 Codex가 새 인증을 사용하지 못하면, 세션을 선택하고 **현재 로그인으로 재연결**을 누르세요. 다시 로그인하거나 기기 코드를 설정하지 않고 저장된 인증으로 공통 서버를 전환합니다. 연결 설정의 Codex 영역에서도 **현재 로그인으로 세션 재연결**을 사용할 수 있습니다.

네이티브 로그인 완료마다 고유 기록을 저장해, 같은 계정으로 다시 로그인해도 열린 세션에 한 번 반영합니다. 기존 계정 ID와 같다는 이유로 새 로그인을 무시하지 않습니다. 작업·Goal·Codex 백그라운드 작업을 순차 중단하고 대기를 확인한 뒤 공식 서버 재시작을 한 번 요청합니다. 창·대화 재연결을 확인하고 AutoApprove가 새 프롬프트를 제출하지 않습니다. 사용자의 대기 메시지는 보존합니다.

공식 Codex의 기본 정상 종료 유예는 60초인데 기존 래퍼는 30초 만에 재시작 명령을 끊었습니다. 공식 유예·종료·준비 확인 시간까지 기다리도록 고쳤고 재연결 확인 시간도 따로 둡니다. 정상 종료된 오류 대화는 종료 차례와 상태를 재확인해 복구할 수 있습니다. 기록 조회를 지원하지 않는 공식 임시 제목 생성 작업도 일반 대화와 구분합니다. 그 외 불명확한 대화·중복 명령·새 작업 경합은 계속 보류합니다. 이미 완료한 전환은 나중의 읽기 오류 때문에 다시 전체 세션을 잠그지 않습니다.

Codex 세션 상세에 **연결 서버 계정·플랜·공유 세션 수**를 표시합니다. 현재 연결된 서버의 공식 응답을 사용하며 인증 파일이나 최근 로그인에서 계정을 추정하지 않습니다. 별도 홈·서버의 단일 세션은 **이 세션 계정 로그인**, 공통 서버는 **공유 계정 로그인 (N개 세션)**으로 구분합니다. 현재 공통 서버의 세션 하나만 다른 계정으로 바꾸려면 별도 인증 홈·서버로 옮겨야 하며, 이 릴리스가 기존 세션을 자동으로 분리하지는 않습니다.

선택한 세션·계정·공유 범위를 로그인 직전에 다시 확인합니다. 설정 창을 닫아도 엔진에서 전환을 이어가며 결과가 불명확한 중단·재시작은 자동 재전송하지 않습니다. [검증 기록](../../VALIDATION.md).

로그인 중에는 자동 전환을 기다리고, 완료 콜백이 늦게 도착해도 같은 로그인을 두 번 적용하지 않습니다. 이후 수동 재연결은 새 요청으로 처리합니다. 심볼릭 링크로 지정한 Codex 홈도 같은 서버로 인식합니다. 전환 전에 이미 오류로 끝난 차례도 앱 재실행 뒤까지 대기하며, 사용자가 새 차례를 시작하면 기존 자동 복구 설정을 다시 적용합니다.
