# AutoApprove 0.2.206 · build 233

세션 프로필의 **대화 ID를 선택 사항**으로 바꿨습니다. 작업 폴더와 CLI만으로 저장하고 다시 열 수 있습니다.

- **대화 ID가 비어 있으면:** 저장한 폴더에서 `codex` 또는 `claude`를 새로 실행합니다. 빈 ID 때문에 저장 경고가 뜨거나 저장 버튼이 비활성화되지 않습니다.
- **대화 ID를 입력하면:** 해당 UUID로 기존 Codex·Claude Code 대화를 이어갑니다. 자동으로 확인된 ID도 지워서 새 CLI 실행으로 바꿀 수 있습니다. 대화 선택 목록의 **새 CLI 실행**도 같은 동작입니다.
- 저장 목록에서 ID가 없는 항목은 **새 CLI 실행**으로 표시합니다. 같은 폴더의 여러 항목을 독립적으로 저장하며, 기존 Terminal 창·탭 묶음과 순서를 유지합니다.
- 앱 실행 중 같은 저장 항목의 복원 요청을 반복하면 확인된 실행 기록으로 중복을 막습니다. ID 없는 항목은 새 CLI 실행을 뜻하므로, 앱을 다시 시작한 뒤 이미 열려 있는 다른 CLI를 자동으로 같은 대화로 연결하지는 않습니다.
- 폴더 경로·CLI 종류·입력된 잘못된 UUID의 검증은 유지합니다. 대화 ID가 없는 프로필은 **0.2.206 이상** 앱에서 열어주세요. 기존 대화 이어하기 프로필도 계속 사용할 수 있습니다.

선택 탭이 없는 Terminal 창의 프로필 저장 오류 수정도 포함합니다. 검사·배포·설치와 실제 Terminal 접근 제한은 [검증 기록](../../VALIDATION.md)에 구분해 기록합니다.
