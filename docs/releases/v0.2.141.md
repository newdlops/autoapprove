# 0.2.141 · PR #5 질문 대기열 갱신 경량화

머지된 [PR #5](https://github.com/newdlops/autoapprove/pull/5)를 반영했습니다. Mac 관리 창에서 질문이 그대로인 동안 세션 제목이나 활동 기록만 바뀌면 질문 편집기의 불필요한 재계산을 줄입니다. 작성 중인 답변과 체크박스 선택을 유지하며, 질문·응답 상태·오류·최초 조회·세션 식별·터미널 연결 상태가 바뀌면 화면을 갱신합니다. 버튼은 최신 동작을 사용하고 답변 전송 오류도 전달합니다.

기존 화면 구성과 승인 범위는 유지합니다. 일반 선택 질문은 직접 답하며, 명시적인 Allow·세션 한정 허용과 현재 모델 유지, 시스템 변경 거절·안전한 대안 안내 규칙을 포함합니다. 별도로 검토 중인 Cocoa 행 준비 최적화는 이번 버전에 포함하지 않았습니다.

macOS 14 이상 Apple Silicon용이며 빌드는 168입니다. 기존 발행자 인증서를 재사용합니다. 새 서비스·관리자 권한이나 보안·VPN 설정 변경은 추가하지 않습니다. 설치 방법은 [설치 안내](../../README.md#설치)를 참고하세요.

최종 검증: Release 전체 **368/368**, 질문 표시 갱신 조건 10종·최신 버튼 동작 5종·비동기 답변 오류 전달 검사를 통과했습니다. 서명된 패키지의 자동 응답·일반 질문 수동 응답 대기·일시정지·재시작·중복 방지와 웹·MCP·격리 PTY·입력 구성요소 검사도 통과했습니다. App/CLI 각각 38개 코드 section과 웹 리소스 13개의 최종 빌드 일치, 기존 발행자 서명과 DMG 무결성을 확인했습니다.

합성 세션의 실제 Mac 관리 창에서 질문 최초 조회와 새 질문 표시까지 확인했습니다. 이후 UI 검증 도구의 키 입력 호출이 약 20분간 지연돼 이번 설치본의 초안 유지·오류 복구·작은 창 시각 검사는 완료하지 못했습니다. 이 항목을 시각 검증 통과로 주장하지 않습니다. 사용자 터미널에 시험 답변을 보내지 않았으며 실물 휴대폰 검사는 수행하지 않았습니다. PR 작성자의 성능 수치는 해당 합성 작업의 결과이며 이번 설치본 전체의 속도 개선율로 사용하지 않습니다.
