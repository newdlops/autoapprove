# 0.2.269 · Terminal 입력 검증 최적화

- 실시간 Terminal 입력의 HTTP 단계에서 원본 CLI 하나만 새로 조회합니다. 네이티브 입력은 원본 CLI부터 Terminal까지의 부모 연결을 제한된 범위에서 두 번 대조합니다.
- 프로세스 정보 변환에 필요한 준비를 묶어서 처리합니다. 입력마다 관련 없는 프로세스의 경로·시작 시각을 반복해서 읽지 않습니다.
- 원본 CLI를 실행한 Terminal의 정확한 PID와 시작 시각으로 창 조회·활성화·탭 선택을 수행합니다. 각 네이티브 요청 전후의 신원, 입력 직전의 TTY·선택 탭·포커스·전경 작업·권한 검증은 유지합니다.
- 수신 Mac의 네이티브 입력 전체 처리 시간(`inputDelivery`)을 따로 계측합니다. 50ms 이하가 목표이며, 실제 입력에서 달성 여부를 확인해야 합니다.
