# 0.2.164 · 빌드 191

로컬 주소 상태를 판정할 때 모든 줄·필드를 배열로 만드는 작업을 없앴습니다. ASCII 행은 바이트 범위로 이름과 주소를 비교하고, 한글 등 비ASCII 행은 기존 글자 판정을 유지합니다. 외부 Cocoa 문자열은 최대 8KiB의 UTF-16 블록으로 읽으며 전체 UTF-8 복사나 결과 캐시를 만들지 않습니다.

정식 0.2.163 대비 새 프로세스 **128개 · 8조건 · 각 8쌍**에서 사전에 고정한 CPU·wall·메모리 기준을 모두 통과했습니다. CPU·wall은 8회의 중앙값, 최대 RSS는 8회의 최대값입니다.

실제 정식 Core와 후보 Core의 같은 합성 문자열 파서를 비교했습니다. CPU·wall은 입력 생성 이후의 파싱 구간이며 최대 RSS에는 프로세스와 입력 생성이 포함됩니다. 빈 문자열은 2,048회, 72바이트는 1,024회, 나머지는 1회 합계입니다. 앱 전체·실제 파일 읽기·휴대폰 연결 지연의 개선율은 아닙니다.

기존 줄바꿈 7종, 글자 단위 공백·주석, 대소문자와 한 개의 끝 점, 정확한 loopback 주소와 뒤늦은 충돌을 유지합니다. 파일 크기·읽기 예산과 설정·백업·시스템 쓰기 경로는 변경하지 않았습니다. 세션별·모든 세션·연결된 Mac 전체 자동화 초기화도 포함합니다.
