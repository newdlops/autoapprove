# AutoApprove 0.2.246

계정·로그인의 ‘현재 로그인으로 세션 재연결’과 AutoApprove 브라우저 로그인 완료 후, 아직 관리형 서버에 연결되지 않은 활성 Goal도 먼저 일시정지합니다. 원본 작업이 실제로 멈추고 빈 입력창으로 돌아온 것을 확인한 뒤 같은 창·대화의 서버 연결을 진행합니다. Goal을 삭제하거나 로컬 DB를 수정하지 않습니다.

연결 과정에서 중단한 Goal은 새 계정·서버·기존 대화 연결을 확인한 뒤 한 번 재개합니다. 원래 일시정지된 Goal, 바뀐 목표·실행 차례, 질문·초안은 유지합니다. 실제 Goal 푸터와 기존 셸을 사용하는 세션도 처리하며, 셸이 없는 세션은 같은 창의 복구 탭을 먼저 준비합니다.

재연결을 취소하거나 로그인 관리자를 교체하면 이전 요청이 나중에 원본 세션을 자동 종료하지 못하도록 보류합니다. 취소 전에 종료를 요청하지 않았고 같은 Goal의 일시정지가 확인된 경우에는 새 재연결 요청으로 이어갈 수 있습니다. 일부 기존 세션 연결이 실패하면 다른 관리형 창이 있더라도 계정 전환을 먼저 진행하지 않습니다. 브라우저 로그인 뒤 연결 실패 보류는 앱 재시작 후에도 유지됩니다.

Vim Normal·Replace 모드에서는 재연결 입력을 보류해 편집 중인 내용을 유지합니다.

실제 다른 Mac의 네이티브 탭·Esc 전달은 직접 검증하지 못했습니다. [검증 기록](../../VALIDATION.md).
