# AutoApprove 0.2.296 · 세션 프로필 부분 복원

- 한 항목의 복원 실패로 같은 창의 나머지 항목까지 막히던 동작을 수정했습니다. 후속 항목은 새 창에서 계속 복원합니다.
- 같은 창에 새 탭을 연결하지 못해도 대화 명령을 보내지 않았음이 확인되면 새 창으로 복원합니다. 이 경우 원래 창·탭 배치와 다를 수 있고 빈 탭이 남을 수 있습니다.
- 명령 전달 결과가 불확실한 항목은 중복 실행하지 않습니다. 명령을 보내지 못한 항목만 다시 시도할 수 있습니다.
- Terminal 자동화 오류에 실패 단계를 표시하고, 명령 전달 전·후를 구분해 재시도 가능 여부를 유지합니다.

검증: 중간 실패 후 후속 항목 복원·재시도 중복 방지, 원본 실행 스크립트와 명령 전달 전후 오류 구분의 집중 검사 2/2 통과. 실제 사용자 Terminal의 `execution error: Error: Error`는 직접 재현하지 않았으며, 이번 변경은 실패 격리·안전한 새 창 대체·오류 단계 표시에 해당합니다. 기존 Codex 실행 파일이나 서버는 변경하지 않습니다.
