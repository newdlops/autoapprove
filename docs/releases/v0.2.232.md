# 0.2.232 · 앱 안에서 Codex 로그인과 빈 대화 검사 수정

**연결 설정 → Codex → Codex 로그인 시작**에서 공식 기기 인증을 시작합니다. 여러 Codex 홈이 연결되어 있으면 대상을 선택하고, 인증 코드를 복사해 **공식 인증 페이지 열기**에서 사용할 계정으로 로그인해주세요. 시작·브라우저 대기·완료 확인·성공·실패·취소 상태를 같은 화면에서 확인합니다. 인증이 끝나면 코드와 링크를 지웁니다.

기존 **계정 변경 시 같은 대화로 자동 전환**을 켜 두면 로그인이 끝난 뒤 저장된 계정 변경을 확인하고 작업 순차 중단 → 공통 서버 전환 → 기존 대화 연결로 이어집니다. 기본은 꺼짐이며 로그인 버튼이 자동으로 켜지는 않습니다. 인증 코드가 만료되거나 기기 인증이 계정에서 허용되지 않으면 다시 시도하거나 계정의 인증 허용 설정을 확인해주세요.

첫 메시지를 보내기 전의 빈 Codex 창에 실행 차례 목록을 요청하면 공식 서버가 `-32600`으로 거절했습니다. 해당 대화 ID의 정확한 공식 오류만 처리하고 대기 상태를 다시 확인합니다. 대기 입력·백그라운드 작업·활성 Goal 검사는 그대로 수행하며, 다른 오류나 검사 중 시작된 작업은 전환을 막습니다. 다른 제어 오류는 실패한 요청 이름도 표시합니다.

창의 원래 대화 ID를 확인할 수 없으면 작업을 중단하거나 서버를 재시작하기 전에 이유를 표시합니다. 빈 대화 창을 닫거나 대화 기록의 연결을 확인한 뒤 **현재 로그인 확인**을 눌러주세요. 연결을 입증하지 못한 채 전환한 뒤 확인 필요 상태로 남기는 것을 피합니다.

로그인용 비공개 터미널은 세션 목록·출력·기록에 넣지 않습니다. Mac과 웹의 로그인 동시 실행을 막으며 원격 사용자는 Mac에서 시작한 인증 코드를 조회할 수 없습니다. 비밀번호나 기존 자격 증명을 AutoApprove가 읽거나 복사하지 않습니다.

검증과 공개 배포·설치 결과는 [검증 기록](../../VALIDATION.md)에 남깁니다.
