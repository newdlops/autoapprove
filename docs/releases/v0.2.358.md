# AutoApprove 0.2.358 · 빌드 385

실행 중인 Antigravity CLI 터미널을 세션 목록에 표시합니다. 연결 설정의 **Antigravity (agy) → agy 훅 설치** 또는 아래 명령으로 사용자 훅을 등록하면 대화 UUID와 작업·대기 상태를 그룹에서 확인할 수 있습니다. 이미 실행 중인 세션에서 이벤트가 오지 않으면 같은 대화를 다시 여세요.

```sh
/Applications/AutoApprove.app/Contents/MacOS/autoapprove install-agy
```

`autoapprove doctor`의 `agyHookInstalled`가 등록 여부를 표시합니다. `remove-agy`는 관리 중인 훅만 제거합니다. 훅에 연결할 수 없는 도구 요청은 agy에서 확인합니다.
