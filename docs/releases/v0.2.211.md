# AutoApprove 0.2.211 · build 238

손쉬운 사용에서 AutoApprove를 이미 허용했는데 세션 프로필에서 같은 허용 안내를 반복하는 문제를 보완합니다.

- 프로필 수집은 사전 AX 신뢰 값 하나로 차단하지 않고 정확한 Terminal 프로세스에 보낸 실제 접근성 조회의 성공/실패로 판단합니다. macOS의 권한 검사는 각 조회·조작에서 그대로 적용됩니다.
- Terminal이 실행 중이 아닌 경우, macOS가 실제로 접근을 거부한 경우, 창 목록을 읽지 못하거나 초점이 바뀐 경우를 구분합니다. 실제 권한 거부 때는 이미 허용한 사용자가 앱을 완전히 종료하고 다시 열어 확인할 수 있도록 안내합니다.
- 새 탭 키 전달은 현재 전달 허용 상태와 실제 AX 초점·TTY·창·프로세스를 확인한 뒤 수행합니다. 실제 AX 거부나 권한 철회·원본/초점 변경에는 전달하지 않으며 불확실한 키나 CLI 명령을 반복하지 않습니다.
- 권한 토글·TCC 초기화·추가 OS 권한 요청을 자동으로 수행하지 않습니다. 기존 프로필 화면과 저장 파일 형식을 유지합니다.

검사·배포·정식 응용 프로그램 경로의 설치 결과는 [검증 기록](../../VALIDATION.md)에 남깁니다. 실제 사용자 Terminal 직접 접근은 도구 정책으로 제한되므로 주입된 AX 응답 검사와 격리 AppKit 검증을 구분합니다.
