# AutoApprove 0.2.330 · 빌드 357

Claude에서 직접 `/clear`를 실행해도 같은 프로세스에 등록된 새 대화 UUID가 확인되면 원래 그룹 구성원에 연결합니다. 그룹장과 하위 구성원 관계, 수신함은 기존 구성원 ID에 연결됩니다. 같은 대화가 다른 실행 세션 또는 그룹 구성원과 충돌하면 연결 갱신을 보류합니다.

새 그룹 메시지나 수신 확인이 들어오면 알림 처리를 깨웁니다. Claude의 응답 종료나 입력 대기 이벤트를 받으면 해당 구성원에게 아직 입력되지 않은 알림을 다시 시도합니다. 작성 중인 입력과 승인 화면을 보호하며, 확인되지 않은 제출은 기존 재알림 시각을 따릅니다.
