# AutoApprove 0.2.352 · 빌드 379

- 대화 그래프의 "전체 다시 정하기"와 "이 구성원 이름 다시 정하기" 버튼으로 보낸 요청을 그룹장(그룹장이 없으면 각 구성원)의 입력창에 사용자의 요청으로 입력합니다. 요청 첫머리에는 어느 버튼을 눌러 보낸 요청인지 적습니다.
- 이전에는 이 요청을 "AutoApprove 그룹 전달" 알림으로 보냈습니다. 그래서 그룹장은 다른 프로그램이 사용자의 요청이라고 전한 말로 보고, 사용자에게 확인할 수 없다며 처리하지 않았습니다.
- 요청에 구성원 목록을 넣지 않고 `get_group_status` 로 구성원 ID와 지금 이름, 역할을 확인하게 해서 요청이 짧아졌습니다.
- AutoApprove 는 요청 끝에 붙인 요청 ID로 그룹장 대화에 요청이 들어갔는지 확인하고, 들어간 것을 확인한 요청은 다시 입력하지 않습니다.
- 구성원을 추가할 때 자동으로 보내는 요청은 지금처럼 AutoApprove 알림으로 보냅니다.
