# 0.2.136 · 반복 알림 요약 계산 경량화

질문·승인 알림을 갱신할 때 이미 요청 ID가 있고 기존 질문 제목과의 중복 비교가 필요 없는 경우, 긴 요약문을 반복해서 Unicode 정규화하고 공백으로 분리하는 계산을 생략합니다. 요청 ID가 없으면 기존 정규화된 키를 만들며, 입력 질문과 대기 질문의 중복 비교도 그대로 수행합니다. 건수·존재 여부 조회는 사용하지 않는 후보 키를 만들기 위해 요약을 정규화하지 않습니다.

0.2.135 원본 소스와 알림 키·본문의 UTF-8 바이트, 원본 세션 ID, 종류, 건수, 주의 필요 여부를 대조한 합성 상태 **25,216개**가 일치했습니다. 분해형·조합형 문자, 여러 공백, 빈 요청 ID와 제목, 전송·예약 질문, 일시정지, 메인·자식 세션, 종료·오류·시스템 변경 경고를 포함합니다. 원래 요약 표시와 알림의 읽음·중복 억제 규칙을 유지합니다.

실제 Release Core에 같은 합성 Cocoa 화면 **16개·500회**를 넣고 이전/수정 실행 파일을 **3쌍 교대** 측정했습니다. 출력 변경 CPU 중앙값은 **5.310730→4.721268초**, 경과 시간은 **5.615879→4.918700초**였습니다. 변경 없는 화면 CPU는 **0.394311→0.402627초**로 비슷한 수준입니다. 네 가지 세션 상태 각 4개, 변경 없는 화면의 상태 발행 0회와 변경 화면 500회를 유지했습니다. 이번 합성 처리 경로의 측정이며 설치 앱 전체 CPU·메모리나 실제 휴대폰·VPN 지연의 개선율은 아닙니다.

Claude의 일반 선택·복수 선택 질문은 웹에서 직접 답할 때까지 기다립니다. 명확한 Yes/No·예/아니오·응·Allow 확인만 자동 처리하며, 실제 시스템 변경 요청의 거절·안전한 대안 안내도 유지합니다.

최종 Release 회귀 **362/362개**가 통과했습니다. 작업 디렉터리 검사는 macOS의 `/tmp`·`/private/tmp` 별칭을 같은 디렉터리의 파일 식별자로 확인하도록 고쳤습니다. 실제 패키지의 격리된 훅에서 일반·복수 선택 **8개**의 명시적 웹 응답 대기, 승인·일시정지 중 재시작·응답 유실 복구·중복 전송 방지를 확인했습니다. 패키지의 서명·버전·코드·웹 리소스 일치와 loopback 웹·MCP·합성 PTY·포트/재시작, DMG 읽기 전용 마운트 검사도 통과했습니다. 실제 사용자 터미널 입력과 휴대폰 검사는 수행하지 않았습니다.

macOS 14 이상 Apple Silicon용이며 빌드는 163입니다. 기존 발행자 인증서를 재사용합니다. 설치 방법은 [설치 안내](../../README.md#설치)를 참고하세요.
