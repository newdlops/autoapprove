# AutoApprove 0.2.209 · build 236

**0.2.210에 통합:** 이 후보의 개선은 [0.2.210](v0.2.210.md)에 포함됩니다. 사용자가 기존 프로젝트 키체인의 서명 중 임시 등록과 원상 복원을 허용한 뒤 같은 게시자로 서명했습니다. 초기 배포 제한과 각 검증 범위는 [검증 기록](../../VALIDATION.md)에 남깁니다.

웹 관리자의 설정 저장·연결 복구를 보강하고 **Codex Goal 재개·취소**를 추가했습니다. 기존 세션과 터미널 초안은 유지합니다.

- **저장과 연결:** 기존 목록 응답을 기다리는 중에 설정을 변경해도 새 조회가 끝날 때까지 저장 상태를 유지합니다. 늦게 도착한 이전 응답은 적용하지 않습니다. 일반 갱신에도 선택 Mac의 조회 우선순위를 유지해, 원격 정책 저장 뒤 불필요하게 ‘갱신 중’으로 바뀌면서 키보드 포커스를 잃는 문제를 수정했습니다. 연결이 끊기면 OS 정책과 Goal 조작을 잠그고 같은 세션을 다시 확인합니다.
- **OS 권한 정책:** 다른 관리자 화면이나 Mac 앱에서 바꾼 정책을 오래된 체크박스 값으로 덮어쓰지 않습니다. 충돌하면 최신 정책과 재선택 안내를 표시합니다. 저장 중인 값은 해당 세션에만 표시하고, 펼친 요청 내용과 키보드 포커스를 보존합니다. 기존 권한 범위와 직접 확인 기본값은 유지합니다.
- **Goal 확인:** Codex 세션 상세에서 목표·상태·사용량을 확인합니다. 원래 대화를 자동으로 확인하지 못하는 실행 방식은 **대화 선택**에서 같은 폴더의 실행 중인 대화를 명시적으로 고릅니다. 선택한 세션만 주기적으로 읽으며 숨겨진 페이지에서는 반복 조회를 멈춥니다.
- **Goal 재개:** 일시정지·진행 막힘·사용량 제한 상태의 원래 목표에 재개를 요청합니다. 예산 제한은 원래 Codex에서 조정해야 합니다. 목표나 원래 CLI가 바뀌면 변경을 거절하고 다시 확인합니다.
- **Goal 취소:** `/goal clear`에 해당하는 목표 해제입니다. 대화는 보존되며 현재 실행 중인 도구나 작업은 계속될 수 있습니다. 취소한 목표의 오래된 화면으로 자동 이어가기·진척 복구가 다시 시작되지 않도록 보류합니다. 새 목표를 확인하거나 재개가 확인되면 보류를 해제합니다. [Codex의 Goal 명령 설명](https://developers.openai.com/cookbook/examples/codex/using_goals_in_codex).
- **기존 연결 사용:** 실행 중인 Codex의 제어 소켓을 사용합니다. 해당 연결이 없는 CLI는 자체 Goal 기록을 읽기 전용으로 조회하고 원래 터미널의 빈 입력 대기 상태에서 명령을 한 번 전달합니다. 초안·작업 중·다른 대화·불확실한 전달에는 명령을 반복하지 않습니다. 별도 Codex 서버나 상주 서비스를 시작하지 않습니다.
- **갱신 비용:** 같은 권한 요청의 행을 매번 재생성하지 않고, Goal 복구 보류 상태는 메모리에 보관해 매 화면마다 데이터베이스를 조회하지 않습니다.

격리된 3개 노드의 실제 HTTP·브라우저 검사에서 정책 충돌, 지연 응답, 세션 전환, 연결 단절·복구, Goal 교체와 응답 유실을 확인했습니다. 추가로 Chromium 40회·WebKit 10회의 반복 검사에서 선택·정책·키보드 포커스를 유지했고 Goal 중복 전달은 없었습니다. 실제 실행 중인 Codex에는 Goal 읽기만 수행했고, 실제 OS 권한 부여나 사용자 터미널 입력은 하지 않았습니다.

이번 환경에서는 PortManager가 선언한 `127.1.0.1` 주소가 네트워크 인터페이스에 없어 명시적 루프백 포트 재사용 검사 1건이 `EADDRNOTAVAIL`로 실패합니다. 시스템 주소·PortManager·보안 정책은 변경하지 않았습니다. 로컬 검증 수치를 실제 Wi-Fi·Cloudflare 지연 보장으로 해석하지 않습니다. 배포·설치와 상세 검증은 [검증 기록](../../VALIDATION.md)에 남깁니다.

제한된 환경의 패키징에는 `AUTOAPPROVE_SIGNING_READ_ONLY=1`을 사용합니다. 이미 사용 가능한 서명 키만 사용하며 키체인 생성·잠금 해제·검색 경로 변경을 하지 않습니다. 키를 사용할 수 없으면 기존 설정을 바꾸지 않고 서명 오류로 중단합니다.
