# AutoApprove 0.2.54 · 빌드 66

Codex가 기존 터미널에 입력하려고 묻는 ‘Would you like to send input to terminal …?’ 질문에서 자동 승인이 진행되지 않던 문제를 수정했습니다.

- 자동 승인이 켜진 세션의 완전한 터미널 입력 승인 질문을 인식합니다. 제목과 터미널 번호가 줄바꿈돼도 처리합니다.
- 현재 선택된 ‘Yes, proceed’와 확인 안내를 검사하고, 전달 직전에 원본 탭과 전체 질문을 다시 비교합니다. 터미널 번호·입력 내용·환경·사유가 바뀌면 이전 질문의 승인 입력을 보내지 않습니다.
- 같은 질문의 화면 크기 변경·반복 조회는 중복 승인하지 않으며, 여러 세션의 동시 질문을 각각 처리합니다.
- 화면의 escape 문자열은 JSON 전송·ANSI 셀 복원·승인 직전 비교에서 그대로 보존하도록 기존 처리를 유지하고 회귀 검사로 확인했습니다.

기존 Codex 대화 연결·대기 입력 관리·같은 네트워크 자동 업데이트·보기 전용 화면 공유 기능을 포함합니다. 휴대폰에는 설치가 필요 없습니다. 같은 네트워크 자동 업데이트를 받으려면 해당 Mac에 0.2.53 이상이 한 번 설치돼 있어야 합니다.

설치 파일은 AutoApprove-0.2.54-macOS-arm64.dmg입니다. 검증 범위는 [VALIDATION.md](https://github.com/newdlops/autoapprove/blob/main/VALIDATION.md)에 기록합니다.
