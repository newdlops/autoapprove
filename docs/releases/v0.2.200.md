# AutoApprove 0.2.200 · build 227

Codex 도구 승인창에서 명시적인 1회 허용을 놓치는 경우를 수정했습니다.

- `Allow once`·`Allow this time`·`Allow this request only`를 기존 `Allow`와 같은 1회 허용으로 인식합니다. 알려진 설명이 붙은 선택지도 지원합니다.
- `Allow` 뒤에 탭·줄바꿈하지 않는 공백 등 Unicode 공백이 있는 제목을 인식합니다. `Allowing` 같은 다른 단어는 승인 제목으로 취급하지 않습니다.
- 자동 승인 OFF·전체 일시정지·사용자 입력 우선·원본 화면 검증·같은 요청 중복 방지를 유지합니다. 작업 선택지·모호한 허용·취소 선택을 자동으로 확정하지 않으며, 영구 허용만 있는 메뉴에는 입력하지 않습니다.

이번 수정은 승인 감지 로직입니다. 기존 화면과 터미널 연결 방식을 유지합니다. [검증 범위](../../VALIDATION.md).
