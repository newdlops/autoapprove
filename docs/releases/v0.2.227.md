# 0.2.227 · 축약된 Claude 하단 상태와 대기 인식

Claude의 하단 안내가 `auto mode on · 1 shell · 1 feedback draft`처럼 바뀌어 단축키 안내가 보이지 않을 때, 빈 입력창이 계속 미확인으로 남는 문제를 보완합니다.

- 고정된 자동 모드·셸/피드백 초안 개수 문법만 하단 안내로 인식합니다. 좁은 화면에서 최대 3줄로 감긴 안내도 제한된 범위 안에서 복원합니다.
- 백그라운드 셸이 보이면 ‘대기 중 · 모니터링’을 유지해 작업 완료 알림으로 오인하지 않습니다. 피드백 검토·전송 카드는 대기로 판정하지 않으며 피드백을 보내지 않습니다.
- 작성 중인 입력, 선택 메뉴, 실행 중 안내, 알 수 없는 후속 문장과 세션 세대 변경에 대한 기존 보호를 유지합니다. 프로젝트/브랜치 같은 자유 형식 문장을 이어 붙이지 않습니다.

이는 화면의 대기 판정을 보완하는 변경입니다. 실제 Terminal 창의 크기·과거 스크롤 조작과 외부 Cloudflare TLS 경로의 미완료 검증은 별도로 유지합니다. 상세 범위는 [검증 기록](../../VALIDATION.md)에서 확인할 수 있습니다.
