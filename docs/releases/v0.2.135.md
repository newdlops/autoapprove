# 0.2.135 · Cocoa 터미널 화면의 행 준비 경량화

Cocoa 문자열을 문자마다 읽고 복사하던 부분을 작은 UTF-16 버퍼로 처리합니다. 최대 8KiB의 임시 읽기 버퍼를 사용하고, 정상 행은 UTF-8 출력에 직접 기록합니다. NFC 정규화·CR/LF·CRLF·잘못된 UTF-16의 대체 처리와 원본 바이트 예산을 유지하며 전체 화면의 UTF-8 복사본을 추가로 보관하지 않습니다.

같은 실제 엔진과 사전 준비한 합성 화면 16개를 사용해 이전/수정 빌드를 3쌍 교대 측정했습니다. 출력이 바뀌는 화면 500회 갱신의 CPU 중앙값은 **7.541→5.107초**, 벽시계 시간은 **7.698→5.216초**였습니다. 변경 없는 화면은 비슷한 수준이었고 각 세션의 상태와 출력 갱신 500회를 유지했습니다. 이 처리 경로의 합성 측정이며 설치 앱 전체나 실제 휴대폰 지연의 개선율은 아닙니다.

Release 전체 회귀 검사 361개와 Debug 내부 행 준비 검사 4개가 통과했습니다. 실제 소스를 이전 배포판과 대조한 행·바이트·저장소·코드 블록 경계 검사 2,164건, 전체 유효 Unicode scalar 1,112,064개, 버퍼 경계 28개 경우도 통과했습니다. 일반 선택 질문 수동 응답과 기존 실행 권한·원본 입력 검증 정책은 유지합니다.

macOS 14 이상 Apple Silicon용이며 빌드는 162입니다. 설치 방법은 [설치 안내](../../README.md#설치)를 참고하세요.
