# AutoApprove 0.2.326 · 빌드 353

공유 서버에 연결된 Codex 탭에서는 서버가 대화 기록 파일을 열고 MCP 호출을 처리합니다. 이전 버전은 이 경우 대상 탭의 세션 ID를 확인하지 못해 갱신을 중단할 수 있었습니다.

개별·전체 세션 ID 갱신과 MCP 재연결은 로컬 대화 기록, 대상 탭과 연결된 MCP 호출, 원래 탭에서 새로 받은 `/status` 응답 순으로 현재 ID를 확인합니다. 그룹 목록을 여는 동안에는 터미널에 입력하지 않습니다. 초안이나 승인창이 열려 있으면 해당 탭의 명령 입력을 보류하고 기존 ID를 유지합니다.

공식 Codex 0.169.0 두 탭을 같은 작업 폴더에서 같은 로컬 Unix 서버에 연결해 검증했습니다. 한 탭에서 `/clear`를 실행한 뒤 해당 구성원만 새 ID로 갱신됐고, 다른 구성원은 기존 ID를 유지했습니다.
