# 0.2.144 · Terminal 커서 조회 경량화

머지된 [PR #6](https://github.com/newdlops/autoapprove/pull/6)을 포함합니다. Terminal 커서를 읽을 때 전체 화면의 창 목록 대신 지정한 창 ID의 메타데이터를 요청하고, 창의 위치·크기와 요소의 역할·자식 속성을 묶어서 조회합니다. 창 ID·소유 PID·화면 표시 여부·경계와 유일한 텍스트 영역을 확인하는 조건은 유지합니다. 텍스트·삽입 위치·보이는 범위는 같은 응답에서 읽습니다.

같은 합성 창 트리에서 읽는 속성 **28개**를 유지하며 조회 호출은 **26→14회**로 줄었습니다. 0.2.143과 비교한 커서 상태 **66건**이 모두 일치했고, 창 메타데이터 **10종**, 전송 실패·잘린 응답 **8종**, 요소 256개 탐색 한도도 통과했습니다. 이 수치는 합성 조회의 호출 수이며, 실제 Mac의 AX 조회 지연·앱 전체 CPU나 휴대폰 체감 속도의 측정값은 아닙니다. 실제 화면·AX 조회를 사용하는 별도 벤치마크는 실행하지 않았습니다.

합친 Core의 전체 Release **368/368** 검사가 통과했습니다. 버전 리소스 복사 뒤에도 검사한 Core와 검사 실행 파일의 동일성을 확인했습니다. 서명 패키지의 자동 응답 12건·명시적인 웹 답변을 기다리는 수동 질문 12건, 일시정지·재시작·응답 유실/중복 방지·격리 웹/MCP/PTY·입력 구성요소·DMG 검사도 통과했습니다. App/CLI 각 38개 코드 section과 웹 리소스 13개가 최종 빌드/소스와 일치합니다.

0.2.143의 tmux 호스트 판별 경량화와 0.2.142의 웹 기록 정리 기능도 포함합니다. macOS 14 이상 Apple Silicon용이며 빌드는 171입니다. 기존 발행자 인증서를 재사용합니다. 설치 방법은 [설치 안내](../../README.md#설치)를 참고하세요.
