# AutoApprove 0.2.280 · build 307

서브에이전트 행에 Goal 관리 화면을 추가했습니다. 지원하는 관리형 서버에서 목표·상태·예산·누적 사용량을 확인하고 일시정지하거나 재개할 수 있습니다. 긴 목표는 전체 펼치기를 제공합니다.

- 일시정지는 Goal의 후속 진행을 먼저 멈춘 뒤 관찰한 현재 작업만 중단합니다. 작업 종료가 확인되지 않으면 이를 별도로 안내합니다.
- 요청 ID를 실행 전에 저장합니다. 같은 요청은 결과가 유실되거나 앱을 다시 열어도 자동 재전송하지 않습니다.
- 미지원 서버·Goal 없음·조회 실패·변경 중·결과 미확인을 구분합니다. 열린 관리 영역만 주기적으로 조회합니다.

**지원 범위:** 이 앱 업데이트만으로 공식 Codex 서버에 새 기능이 설치되지는 않습니다. 고정된 Codex 0.167.1용 opt-in 소스 패치와 준비 도구를 포함했으며, 실제 서버 설치/업그레이드와 기존 클라이언트 이동은 아직 준비 중입니다. 로그인 그룹 변경과 세션별 실행 서버 선택도 이번 배포의 완료 기능이 아닙니다.
