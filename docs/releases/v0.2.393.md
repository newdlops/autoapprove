# AutoApprove 0.2.393 · 빌드 420

- get_group_status(view="overview")는 작업 지시·보고 원문 없이 구성원별 한 행을 반환합니다. 최근 화면을 판독할 수 있을 때 입력창, ctx, 5시간 사용률 또는 남은 컨텍스트 비율을 표시합니다. unacknowledged는 수신 확인 대기 건수입니다.
- send_group_message의 새 messageID와 supersedes 배열은 같은 대상에게 보낸 미전송 일반 메시지를 한 트랜잭션에서 대체합니다. cancel_group_messages는 messageIDs만 취소합니다. 전송을 시작했거나 결과가 불확실한 메시지는 보존합니다.
- 그룹장은 interrupt_group_task에 groupID, memberID, taskID를 지정해 원래 작업 화면을 저장하고 Esc를 한 번 전달할 수 있습니다. 이후 overview로 상태를 다시 확인하세요.
- 배정 30분 뒤까지 완료 보고가 없으면 배정자 보관함에 작업별로 한 번 알립니다.
- assign_group_tasks는 최대 16건의 공통 또는 개별 지시를 한 번에 받아 항목별 결과를 반환합니다. assign_group_task와 일괄 배정의 workScope에 같은 브랜치·PR·경로를 선언하면 scopeConflicts로 진행 중인 다른 소유자를 알려주고 배정을 보류합니다. 의도한 공동 작업은 allowScopeConflict=true로 배정합니다. 항목별 requestID를 지정하면 기록된 배정을 재전송하지 않습니다.
- AutoApprove가 작업의 명령 접두사를 거절하면 첫 구절과 수정 방법을 알려줍니다.
