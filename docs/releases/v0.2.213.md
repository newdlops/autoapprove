# 0.2.213 · 터미널 프로필 저장·복원

- **복원 준비:** 실행 중인 CLI의 신원·설정 폴더와 중복 여부를 확인하며, 저장할 때 사용하는 전체 탭 선택·구성 수집과 Codex 대화 선택 목록 조회를 생략합니다. 탭 수집 권한 오류가 복원 준비까지 막던 경로를 분리했습니다.
- **현재 창 저장:** 이전 선택 확인·다음 탭 선택·선택 결과를 한 스크립트에서 처리합니다. 같은 설정 폴더·작업 폴더의 대화 선택 목록은 한 번의 수집 동안 공유하고 다음 수집 때 다시 읽습니다. 대화를 자동으로 선택하지 않습니다.
- **탭 식별 비용:** 복원 중 선택 창은 정확한 TTY 조건의 네이티브 Apple Event로 확인합니다. 확인마다 스크립트 프로세스를 새로 띄우고 모든 탭을 순회하던 비용을 줄이고, 새 탭 준비의 전체 TTY 목록도 한 번만 읽습니다.
- **탭 반영 대기:** 새 탭과 선택 변경을 한 번 실행한 뒤 AX 화면 반영을 제한 시간 동안 읽습니다. 새 셸의 준비 확인도 빠른 고정 횟수 대신 최대 5초 동안 기다립니다. 준비된 경우 즉시 진행합니다.
- **실패 확인:** 불확실한 전달을 다시 보내지 않으며, 재시도 화면에도 최초 오류 원인을 남깁니다. 원본 TTY·프로세스·동일 탭 그룹·빈 셸 확인과 후속 탭 중단을 유지합니다.

프로필 파일 형식과 기존 화면 구성은 유지합니다. 검사·격리 AppKit·공개 배포·정식 설치 결과는 [검증 기록](../../VALIDATION.md)에 남깁니다. 실제 사용자 Terminal의 전체 저장·복원 시간과 성공률은 이번 자동 검증에서 측정하지 않았습니다.
