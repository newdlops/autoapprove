# AutoApprove 0.2.183 · build 210

다른 네트워크의 기기에서도 HTTPS 웹 페이지로 Mac 관리 화면과 터미널에 접속할 수
있도록 **연결 설정 → 다른 네트워크에서 접속**을 추가했습니다. 외부 접속은 기본적으로
꺼져 있습니다.

- 계정 없이 만드는 **Cloudflare 임시 주소**, 토큰을 사용하는 **Cloudflare 고정 도메인**,
  별도로 실행 중인 **로컬 터널 연결**을 지원합니다. 연결 도구는 앱에서 설치할 수 있고,
  공식 cloudflared 2026.10.3의 크기와 SHA-256을 검증합니다.
- 연결 확인 후 접속 링크와 QR을 제공합니다. 무작위 접속 키로 인증하고, 브라우저는
  Secure/HttpOnly 쿠키로 최대 8시간 접속합니다. 로그아웃·종료·키 교체 시 인증과
  진행 중인 외부 연결을 해제합니다. Cloudflare 토큰은 Mac 키체인에 보관합니다.
- 고정 도메인은 기존 실시간 비트 스트림을 사용합니다. Cloudflare 임시 터널은
  SSE를 지원하지 않아 화면을 순서대로 조회합니다. 두 방식 모두 원본 PID·TTY 확인,
  순차 입력, 불확실한 입력의 자동 재전송 금지를 유지합니다.
- 외부 접속은 별도의 loopback 인증 게이트웨이를 사용합니다. 기존 LAN 검색·연결을
  유지하며, 외부 페이지의 복구 경로가 사설 IP로 이동하지 않도록 했습니다.
- 연결 도구 종료 시 재연결을 시도하고, 연결 종료 시 소유한 도구와 접속을 정리합니다.
  외부 연결 중에는 LAN 자동 업데이트를 기다립니다.

현재 검증 네트워크에서는 Cloudflare edge의 외부 TCP 7844 연결이 시간 초과되어
실제 인터넷 Quick Tunnel 검사는 완료하지 못했습니다. 연결되지 않은 주소는 준비
완료로 표시하지 않으며 원인을 안내합니다. 사용자 계정의 고정 도메인은 도메인·토큰을
설정한 뒤 확인해야 합니다. 인증·실시간/순차 조회·실제 격리 PTY·입력 중복 방지는
합성 HTTPS 환경의 Chromium/WebKit에서 검사했습니다.
