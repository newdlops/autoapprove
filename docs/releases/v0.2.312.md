# AutoApprove 0.2.312 · 빌드 339

AutoApprove가 새로 실행하는 Codex를 OpenAI 공식 원본으로 전환합니다. 앱에 포함하는 Codex도 수정본이 아닌 공식 0.169.0 패키지이며, 원본 파일 해시와 OpenAI 코드 서명을 확인합니다. 실행 중인 사용자 Codex는 교체하거나 종료하지 않습니다.

## 유지하는 기능

- 자동 승인, 질문 처리, 세션 그룹과 로컬 메시지 전달
- 로그인 홈 선택, 계정 조회와 이미 연결된 관리형 서버의 로그인 재연결
- 호환되는 공식 서버를 확인한 저장 대화의 프로필 복원
- 공식 서버에서 지원 조건이 확인된 하위 에이전트 Goal 일시정지·재개

선택된 서버 패키지가 수정본이거나 호환 서버를 확인하지 못한 경우에도, 대화 ID를 비워 둔 새 프로필은 공식 CLI를 독립 실행할 수 있습니다. 이때 데몬 자동 연결을 명시적으로 끄며 로그인 홈을 유지합니다. 저장 대화의 이어 열기는 이 경로를 사용하지 않습니다.

## 구현하지 못한 기능

1. 이미 열린 터미널의 모든 대화·하위 작업·초안을 보존하는 로그인 그룹 간 이동·병합·분리
2. 이미 열린 독립 Codex 세션을 공유 서버에 자동 편입
3. 실행 중인 수정판 Codex 서버·클라이언트를 공식판으로 자동 교체
4. 터미널별 전체 접속 ID와 서버 연결 목록 조회
5. 하위 에이전트 승인 후 직전에 보던 임의의 화면으로 복귀. 확인된 경로는 Main으로 돌아오며, 별칭·잘린 이름·불분명한 목록은 수동 조작이 필요합니다.
6. 처리 결과가 불확실한 Goal 요청의 자동 복구·재실행. 중복 전송을 막기 위해 새 상태 확인과 명시적인 새 요청이 필요한 경우가 있습니다.

미지원 이동·연결 목록 기능은 화면에서 구분하고 서버 준비나 터미널 입력 전에 거절합니다. 기존 수정판 패키지와 실행 중인 작업은 유지하므로, 이미 열려 있는 Codex의 실행 파일이 이번 앱 설치만으로 바뀌지는 않습니다.

미지원은 공식판에서 영원히 불가능하다는 뜻이 아닙니다. 열린 세션 이동은 숨겨진 대화·초안의 완전한 범위를 확인하지 못했고, 재실행 시험에서 숨겨진 초안 유실을 확인했습니다. 기존 세션 편입은 모든 작업이 쉬는 통제된 환경에서는 성공했지만, 다른 클라이언트의 작업까지 확인하고 조율하는 처리가 미완성입니다. 전체 연결 목록은 터미널과 서버 내부 연결 ID의 누락 없는 대응표를 얻지 못했습니다. 화면 복귀는 승인창에 직전 화면 정보가 없으며, Goal 복구는 결과 기록 전 종료된 요청을 새 상태와 대조해 자동 판정하는 처리가 미완성입니다.

## 검증 범위

전체 회귀 검사 **298/298**, 최종 release 빌드와 VSIX 패키징이 통과했습니다. 서명한 앱 내부의 공식 Codex 42개 파일도 원본과 일치함을 확인했고, 설치 DMG와 업데이트 ZIP 및 각각의 SHA-256 파일을 생성했습니다.

공식 원본 패키지의 전체 파일·서명 검사, 격리된 실제 공식 데몬과 PTY, 수정판 선택 캐시 실행 거부, 새 프로필의 공식 독립 실행을 검증했습니다. 하위 Goal의 실제 일시정지·재개 및 제어 프로세스 중단 경계도 별도 임시 환경에서 확인했습니다. 사용자 터미널이나 실제 자격 증명은 이 검사에 사용하지 않았습니다.

계정 화면은 밝음·어두움과 350·600포인트 너비에서 합성 상태를 렌더링해 확인했습니다. 실제 사용자 터미널의 클릭·스크롤 성능은 이번 검증 범위에 포함하지 않습니다. 지원 범위와 상세 증거는 [조사 기록](../superpowers/specs/2026-11-16-official-codex-alternatives.md)에 있습니다.
