# 0.2.150 · Git 상태 조회 경량화

Git 브랜치를 반복 확인할 때 알려진 메타데이터 파일과 디렉터리의 유형을 명시해, 경로 생성 중 불필요한 파일 속성 조회를 줄였습니다. HEAD·설정·참조·객체 변경과 실제 파일 유형은 계속 확인합니다. 조회 주기와 자동 승인·일반 질문의 수동 응답 정책은 유지합니다.

실제 Release 코어에 합성 저장소 16개를 제공하고 250회 순회·8쌍 교대로 비교한, 변경 없는 메타데이터 확인의 CPU 중앙값입니다.

| 조회 상황 | 기존 | 변경 후 | 감소율 |
| --- | ---: | ---: | ---: |
| 일반 브랜치 | 0.869476초 | 0.683703초 | 약 21.4% |
| Linked worktree | 1.126467초 | 1.0251905초 | 약 9.0% |
| Packed ref | 0.7071165초 | 0.589376초 | 약 16.7% |
| Detached HEAD | 1.579145초 | 1.4544995초 | 약 7.9% |

사전에 정한 CPU·메모리 기준을 모두 통과했습니다. 측정 중 Git 호출은 두 버전 모두 0회였고, HEAD를 바꾼 뒤에는 다시 검증했습니다. 비교 프로세스의 peak RSS 중앙값은 12,730,368→12,558,336바이트였습니다. 실제 Git 실행 시간·전체 앱 CPU/메모리·휴대폰이나 VPN 연결 속도의 개선율은 아닙니다.

전체 회귀 **376/376**과 Git 경계 검사 **8/8**을 통과했습니다. 특수 문자 경로, 메타데이터의 디렉터리 교체, 심볼릭 링크 대상 오류와 상대 gitdir를 확인했습니다. 새 서비스·자동 실행 등록이나 보안·권한·VPN 설정 변경은 없습니다.

최종 서명 패키지의 자동 Allow/이번 세션/현재 모델 12건, 일반 질문의 명시적 웹 응답 대기 12건과 재시작·응답 유실/중복 방지·웹/MCP·격리 PTY·입력 번들·DMG 검증도 통과했습니다. 설치 앱의 파일 수와 총 바이트는 이전과 같으며, DMG는 8,899,073바이트로 이전보다 약 1MB 큽니다.

macOS 14 이상 Apple Silicon용이며 빌드는 177입니다. 설치 방법은 [설치 안내](../../README.md#설치)를 참고하세요.
