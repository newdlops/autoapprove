# 0.2.237 · 앱 이동 후 Claude 훅 경로 복구

Claude 훅이 이전 `dist/AutoApprove.app`을 참조한 상태에서 빌드를 정리하면 `PreToolUse`·`PostToolUse`에 파일을 찾을 수 없다는 오류가 반복됐습니다. 기존 시작 시 갱신은 현재 앱 경로와 일치하는 훅만 처리해 이동한 경로를 놓쳤습니다.

이제 앱 시작 시 같은 `AUTOAPPROVE_HOME`을 사용하는 정식 AutoApprove 앱 훅의 경로를 현재 앱으로 갱신합니다. 옛 빌드가 남아 있는 경우와 이미 삭제된 경우 모두 처리하며, 원본 설정을 백업하고 반복 실행 시 불필요하게 다시 쓰지 않습니다.

브리지를 정상적으로 시작한 앱만 경로를 갱신합니다. 실행 전·종료 후 엔진이나 이미 실행 중인 앱 때문에 시작에 실패한 복사본은 설정을 바꾸지 않습니다.

다른 저장소의 훅, 사용자 정의 실행 파일·셸 명령, 전체 훅 비활성화와 명시적으로 비워 둔 `StopFailure` 설정을 보존합니다. 셸 명령을 평가하지 않고 설치기가 생성한 정확한 인용 형식만 해석합니다. [검증 기록](../../VALIDATION.md).
