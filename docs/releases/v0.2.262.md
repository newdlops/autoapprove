# AutoApprove 0.2.262 · 빌드 289

같은 네트워크에서 새 버전을 받았어도 Mac 덮개가 닫혀 있다는 이유로 설치를 계속 미루던 제한을 제거했습니다. 닫힌 상태로 실행 중인 Mac에서도 앱을 교체하고 다시 엽니다. 잠든 Mac을 원격으로 깨우지는 않습니다.

업데이트 설치 도구는 앱 종료 전에 유휴 잠자기 방지 활동을 시작합니다. AutoApprove가 이미 소유한 잠자기 유지 상태가 있으면 설치 도구의 감시 프로세스로 인계하고, 새 앱이 유지 상태를 이어받은 뒤 감시를 넘깁니다. 설치 실패·프로세스 종료 때는 감시가 기존 잠자기 설정을 복원합니다. 새 관리자 권한이나 잠자기 설정 규칙을 설치하지 않습니다. 일반적인 앱 종료의 복원 동작은 유지합니다.

원본 Codex·Claude 세션은 유지하며 입력·별도 PTY·웹 질문·화면 공유·로그인·진단 등의 기존 대기는 유지합니다. 서명·버전·체크섬·원본 프로세스 검증도 유지합니다.

0.2.261 이하 수신기는 기존 덮개 제한을 실행하므로, 이번 한 번은 덮개를 열고 업데이트하거나 새 설치본을 적용해야 합니다. 0.2.262부터 이후 업데이트에 새 동작이 적용됩니다.
