# AutoApprove 0.2.307 · 빌드 334

그룹원이 그룹장이나 다른 그룹원에게 자유롭게 질문하고 답하는 경로를 추가했습니다. Codex↔Claude를 포함하며, 그룹장 유무와 관계없이 같은 그룹 안에서 사용할 수 있습니다.

- `ask_group_question(groupID, memberID, text)`: 대상 구성원에게 질문합니다.
- `reply_group_question(groupID, memberID, text)`: 받은 질문에 답합니다. 메시지에 표시된 보낸 구성원 ID를 대상으로 지정하고 무엇에 대한 답인지 함께 적습니다.
- `get_session_groups`와 `get_group_status`의 `canAskQuestion`은 대상과 대화가 확인됐는지를 나타냅니다. 즉시 입력 가능 여부는 전송 시 다시 확인합니다.

질문에는 보낸 구성원과 답장 주소를 붙여 같은 Mac의 원래 터미널에 입력합니다. Unix 소켓과 기존 터미널 입력 경로만 사용하며, 외부 서버·LAN·메시지 큐를 추가하지 않습니다. 전달 완료는 에이전트가 읽거나 답변했다는 의미가 아닙니다.

Codex는 작업 중에도 빈 입력창에 받을 수 있습니다. Claude는 기존 전송 방식에 맞춰 idle 상태에서 받습니다. 초안·질문·승인·다른 입력과 겹치거나 연결을 확인하지 못하면 전달하지 않습니다. 제출 여부가 불확실하면 자동 재전송하지 않으며 원래 터미널에서 확인해야 합니다.

기존 작업 지시는 `assign_group_task`, 직속 작업자의 선택지·권한 요청 답변은 `answer_group_question`을 그대로 사용합니다. 새 질문·답변 도구는 작업 기록, 그룹 역할, 자동 승인 설정을 바꾸지 않습니다.

이미 열린 에이전트의 MCP 도구 목록은 이전 목록이 남을 수 있습니다. 새 도구가 보이는 MCP 연결에서 사용해야 합니다. 앱 설치만으로 기존 에이전트의 도구 목록까지 갱신됐다고 간주하지 않으며, 사용자 CLI나 진행 중인 대화를 자동으로 다시 시작하지 않습니다.
