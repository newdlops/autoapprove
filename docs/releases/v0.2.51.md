# AutoApprove 0.2.51 · 빌드 62

휴대폰에서 Mac 화면을 보고, 같은 Codex·Claude Code 세션에 자동 테스트를 지시합니다.

- **화면 공유** 한 번으로 Mac 전체 화면을 바로 엽니다. 보기 전용이며 확대는 휴대폰에만 적용됩니다. 기존 MCP 공유가 없어도 시작할 수 있습니다.
- **세션에 테스트 지시**로 공유를 연 원본 세션의 질문·메시지를 엽니다. 닫으면 같은 공유 화면으로 돌아갑니다. 세션 종료·선택 변경에는 지시 버튼을 비활성화합니다.
- 최신 Codex에서 **Codex 대화 연결**로 고른 대화에 새 메시지와 테스트 지시도 전달합니다. 보내기 전에 원본 실행과 선택한 대화·폴더를 확인합니다.

각 Mac을 업데이트하고 휴대폰 페이지를 새로고침해주세요. 화면 녹음 권한은 Mac에서 한 번 허용해야 합니다. 휴대폰 설치는 필요 없습니다. 공유 종료·보기 닫기·브라우저 숨김과 10분 만료를 유지합니다.

검증 범위는 [VALIDATION.md](https://github.com/newdlops/autoapprove/blob/main/VALIDATION.md)에 기록합니다. 설치 파일은 `AutoApprove-0.2.51-macOS-arm64.dmg`입니다.
