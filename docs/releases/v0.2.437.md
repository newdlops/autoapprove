# AutoApprove 0.2.437 · 빌드 464

그룹 대화 그래프의 구성원 목록에서 닉네임 ‘전체 다시 정하기’ 옆에 ‘모든 메시지 비우기’를 추가했습니다. 그룹 이름을 확인하고 실행하면 해당 그룹과 하위 그룹의 대기 메시지, 미응답 질문, 예약된 배정을 비웁니다. 이미 전달된 그룹 배정과 배정 기록 없이 작업 중인 그룹 세션에는 원래 대화를 확인한 뒤 중단을 요청하며, 중단을 확인해야 하는 구성원을 결과에 표시합니다.

MCP의 `clear_group_member`는 다른 구성원의 초기화가 진행 중이어도 지정한 구성원을 별도로 접수합니다. 같은 구성원의 중복 요청은 기존 초기화 결과를 공유하며, 어느 요청 ID로도 상태를 확인할 수 있습니다. Codex의 원래 터미널에서 초기화 전후 대화 ID를 확인할 수 있으면 상태 확인 명령 입력을 생략합니다.
