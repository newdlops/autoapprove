# AutoApprove 0.2.328 · 빌드 355

Codex가 Terminal 또는 iTerm2의 같은 셸에서 새 대화로 다시 실행되면 세션 ID 갱신에서 해당 대화를 확인해 기존 구성원에 연결합니다. 셸의 실행 시각과 PID, 터미널 종류, TTY, 로그인 홈과 작업 폴더를 대조합니다. 이전에 저장한 구성원은 세션 그룹 창에서 **새 대화로 교체…**를 선택하고 실행 중인 탭을 지정할 수 있습니다.

그룹장 역할과 상위·하위 관계는 기존 구성원 ID에 유지됩니다. 새 대화가 별도 구성원으로 이미 등록된 경우 역할·작업·메시지 기록 충돌이 없는 중복 항목은 함께 정리합니다.
