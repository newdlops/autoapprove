# 0.2.134 · 반복 화면 감시 CPU 경량화

터미널 화면의 위험 명령 후보를 한 번에 찾는 작은 검색표를 추가했습니다. 후보가 없는 일반 출력은 불필요한 정규식 검사를 생략합니다. 후보가 있거나 Unicode 처리가 불확실하면 기존 검사를 거치며, 설치 스크립트는 매번 현재 파일을 다시 확인합니다. 입력 내용이나 승인 결과를 새로 캐시하지 않습니다.

동일한 실제 엔진에 사전 준비한 합성 Cocoa 화면 16개를 넣고, 이전·수정 빌드를 3쌍 교대 측정했습니다. 500회 갱신의 CPU 중앙값은 다음과 같습니다.

| 화면 | 0.2.133 | 수정본 |
| --- | ---: | ---: |
| 변경 없음 | 1.477초 | 0.460초 |
| 출력 변경 | 9.112초 | 7.927초 |

각 세션의 작업·대기·승인·질문 상태와 출력 갱신 500회를 유지했습니다. 유휴 상태 확인은 측정 전에 준비했고, 원본 터미널 읽기·입력·화면 캡처는 없습니다. 이 처리 경로의 합성 측정이며 설치 앱 전체 CPU나 실제 휴대폰 지연의 개선율은 아닙니다.

Release 회귀 검사 360개가 통과했습니다. 배포판 0.2.133과 판정 12,750건, Unicode·경로 경계 입력 5,560,320건의 대조도 통과했습니다. 0.2.133의 일반 선택·복수 선택 질문 수동 응답 정책과 실제 시스템 변경의 안전한 대안 안내를 유지합니다.

macOS 14 이상 Apple Silicon용이며 빌드는 161입니다. 설치 방법은 [설치 안내](../../README.md#설치)를 참고하세요.
