# AutoApprove 0.2.299

- 앱 메뉴와 메뉴 막대에 ‘업데이트…’를 추가했습니다. GitHub 정식 릴리스를 앱 시작 시와 매시간 확인하고 새 버전을 자동 다운로드·적용합니다. 자동 적용은 창에서 끌 수 있고 선택은 재실행 후에도 유지됩니다.
- 기존 서명·체크섬 검증, 다운로드 재개와 앱 교체 절차를 재사용합니다. 설정·프로필·대화 데이터는 유지하며 AutoApprove만 재실행합니다.
- 웹 접속이 꺼져 있어도 업데이트할 수 있습니다. 네트워크 격리 모드에서는 확인을 중지하고, 입력 전송·로그인·진단·별도 PTY·화면 공유 중에는 적용을 기다립니다.
- 동일 설치기가 LAN·웹 요청과 GitHub 자동 업데이트를 직렬 처리합니다.
- 그룹의 대화 ID를 갱신하는 동안 같은 실행 세션이 목록에서 그룹 밖으로 빠지지 않게 했습니다. 갱신 직후 그룹 표시도 다시 계산하며, 작업 전달 시 대화 ID 확인은 그대로 유지합니다.

- Codex 그룹 메시지는 대상 Terminal 탭에 한 번에 직접 전달합니다. 창 활성화·포커스 선택·클립보드·키보드 이벤트를 사용하지 않으며, 직접 전달할 수 없으면 포커스를 가져오는 대신 미전달로 처리합니다.

검증: 자동 업데이트 설정 유지·격리·오류 처리와 그룹 표시·포커스 없는 메시지 전달 회귀 검사, 업데이트 창의 정상·오류 상태 렌더, 웹 서버 없는 별도 서명 앱의 자동 다운로드·교체·재시작. 로컬 적용은 GitHub에서 받은 검증된 ZIP 캐시와 기존 앱의 업데이트 경로를 사용합니다.
