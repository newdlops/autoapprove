# 0.2.217 · 프로필 저장·복원 조회 경량화

- **저장:** 처음 확인한 창 ID와 정확한 TTY 조건으로 해당 탭을 찾습니다. 탭마다 다른 창의 모든 탭을 다시 훑던 조회를 제거했습니다. 이전 선택·창 ID·TTY·현재 초점은 계속 확인합니다.
- **복원:** 새 탭과 원래 탭의 묶음을 확인할 때 이미 읽은 네이티브 탭을 직접 선택합니다. 탭 추가 단계의 외부 스크립트는 **4→2회**, 설정 프로필 확인과 명령 전달까지 포함하면 **6→3회**로 줄입니다. 설정 프로필 확인은 탭을 선택하기 전 준비 단계에 합쳤습니다.
- **반복 조회:** 한 작업 안에서 확인한 Terminal 프로세스를 사용하고 매 조회 전후에 커널의 PID·시작 시각을 다시 확인합니다. 전체 프로세스 목록 대신 해당 PID만 다시 읽습니다. 다른 저장·복원 작업에 오래된 프로세스를 재사용하지 않습니다.
- **순서와 대상 확인:** 두 번째부터 128번째 탭까지 같은 경로를 사용합니다. 창별 완료 순서와 저장된 대화 ID, 정확한 TTY·창·탭 묶음·빈 셸 확인, 키와 명령의 단일 전달은 유지합니다. 확인되지 않은 선택을 다른 방식으로 재전송하지 않습니다.

관련 탭 **34/34**·프로필 **11/11**이 통과했습니다. 두 번째부터 128번째 탭 각각의 AX 객체 교체와 이전/새 선택 경로 **1,016건**, 잘못된 대상·초점·권한·설정 누락과 중복 제출 방지를 포함합니다. 최종 전체 회귀는 **604/605**이며 실패 1건은 이전 버전과 같은 별도 루프백 주소 재사용 검사의 `NWError 49`입니다. 첫 전체 실행의 승인 지연 검사 1건은 단독 재실행과 두 번째 전체 실행에서 통과했습니다.

조회·스크립트 횟수 비교는 합성 데이터로 수행하며 실제 Terminal 전체 복원의 소요 시간이나 배수 개선을 뜻하지 않습니다. 회귀 테스트와 배포·설치 기록은 [검증 기록](../../VALIDATION.md)에 남깁니다. 사용자 요청에 따라 실제 Terminal 저장·복원과 추가 UI 검증은 자동 실행하지 않습니다.
