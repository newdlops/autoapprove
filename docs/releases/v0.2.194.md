# AutoApprove 0.2.194 · build 221

화면 공유와 터미널 입력의 연결 안정성과 전송 효율을 개선합니다.

- 현재 캡처·권한·공유 수명을 확인한 뒤, 이미지가 같으면 조건부 응답으로 본문 전송과 브라우저 디코딩을 생략합니다. Mac 사이 중계와 Cloudflare에도 적용합니다.
- 여러 뷰어가 하나의 캡처·검증 결과와 관찰 시각을 함께 사용합니다. 한쪽 조회의 취소가 다른 쪽 조작을 끊거나 더 최신 캡처를 지우지 않도록 했습니다.
- 조작 화면의 요청 간격에서 이미 응답을 기다린 시간을 빼 화면 갱신의 불필요한 대기를 줄입니다. 캡처 요청은 하나씩 진행합니다.
- 응답 없는 입력 WebSocket을 감지합니다. 확인된 유휴 터미널은 자동 복구하고, 전송 결과가 불확실한 입력은 재전송하지 않습니다. 화면 조작이 끊기면 눌린 버튼을 해제합니다.
- 빠른 ACK가 포인터 이동 병합을 무효화하던 문제와, 꽉 찬 대기열에서 마지막 이동 좌표를 바꿀 때 조작이 종료되던 문제를 고쳤습니다. 클릭·텍스트·버튼 해제는 순서대로 즉시 보냅니다.
- native 입력 대상은 매 입력 직전 한 번 새로 확인하고 그 결과를 바로 사용합니다. 입력 사이에 창 위치·포커스·소유자 정보를 재사용하지 않습니다.
- 구형 호스트의 전체 이미지 응답과 기존 질문·메시지·원본 CLI·PIN·PortManager 동작을 유지합니다.
