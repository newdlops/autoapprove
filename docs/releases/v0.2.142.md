# 0.2.142 · 웹 목록과 지난 메시지 정리

연결이 끊긴 Mac은 접힌 ‘이전 연결’에 모읍니다. ‘목록 정리’에서 연결 끊긴 Mac과 경고 표시를 한꺼번에 정리하고 다시 표시할 수 있습니다. Mac별 정리와 경고별 정리도 지원하며, 구버전·오프라인 Mac의 오류는 이 브라우저에서 표시를 정리할 수 있습니다. 서버 목록에서 제거된 Mac의 화면 행과 해당 행의 참조도 해제합니다. 다시 연결된 Mac과 새 ID의 경고는 표시합니다.

지난 답변은 접힌 간단한 기록으로 표시하고 편집기는 새 질문에 사용합니다. ‘이전 메시지·전송 상태’에는 개별·전체 정리와 1분 되돌리기를 추가했습니다. 지난 기록은 작성창과 분리된 스크롤 영역에 두어 모바일에서 메시지 입력·전송 조작부를 밀어내지 않습니다. 저장에 실패하면 기록을 유지하고 오류를 표시하며, 늦게 도착한 접수 확인이 정리한 기록을 되살리거나 새 초안을 지우지 않도록 했습니다.

목록·경고·지난 답변 정리는 접속한 웹 주소의 브라우저에 식별자만 저장합니다. 지난 메시지 정리는 해당 탭의 전송 기록을 대상으로 합니다. 작성 초안·전송 중인 요청·Codex의 실제 대기 입력·Mac의 감사 내역과 안전 검사는 유지합니다. 별도로 검토한 Cocoa 변환 후보는 포함하지 않았습니다.

macOS 14 이상 Apple Silicon용이며 빌드는 169입니다. 기존 발행자 인증서를 재사용합니다. 설치 방법은 [설치 안내](../../README.md#설치)를 참고하세요.

최종 검증: Release 전체 **368/368**, 서명 패키지의 자동 응답 12건·수동 질문 대기 12건, 웹·MCP·격리 PTY·입력 구성요소와 DMG 무결성 검사가 통과했습니다. Chromium·WebKit에서 정리·복원·새 경고·저장 실패·다른 세션·작성 초안·전송 중 요청·늦은 접수 응답을 검사했습니다. 390×844·768×1024·1440×900의 목록·메시지 화면과 어두운 화면을 확인했고 JavaScript 오류는 없었습니다. 실제 Swift HTTP를 쓰는 오류 확인·메시지 전송 회귀와 기존 유휴 목록·재연결 검사도 통과했습니다. 실물 휴대폰의 키보드·IME 검사는 포함하지 않았습니다.

같은 합성 ‘지난 답변 44개·새 질문 1개’의 실제 브라우저에서 질문 편집기는 **45→1개**, 질문·메시지 창의 DOM 요소는 **793→158개**였습니다. 화면 구성 수의 비교이며 앱 전체 CPU·메모리나 네트워크 지연의 개선율은 아닙니다.
