# AutoApprove 0.2.319 · build 346

그룹 조회에 모델·추론 수준을 포함하고 Codex↔Claude의 일반 메시지, 작업 지시와
완료 보고 경로를 개선합니다. 0.2.318의 Codex 대화 ID 보존 수정도 포함합니다.

`get_session_groups`와 `get_group_status`의 각 구성원에 `model`,
`reasoningEffort`, `modelSettingsSource`, `modelSettingsRecordedAt`을 반환합니다.
확인한 대화 UUID·로그인 홈에 대응하는 Codex 세션 메타데이터 또는 Claude의
마지막 실행 메타데이터를 읽습니다. 전역 기본값을 추정하지 않으며, 확인할 수
없는 값은 `null`입니다. 실행 전 모델 선택을 바꾼 직후에는 다음 기록이 생길
때까지 이전 실행값이 표시될 수 있습니다.

`send_group_message`는 그룹장 유무와 관계없이 같은 그룹의 Codex↔Claude를
양방향으로 지원합니다. 일반 대화는 작업 지시나 승인 권한을 부여하지 않습니다.
작업·선택지 승인에는 기존의 직속 관계 검증을 유지합니다. Codex MCP 호출의
대화 UUID·홈으로 확인된 그룹장은 터미널 프로세스가 조회되지 않아도 직속
Claude 구성원에게 지시할 수 있습니다.

Claude의 `Stop` 훅이 누락돼도 전달된 그룹 작업을 계속 확인합니다. 정확히
일치하는 대화가 대기 중이고, 지시 이후의 최종 응답(`end_turn`)이 기록돼 있어야
완료 보고를 복구합니다. 해당 응답의 사용자 요청도 지시 이후에 기록됐고 원래
작업 내용과 일치해야 합니다. 이전 응답·도구 실행 중·다른 대화·하위 대화·쓰는 중인
불완전한 기록은 완료 증거로 사용하지 않습니다. 읽기는 파일 끝 1 MiB로 제한하고
변경되지 않은 기록은 캐시합니다. 보고와 메시지는 같은 Mac의 로컬 수신함에
저장하며, 명시적인 수신 확인 전까지 보관합니다.

검사는 소유한 합성 대화·파일·가짜 터미널 어댑터를 사용하며 사용자 터미널에
시험 입력을 보내거나 기존 CLI를 재시작하지 않습니다.

디버그 전체 313/313, 릴리스 전체 282/282, IP 네트워크를 차단한 그룹 검사 43/43, 실제 격리 MCP
표준 입출력 검사 15/15를 통과했습니다. 오프라인 검사에는 같은 그룹의 양방향
일반 메시지·질문·답변, 충돌 시 보관, 재시작 후 복구와 수신 확인을 포함합니다.
