# AutoApprove 0.2.193 · build 220

공유 화면에서 키보드와 마우스로 Mac을 조작합니다.

- 화면 공유의 **조작하기**로 클릭·드래그·우클릭·더블 클릭·스크롤과 키보드 입력을 켭니다. 기본은 보기 전용입니다.
- 한글 조합·이모지·붙여넣기와 Mac 단축키 버튼, 휴대폰의 탭·보조 클릭·두 손가락 스크롤을 지원합니다.
- Mac 연결 설정에 **화면 조작 허용**을 추가했습니다. macOS 손쉬운 사용 권한은 사용자가 한 번 허용합니다.
- 지속 연결과 작은 바이너리 입력, 포인터 이동 병합, 조작 중 작은 화면의 빠른 갱신으로 전송량을 제한합니다.
- 한 Mac에 한 조작 연결만 허용하고 현재 화면·창 소유자·입력 순서·권한을 검사합니다. 연결 손실·오래된 화면·종료 시 버튼을 해제하며 입력을 자동 재전송하지 않습니다.
- 같은 터미널의 수동 조작 중 자동 승인은 대기합니다. 기존 원본 CLI·별도 터미널·Cloudflare 인증과 PortManager 주소를 유지합니다.
