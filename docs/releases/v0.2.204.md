# AutoApprove 0.2.204 · build 231

관리 페이지에서 Mac 기본 Terminal의 이전 출력을 **전체 기록**으로 볼 수 있습니다. 실시간 화면의 짧은 표시 범위를 늘리는 대신, 기록을 열 때만 별도로 읽고 필요한 구간을 전송합니다.

- 세션 선택 → **전체 기록**을 누릅니다. 처음에는 가장 최근 기록을 보여주며, 위아래 스크롤이나 **이전·다음**으로 앞뒤를 읽을 수 있습니다. **맨 처음·최신 기록**으로 바로 이동합니다.
- **새로고침**은 원본 Terminal에서 기록을 다시 가져옵니다. 조회 시각과 전체 줄 수를 표시하며, 실패하면 읽던 기록을 유지합니다. 읽기 전용이므로 기록 안의 과거 승인창을 실행하거나 키 입력을 원본으로 보내지 않습니다.
- 전체 원본은 사용자 전용 임시 파일에 보관합니다. 한 번에 최대 16,384 UTF-16 단위·512개 줄바꿈의 구간만 전송하고 브라우저는 최대 세 구간만 유지합니다. 같은 원본 조회는 공유하며, 기록을 열지 않으면 추가 조회나 화면 모듈 전송이 없습니다.
- 기본 Terminal이 현재 보관하고 있는 출력이 대상입니다. Terminal 설정이나 사용자의 지우기로 이미 삭제된 출력은 복구하지 못합니다. iTerm2·VS Code·앱 관리 PTY에는 이 버튼을 표시하지 않습니다. 선택한 Mac이 이 버전 이상이어야 합니다.
- 완료된 임시 기록은 최대 네 개·합계 512MiB로 제한하며, 새 원본 조회는 한 번에 하나만 진행합니다. 마지막 사용 후 10분이 지난 기록은 다음 조회 시 정리합니다. 앱 종료에도 정리하며 비정상 종료의 잔여 파일은 다음 기록 조회 때 정리합니다. 단일 기록이 512MiB를 넘으면 잘라 보여주지 않고 오류를 안내합니다.

검사 범위와 실제 Terminal 접근 도구의 제한은 [검증 기록](../../VALIDATION.md)에 구분해 기록합니다.
