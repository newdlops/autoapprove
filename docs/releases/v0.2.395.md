# AutoApprove 0.2.395 · 빌드 422

- 그룹장은 `list_group_background_jobs`에 groupID를 지정해 구성원의 백그라운드 작업을 조회합니다. memberID로 범위를 좁히거나 memberID와 jobID를 함께 넣어 최근 출력과 확인된 종료 코드를 봅니다.
- `stop_group_background_job(groupID, memberID, jobID)`는 지정한 작업 하나의 종료를 요청합니다. stopping은 확인 대기, stopped는 종료 확인입니다.
- Codex는 연결된 서버의 대화별 작업 ID를 사용합니다. Claude Code는 원래 CLI의 직속 셸, 전용 프로세스 그룹과 대화별 작업 출력 파일을 확인한 경우에 개별 중단을 지원합니다. Antigravity 등 개별 작업을 식별할 수 없는 세션은 화면에서 확인한 개수 또는 미확인을 표시합니다.
- 그룹 요약의 backgroundRunning과 canAcceptTask는 별개입니다. watch_group_events에서 관측한 작업의 종료·실패를 확인할 수 있습니다. 실행 시간이 확인되지 않으면 최초 관측 이후의 시간만 제공합니다.
