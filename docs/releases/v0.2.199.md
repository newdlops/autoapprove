# AutoApprove 0.2.199 · build 226

같은 네트워크에서 페이지 전체와 Mac 상태가 불필요하게 ‘다시 연결’로 바뀌는 경로를 수정했습니다.

- 이미 연결된 페이지의 목록 요청이 일시 실패하면 새 일반 조회로 한 번 재확인합니다. 성공하면 목록·선택·연결 상태를 유지하고, 재확인도 실패하면 실제 끊김을 표시합니다. 기존 요청 제한 시간 안에서 동작하며 정상 상태의 조회량은 늘리지 않습니다.
- LAN과 인증 게이트웨이에서 유휴 연결이 새 요청을 막던 문제를 수정했습니다. 연결 한도에 도달하면 처리가 끝난 빈 연결만 정리합니다. 활성 요청·터미널 출력·입력 채널과 기존 연결 한도는 유지합니다.
- 페이지가 처음 확인한 Mac의 식별을 유지합니다. 주소가 다른 Mac을 가리키거나 인증·응답 형식에 문제가 있으면 오류를 표시합니다. 입력이나 인증 제출을 자동 재전송하지 않습니다.

핵심 검사 521개와 Chromium·WebKit 장애 복구, 실제 Core의 연결 압력·터미널 연속성·인증 게이트웨이 검증을 통과했습니다. [검증 범위](../../VALIDATION.md).
